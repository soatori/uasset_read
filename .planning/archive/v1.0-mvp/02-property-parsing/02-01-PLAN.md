对于 Phase 2，实现以下分派器:
```python
def parse_int_property(tag: PropertyTag, archive: FArchive) -> int:
    """根据类型名解析 IntProperty (int32) 或 Int64Property (int64)。"""
    type_name = tag.type
    if type_name == "Int64Property":
        return archive.read_i64()
    elif type_name == "Int16Property":
        return archive.read_u16()  # Int16 有符号, UInt16 无符号
    elif type_name == "Int8Property":
        return archive.read_u8()   # Int8 有符号, UInt8 无符号
    else:  # IntProperty
        return archive.read_i32()

def parse_float_property(tag: PropertyTag, archive: FArchive) -> float:
    """根据类型名解析 FloatProperty (float) 或 DoubleProperty (double)。"""
    type_name = tag.type
    if type_name == "DoubleProperty":
        return archive.read_f64()
    else:  # FloatProperty
        return archive.read_f32()
```
