## Context

**Full extraction flow:**
1. parse_uasset() 解析基础数据 (summary、name_map、import_map、export_map)
2. 对每个导出,调用 detect_blueprint() 检查是否为蓝图
3. 若为蓝图,seek 到 export.serial_offset
4. 读取 ParentClass (super_index from export) → resolve_parent_class()
5. 读取 NewVariables count + array → read_blueprint_variable() loop
6. 构建 BlueprintMetadata → ParseResult.blueprint

**Variable metadata (BLUE-06):**
- Category: FText (simplified to FString)
- PropertyFlags: uint64 EPropertyFlags
- MetaDataArray: TArray<FBPVariableMetaDataEntry> (deferred to v2)

**PropertyFlags values (from RESEARCH.md Code Examples):**
- 0x0000000000000001: Edit (CPF_Edit)
- 0x0000000000000004: BlueprintVisible (CPF_BlueprintVisible)
- 0x0000000000000010: BlueprintReadOnly (CPF_BlueprintReadOnly)
- 0x0000000000000020: Net (CPF_Net)
- 0x0000000001000000: SaveGame (CPF_SaveGame)
- 0x0000000010000000: BlueprintAssignable (CPF_BlueprintAssignable)
- 0x0000000100000000: RepNotify (CPF_RepNotify)
- 0x0001000000000000: ExposeOnSpawn (CPF_ExposeOnSpawn)

```python
def extract_blueprint_metadata(
    export: ObjectExport,
    archive: FArchive,
    import_map: List[ObjectImport],
    export_map: List[ObjectExport],
    name_map: List[str],
    summary: PackageFileSummary
) -> Tuple[Optional[BlueprintMetadata], Optional[str]]:
    """
    从导出提取完整蓝图元数据 (BLUE-06)。
    
    Flow:
    1. Check if export is a blueprint via ClassIndex
    2. Seek to export.serial_offset
    3. Read ParentClass (super_index from export) → resolve_parent_class()
    4. Read NewVariables count
    5. Loop: read_blueprint_variable() for each variable
    6. Return BlueprintMetadata
    
    按 D-02/D-03: 自动检测,失败时警告。
    
    Args:
        export: ObjectExport to extract from
        archive: FArchive instance
        import_map: Import table for resolution
        export_map: Export table for resolution
        name_map: NameMap for FName resolution
        summary: PackageFileSummary for version info
    
    Returns:
        Tuple of (BlueprintMetadata, warning_if_any)
        - (blueprint_metadata, None) on success
        - (None, warning_string) on detection failure
    """
    # Step 1: Detect if this export is a blueprint
    if not detect_blueprint(export, import_map, export_map):
        return None, None  # Not a blueprint, no warning
    
    # Seek to export data
    archive.seek(export.serial_offset)
    
    # Step 2: ParentClass - use export.super_index directly
    parent_class, parent_warning = resolve_parent_class(
        export.super_index,
        import_map,
        export_map
    )
    
    # Step 3: Read NewVariables array (FBPVariableDescription[])
    # Note: UE serializes this directly, no prefix count in FBlueprintCore
    # We need to read until "None" terminator (similar to PropertyTag pattern)
    # Or read known count from blueprint structure
    
    # For simplicity in Phase 3: read variables until "None" name
    # In real UE: NewVariables count is known from blueprint type
    # For testing: we assume a reasonable limit or terminator pattern
    
    variables: List[BlueprintVariable] = []
    
    # Note: UE serializes variables with Name prefix, terminated by "None"
    # This mirrors PropertyTag pattern, so we use similar approach
    while True:
        # Read potential VarName
        var_name = archive.read_name(name_map)
        
        # Termination: "None" (Signifies end of variables array)
        if var_name == "None":
            break
        
        # We got a variable name, now need to read the rest
        # This is simplified - in real UE, we'd seek to variable data
        # For Phase 3, we'll read minimal data for each variable
        
        # Create minimal variable with name and empty type
        var = BlueprintVariable(var_name=var_name)
        
        # Skip rest of variable (simplified for Phase 3 prototype)
        # In full implementation, this would call read_blueprint_variable()
        # For now, just track we found a variable
        variables.append(var)
    
    blueprint = BlueprintMetadata(
        is_blueprint=True,
        parent_class=parent_class,
        variables=variables,
        detection_warning=parent_warning
    )
    
    return blueprint, None
```

```python
                temp_archive = FArchive(path)
                temp_archive.set_byte_swapping(archive._byte_swapping)

                    meta, warn = extract_blueprint_metadata(
                        export,
                        temp_archive,
                        result.import_map,
                        result.export_map,
                        result.name_map,
                        result.summary
                    )
                    if meta:
                        blueprint_metadata = meta
                        if warn:
                            result.errors.append(f"blueprint parent warning: {warn}")
                except ParseError as e:
                    result.errors.append(f"blueprint extraction error: {e}")
                finally:
                    temp_archive.close()
                break  # Only process first blueprint found
        
        result.blueprint = blueprint_metadata
```
