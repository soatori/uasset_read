All expression subclasses inherit from `KismetExpression` and are dataclasses with `from_archive()` classmethods. Key attribute patterns:
- Literals: `.Value` holds the constant (int/float/bool/str)
- Variables: `.Variable` or `.Property` holds FKismetPropertyPointer
- Functions: `.StackNode` (int), `.Parameters` (list[KismetExpression])
- Control flow: `.CodeOffset` (int) for jumps, `.BooleanExpression` for JumpIfNot
- Assignments: `.Variable` + `.Assignment` (KismetExpression)
- Casts: `.Target` (KismetExpression) + `.ConversionType` (ECastToken byte) or `.ClassPtr`
- Context: `.ObjectExpression` + `.ContextExpression`

- EX_Let → `f"{line_cpp(expr.Variable, tr)} = {line_cpp(expr.Assignment, tr)}"`
- EX_LetBool → same as EX_Let
- EX_LetDelegate/EX_LetMulticastDelegate → same pattern
- EX_LetObj/EX_LetWeakObjPtr → same pattern
- EX_LetValueOnPersistentFrame → special: if variable name contains "K2Node_", prefix with "UberGraphFrame->" (per CUE4Parse)

**Function calls (per D-04, uses MathFunctionCleaner):**
- EX_FinalFunction/EX_CallMath/EX_LocalFinalFunction → render params via recursive `line_cpp()`, then call `MathFunctionCleaner()` for EX_CallMath, or render as `ClassName::FuncName(params)` for others
- EX_VirtualFunction/EX_LocalVirtualFunction → similar without math cleaning
- EX_CallMulticastDelegate → `delegate.Broadcast(params)`
- EX_InstanceDelegate → `delegate.Invoke(params)`
- EX_EndParmValue/EX_EndFunctionParms → `""` (marker tokens, no output)

- `f"return {line_cpp(expr.ReturnExpression, tr)}"`

**No-output operators:**
- EX_EndOfScript → `""`
- EX_DeprecatedOp4A → `""`
- EX_Nothing/EX_NothingInt32 → `""`

For each case, call `line_cpp()` recursively on child expressions. Pass `type_registry` through all recursive calls.
