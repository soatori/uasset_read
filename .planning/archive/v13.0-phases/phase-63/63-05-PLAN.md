  <files>src/uasset_read/kismet/structured_flow.py</files>
  <action>
Create `StructuredControlFlow` class in `structured_flow.py`:

**CFG Construction:**
1. Build a mapping from StatementIndex → expression index in the list
2. Build successor map: for each expression, determine which expressions can follow
   - Normal: next expression (index + 1)
   - EX_Jump: target expression at CodeOffset
   - EX_JumpIfNot: both next (if true) and target (if false)
   - EX_Return: no successor (terminal)
3. Build predecessor map (reverse of successor map)

**if/else Detection (Push+JumpIfNot+Pop pattern):**

The bytecode pattern for if/else:
```
PushExecutionFlow(else_offset)     → push else_offset
JumpIfNot(condition, else_offset) → if (!condition) goto else
... then body ...
PopExecutionFlow()                 → pop → goto else
Label_else:
... else body (or end if no else) ...
```

Detection algorithm:
1. Scan for `EX_PushExecutionFlow` followed by `EX_JumpIfNot` with matching offset
2. The push offset = the jump target = the else branch start
3. Find the `EX_PopExecutionFlow` that ends the then body
4. The else body runs from else_offset until the next label or end of function
5. If there's no separate else body (jump target is at end), it's if-only (no else)

When a pattern is detected:
- Extract condition from `JumpIfNot.BooleanExpression` via `line_cpp()`
- Extract then-body lines (expressions between JumpIfNot and PopExecutionFlow)
- Extract else-body lines (expressions from else_offset to next label/end)
- Render as:
  ```cpp
  if (condition) {
      // then body
  } else {
      // else body
  }
  ```

For if-only (no else):
```cpp
if (condition) {
    // then body
}
```

Use a work-list approach: scan for patterns, replace matched regions with structured blocks, continue until no more patterns found.

**Fallback:** If pattern matching fails, render as goto-based output (same as Plan 04).

Extend `StructuredControlFlow` with loop detection:

**For loop detection (back-jump pattern):**

The bytecode pattern for for loops:
```
Label_start:
... loop body ...
(condition check)
if (condition) goto Label_start  → back-jump to start
```

Detection: Look for EX_Jump or EX_JumpIfNot where the target offset is BEFORE the current instruction (back-jump).

When a back-jump is found:
1. The loop body is from the jump target to the jump instruction
2. The condition is from JumpIfNot.BooleanExpression (or always-true for unconditional for)
3. Render as:
   ```cpp
   while (condition) {
       // body
   }
   ```
   or if there's an initialization before the loop:
   ```cpp
   for (; condition; ) {
       // body
   }
   ```

**While loop detection (Push+JumpIfNot+back-jump):**

Pattern:
```
PushExecutionFlow(after_loop)
Label_loop_start:
JumpIfNot(condition, after_loop)  → exit when false
... loop body ...
Jump Label_loop_start             → back to start
Label_after_loop:
```

Render as:
```cpp
while (condition) {
    // body
}
```

**Integration into FunctionBodyBuilder:**
1. Modify `FunctionBodyBuilder.build()` to accept optional `structured: bool = True` parameter
2. When structured=True:
   - Run `StructuredControlFlow(expressions, type_registry).analyze()`
   - Use structured output for recognized patterns
   - Use goto-based output for unrecognized patterns
3. When structured=False: use pure goto-based output (Plan 04 behavior)

**D-03 compliance:** If any pattern detection fails or produces ambiguous results, silently fall back to goto. Do NOT raise errors or block on edge cases. Log unstructured regions as comments: `/* could not structure this region */`.
