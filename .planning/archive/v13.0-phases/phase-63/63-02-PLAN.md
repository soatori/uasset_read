Add `match/case` entries in `line_cpp()` for all cast types:

**EX_Cast:** Uses `ConversionType` (ECastToken byte). Map each ECastToken to a C++ type name:
- CST_ObjectToBool → `"bool"`, CST_ObjectToBool2 → `"bool"`
- CST_InterfaceToBool → `"bool"`, CST_InterfaceToBool2 → `"bool"`
- CST_DoubleToFloat → `"float"`, CST_FloatToDouble → `"double"`
- CST_ObjectToInterface → `"interface"`
- Default: `f"Cast<unknown_{expr.ConversionType}>()"`

Render as: `f"Cast<{cpp_type}>({line_cpp(expr.Target, tr)})"`

**EX_CastBase / EX_DynamicCast / EX_ObjToInterfaceCast / EX_CrossInterfaceCast / EX_InterfaceToObjCast:**
- These have `ClassPtr` (int package index). Since we can't resolve the class name without linker, render as:
  `f"Cast<{expr.ClassPtr}>({line_cpp(expr.Target, tr)})"` — use placeholder with index

**EX_MetaCast:**
- Render as: `f"static_cast<auto>({line_cpp(expr.Target, tr)})"` — MetaCast is for metaclass casting, use static_cast hint

All handlers recursively call `line_cpp()` on `.Target` child expression.
