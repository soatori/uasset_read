## Tasks

### Task 1: 修复 FMemberReference 的 MemberName 读取 (GAP-01)

**问题:** `read_fmember_reference()` 中 `archive.read_name(name_map)` 返回 'None'。

**根因分析:**
1. PropertyTag 层已正确解析 `FunctionReference.MemberName` (见 GAP-REPORT)
2. 但 `create_node_from_archive()` 调用 `read_fmember_reference()` 时 archive 位置不对
3. UE5 的 FName 序列化格式: `index (i32) + number (i32)`，而 `read_name()` 可能只读取 index

**文件:** `src/uasset_read/serializers/graph.py`

**Action:**

1. **调试 archive 位置问题:**
   - 在 `read_ue_graph_node()` 中，确认 `read_k2node_call_function()` 调用时的 archive 位置
   - 检查是否在 script_serial PropertyTag 解析后，archive 跳过了正确的偏移量
   - 参考 UE 源码: `K2Node_CallFunction.cpp` 的 `Serialize()` 函数确认字段顺序

2. **修复 FName 序列化:**
   - UE5 FName = `NameIndex (i32) + Number (i32)` (见 `FArchive& operator<<(FName&)`)
   - 确认 `archive.read_name()` 正确读取两个 i32 值
   - 如果当前实现只读取 index，需要添加 number 读取

3. **验证方案:**
   - 使用 `BP_FirstPersonCharacter.uasset` 中的 `K2Node_CallFunction_8428` 作为测试目标
   - 预期 `member_name` = `'AddControllerYawInput'` 或类似函数名

**Verify:**
```xml
<verify>
  <automated>pytest tests/test_graph_parser_fix.py::test_fmember_reference_member_name -v</automated>
</verify>
```

**Done:** `function_reference.member_name` 不为 'None'，能正确解析为实际函数名（如 'AddControllerYawInput'）。

### Task 2: 修复 Pin 连接数组读取 (GAP-02)

**问题:** `read_pin_array()` 返回空列表，导致所有 `linked_to_raw=[]`。

**根因分析:**
1. UE 源码 `SerializePinArray()` 先读取 `int32 ArrayNum`
2. 当前 `read_pin_array()` 可能:
   - archive 位置不对（在读取其他字段后错位）
   - `bNullPtr` 格式错误（UE5 bool = uint32，非 int32）
   - 数组元素序列化格式与 UE5 不匹配

**文件:** `src/uasset_read/serializers/graph.py`

**Action:**

1. **修复 read_pin_reference 中的 bNullPtr 格式:**
   - UE5: `Ar << bNullPtr` → bool 序列化为 `uint32` (4 bytes)
   - 当前: `archive.read_i32()` → 错误，应使用 `archive.read_bool()` (已正确映射到 uint32)
   - 或确认 `read_bool()` 的实现是否正确读取 4 bytes

2. **确认 archive 位置正确性:**
   - 在 `read_ue_graph_pin()` 中，确认调用 `read_pin_array()` 前 archive 已正确读取所有前置字段
   - 添加位置断言检查，对比实际位置与预期位置

3. **添加调试日志（临时）:**
   - 记录 `array_count` 读取值
   - 如果 `array_count == 0`，记录当前位置和文件剩余字节
   - 使用 UE 编辑器导出的同一文件对比验证

**Verify:**
```xml
<verify>
  <automated>pytest tests/test_graph_parser_fix.py::test_pin_linked_to_not_empty -v</automated>
</verify>
```

**Done:** `pin.linked_to_raw` 不为空数组，包含正确的 Pin 引用（`{"owning_node": str, "pin_guid": str}`）。
