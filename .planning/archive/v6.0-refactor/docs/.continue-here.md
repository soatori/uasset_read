**UE5 序列化格式发现：**

1. **NodePosX 存储位置变化**: UE5 将节点位置信息作为 PropertyTags 存储在 script_serial 区域，而非 pins 解析后的裸字段
2. **FPropertyTypeName 格式**: FName(8 bytes: index + number) + InnerCount(4 bytes)，测试需使用此格式而非 FString
3. **空 flow 处理**: EnhancedInputAction 的 Started/Ongoing 状态可能无连接，需过滤避免空 function_name
4. **连接格式**: linked_to_raw 使用 `{"pin_guid": str}` dict 格式在 output pin 上
