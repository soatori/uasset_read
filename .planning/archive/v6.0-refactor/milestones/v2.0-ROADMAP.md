**Status:** ✅ SHIPPED 2026-05-02

## Overview

v2.0里程碑实现蓝图图完整解析、高级属性类型支持、依赖分析功能，使AI agent能理解蓝图逻辑并作为C++转换参考。修复v1.0导出表解析bug，新增Graph→Node→Pin三层结构解析、六种高级属性解析、ImportMap+SoftObjectPaths依赖图构建。

### Phase 7: 蓝图图核心解析

**Goal**: 实现蓝图图结构的基础解析（Graph → Node → Pin）

**Depends on**: Phase 6

**Plans**: 3 plans

- [x] 07-01: 数据结构定义 + EdGraph检测（GRAPH-01, GRAPH-02）
- [x] 07-02: Node/Pin核心解析（GRAPH-03, GRAPH-04）
- [x] 07-03: 节点类型特定解析器 + 测试（GRAPH-05~09）

**Details**:

定义蓝图图三层数据结构：
- **UEdGraphPin**: pin_id (FGuid hex), pin_name, direction, pin_type, linked_to_raw, sub_pins, parent_pin
- **UEdGraphNode**: node_guid, node_pos_x/y, node_comment, pins, class_name, node_data (多态)
- **UEdGraph**: graph_name, graph_class, schema, nodes, graph_guid, b_editable
- **FMemberReference**: member_parent, member_name, member_guid, b_self_context

ParseResult扩展：
- 新增 `graphs: List[UEdGraph]` 顶层字段（与blueprint同级）

实现EdGraph导出类型检测：
- PKG_Cooked标志检测（避免解析已剥离资产）
- ClassIndex包含"EdGraph"或"UberEdGraph"视为图对象

节点类型识别（9种）：
- K2Node_CallFunction（函数调用）
- K2Node_Event（事件节点）
- K2Node_Knot（路由节点）
- EdGraphNode_Comment（注释节点）
- K2Node_EnhancedInputAction（输入动作）
- K2Node_VariableGet/Set（变量访问）
- K2Node_IfThenElse（条件分支）
- K2Node_MacroInstance（宏实例）

### Phase 9: 高级属性类型

**Goal**: 实现高级属性类型的完整解析（StructProperty、MapProperty、SetProperty、EnumProperty、TextProperty、DelegateProperty）

**Depends on**: Phase 7

**Plans**: 3 plans

- [x] 09-01: 数据类定义 + type_dispatch扩展（ADVP-01~06）
- [x] 09-02: 六种高级属性解析函数实现（ADVP-01~06）
- [x] 09-03: 单元测试 + Lyra资产验证（ADVP-01~06）

**Details**:

定义AdvancedPropertyValue基类 + 六种高级属性dataclass：
- **StructValue**: fields: Dict[str, Any], 递归深度限制5
- **MapValue**: pairs: List[Tuple[Any, Any]]
- **SetValue**: elements: List[Any]
- **EnumValue**: enum_type: str, enum_value: str
- **TextValue**: namespace: str, key: str, source_string: str
- **DelegateValue**: object_name: str, function_name: str

扩展parse_property_value() type_dispatch：
- 添加summary和depth参数（版本检查、递归深度）
- 六种高级属性lambda入口

解析函数实现：
- `parse_struct_property()`: 嵌套结构体解析，递归深度限制
- `parse_map_property()`: 键值对数组，支持基本类型键
- `parse_set_property()`: 唯一元素集
- `parse_enum_property()`: 枚举类型名 + 枚举值名
- `parse_text_property()`: FText三字段提取
- `parse_delegate_property()`: 函数引用解析

### Phase 10: 依赖分析

**Goal**: 构建 ImportMap + SoftObjectPaths 依赖图，检测循环依赖

**Depends on**: Phase 7

**Plans**: 6 plans (including 2 gap closure plans)

- [x] 10-01: ParseResult扩展 — imports/soft_references/circular_deps字段
- [x] 10-02: build_imports_list + read_soft_object_paths函数实现（DEPS-01, DEPS-02）
- [x] 10-03: detect_circular_deps + format_json_full扩展 + parse_uasset集成（DEPS-03, DEPS-04）
- [x] 10-04: 单元测试 + 完整验证（DEPS-01~04）
- [x] 10-05: [GAP CLOSURE] SoftObjectPath UE5 >= 1007 FTopLevelAssetPath格式修复
- [x] 10-06: [GAP CLOSURE] ImportMap UE5条件字段 + 蓝图提取修复

**Details**:

ParseResult扩展三个顶层字段：
- `imports: List[Dict]` — ImportMap依赖列表（包路径、类名、对象名）
- `soft_references: List[Dict]` — SoftObjectPaths软引用（AssetReference）
- `circular_deps: List[List[str]]` — 循环依赖列表

build_imports_list()实现：
- 解析ImportMap构建依赖列表
- 提取package_path、class_name、object_name
- 处理UE5条件字段（TopLevelAssetPath格式）

read_soft_object_paths()实现：
- 解析SoftObjectPaths数组
- UE5 >= 1007使用FTopLevelAssetPath格式（AssetPath/SubPathString）
- UE5 < 1007使用旧格式（AssetPath/ObjectPath）

detect_circular_deps()实现：
- 检测ImportMap相互引用
- 返回循环依赖链列表

Gap Closure修复：
- SoftObjectPath UE5 >= 1007 FTopLevelAssetPath格式（2字段）
- ImportMap UE5条件字段（TopLevelAssetPath）
- 蓝图提取修复（ClassIndex解析）
