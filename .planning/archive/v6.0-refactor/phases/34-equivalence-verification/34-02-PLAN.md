**步骤 B: 修复确认的 Bug**

根据 34-RESEARCH.md 推荐，修复以下两个确认的 bug：

**Bug #8: parent_class str(dict) — 修复 variable_extractor.py:357**

当前代码（第 357 行）：
```python
parent_class = str(prop.value) if prop.value else None
```

问题：prop.value 是 ObjectProperty 实例时，str() 产生 `"{'type': 'import', ...}"` 字面量字符串。

修复方案：
```python
# 如果 prop.value 是 PropertyValue 实例，提取其 raw_value
if prop.value and hasattr(prop.value, 'value'):
    parent_class = prop.value.value if prop.value.value else None
elif prop.value and isinstance(prop.value, dict):
    parent_class = prop.value.get('raw_index') or prop.value.get('resolved')
else:
    parent_class = prop.value if prop.value else None
```

注意：此修复可能导致 parent_class 从 str(dict) 变为裸整数值（raw_index）。如果旧版输出也是 None 或 None-like，则修复后可能更接近旧版行为。

**Bug #7: mermaid 缺失 — 修复 _build_mermaid_flowchart**

当前代码（markdown_formatter.py:128-132）：
```python
for node in nodes:
    if node.get("node_type") == "K2Node_CallFunction":
        func_name = node.get("function_name", "Unknown")
        calls.append(func_name)
```

问题：新版 execution_flows 的 nodes 没有 function_name 字段，且 node_type 全是 K2Node_Event。

修复方案：适配新格式
```python
for node in nodes:
    node_type = node.get("node_type", "")
    # 新格式: 提取 node_type 作为节点名（去掉 K2Node_ 前缀）
    node_name = node_type.replace("K2Node_", "") if node_type else "Unknown"
    # 如果有 function_name（旧格式兼容），使用它
    func_name = node.get("function_name")
    if func_name:
        calls.append(func_name)
    elif node_type:
        calls.append(node_name)
```

修复后：mermaid 图将显示节点类型链（如 Event --> SetVisibility --> SetActorLocation），虽然不如函数名链精确，但至少恢复了图表功能。
