## Task 1: 实现 UEdGraphPin 解析函数（GRAPH-04）

新增 `read_ue_graph_pin()` 函数：

1. **安全边界常量**
   - `MAX_PINS_PER_NODE = 1000`（T-07-02-02）
   - `MAX_NODES_PER_GRAPH = 5000`（T-07-02-03）
   - `MAX_LINKEDTO_PER_PIN = 100`（T-07-02-04）

2. **辅助函数 `resolve_class_name()`**
   - 从 PackageIndex 解析类名（支持 Import/Export 引用）
   - 用于 Schema、ClassIndex 等 FPackageIndex 字段

3. **引脚解析函数 `read_ue_graph_pin()`**
   - 序列化顺序：
     1. PinId (FGuid 16 bytes) → hex string
     2. PinName (FName) → str
     3. Direction (uint8) → int
     4. PinType → 调用 Phase 3 `read_ed_graph_pin_type()`
     5. DefaultValue/AutogeneratedDefaultValue (FString)
     6. LinkedTo 数组 → D-01a 原始数据存储
     7. SubPins 数组 → PinId 列表
     8. ParentPin 条件字段
     9. Flags bitfield
   - 边界检查：linked_to_count/sub_pins_count <= MAX_LINKEDTO_PER_PIN

## Task 2: 实现 UEdGraphNode/UEdGraph 解析函数（GRAPH-03）

新增 `read_ue_graph_node()` 和 `read_ue_graph()` 函数：

1. **节点解析函数 `read_ue_graph_node()`**
   - 定位到节点 SerialOffset
   - 序列化顺序：
     1. Pins 数组 → 调用 `read_ue_graph_pin()`
     2. NodePosX/Y (int32)
     3. NodeGuid (FGuid 16 bytes)
     4. NodeComment (FString)
   - 类型识别：`resolve_class_name(node_export.class_index)`
   - 边界检查：pins_count <= MAX_PINS_PER_NODE
   - node_data = None（Wave 3 实现类型特定解析）

2. **图解析函数 `read_ue_graph()`**
   - 定位到图 SerialOffset
   - 序列化顺序：
     1. Schema (FPackageIndex) → resolve_class_name
     2. Nodes 数组 (FPackageIndex → 导出 → read_ue_graph_node)
     3. GraphGuid (FGuid 16 bytes)
     4. bEditable (uint8)
   - 边界检查：nodes_count <= MAX_NODES_PER_GRAPH

3. **更新 `extract_blueprint_graphs()`**
   - 添加 `archive`、`name_map` 参数
   - 调用 `read_ue_graph()` 完整解析

4. **更新 `parse_uasset()`**
   - 添加 graphs 字段填充调用
