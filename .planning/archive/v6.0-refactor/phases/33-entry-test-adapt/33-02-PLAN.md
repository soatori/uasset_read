**create_parser() 函数（D-03）：**
等价迁移旧版，包含以下参数：
- `file`（位置参数）: `.uasset` 文件路径
- `--json`（互斥组）: 输出完整 JSON 结构
- `--text`（互斥组）: 输出 YAML 风格文本（默认）
- `--summary`（互斥组）: 输出精简摘要格式
- `--markdown`（互斥组）: 输出 Markdown 格式
- `--verbose`: 包含额外详细字段
- `--output FILE`: 写入文件而非 stdout
- `--export INDEX`: 仅输出指定索引的 export
- `--graph`: 在输出中包含蓝图图数据
- `--schema`: 包含字段语义注解（_schema）

**main() 函数（D-05）：**
完整等价迁移旧版逻辑：
1. 调用 `create_parser()` 解析参数
2. `SystemExit` 捕获 → `sys.exit(EXIT_ARGUMENT_ERROR)`
3. 文件存在性检查：不存在 → 输出 "Error: File not found: {path}" 到 stderr → `sys.exit(EXIT_FILE_NOT_FOUND)`
4. 调用 `parse_uasset(args.file)` 获取 ParseResult
5. `result.is_success == False` → 输出 "Parse errors:" + 每条错误到 stderr → `sys.exit(EXIT_PARSE_ERROR)`
6. 格式路由（按优先级）：
   - `args.graph` 为 True:
     - `args.json or args.verbose`: `format_json_full(result, include_schema)` → JSON 输出
     - `args.text`: `format_text_full(result)` → 文本输出
     - 否则: `{"graphs": format_graphs_json(result.graphs)}` → JSON 输出
   - `args.markdown`: `format_markdown(result)`
   - `args.json`: `format_json_full(result, include_schema)` → JSON 输出
   - `args.summary`: `format_json_summary(result, include_schema)` → JSON 输出
   - 默认（无标志或 --text）: `format_text_full(result)`
7. 输出路由：
   - `args.output` 存在：写入文件，输出 "Output written to {path}" 到 stderr
   - 否则：print 到 stdout
8. `sys.exit(EXIT_SUCCESS)`

其中 `include_schema = args.schema or args.verbose`。

**格式导入语句：**
```python
from uasset_read.formatters import (
    format_json_full,
    format_json_summary,
    format_text_full,
    format_markdown,
    format_graphs_json,
)
```

**注意：** `--export INDEX` 参数在旧版 `main()` 中没有实际使用（仅定义），新版保持相同行为。

|----------|-------------|
| 用户输入 → argparse | --export INDEX 为 int 类型，argparse 自动验证非整数值 |
| 用户提供的文件路径 → Path | 仅读取不写入，无路径遍历风险（只读操作） |
| 解析结果 → stdout | 解析数据输出到 stdout，错误输出到 stderr（D-25 决策） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-05 | Tampering | CLI file path (path traversal) | accept | CLI 仅执行读取操作，不写入文件（除 --output 指定路径），不执行用户输入 |
| T-33-06 | DoS | CLI --export INDEX (invalid int) | mitigate | argparse type=int 自动拒绝非整数输入 |
| T-33-07 | DoS | --output FILE write error | mitigate | try/except IOError 捕获写入错误，输出到 stderr 并退出 EXIT_ARGUMENT_ERROR |
| T-33-08 | Information Disclosure | Error messages to stderr | accept | 错误消息仅包含文件名和简短描述，不泄露内部路径或堆栈跟踪 |
