**函数 1: `read_ed_graph_pin_type(archive, name_map, summary) -> FEdGraphPinType`**
- 版本检查：`ue4_version = summary.file_version_ue4`，`use_custom_serialization = ue4_version >= 324`
- 自定义序列化模式（UE4 >= 324）：按 EdGraphPin.cpp L163-346 顺序读取
  - PinCategory/PinSubCategory 使用 use_fname_format 判断（framework_version >= FFRAMEWORK_VERSION_PINS_STORE_FNAME or summary.file_version_ue5 > 0）
  - PinSubCategoryObject: i32
  - ContainerType: use_modern_container = framework_version >= FFRAMEWORK_VERSION_ED_GRAPH_PIN_CONTAINER_TYPE or summary.file_version_ue5 > 0；现代模式读 u8 + Map 处理，旧模式读 3 个 bool
  - 位标志: u8 字节提取 is_reference(0x04), is_const(0x08), is_weak_pointer(0x10), is_uobject_wrapper(0x20)
- 反射序列化模式（UE5 默认）：按 EdGraphPin.h L76-133 声明顺序读取
  - PinCategory(FName), PinSubCategory(FName), PinSubCategoryObject(i32), MemberParent(i32), MemberName(FName), MemberGuid(16 bytes), TerminalCategory(FName), TerminalSubCategory(FName), TerminalSubCategoryObject(i32), ContainerType(u8), 位标志(u8)

**函数 2: `read_ue_graph_pin(archive, name_map, summary, export_map, import_map) -> UEdGraphPin`**
- 18 字段按顺序读取（UE 源码 EdGraphPin.cpp L1838-1964）：
  1. OwningNode (i32)
  2. PinId (16 bytes hex)
  3. PinName (FName/FString 版本依赖)
  4. PinFriendlyName (FText) — 使用 try/except + seek-back 回退策略处理 history_type -1/0/255/其他
  5. SourceIndex (i32, 版本依赖 mainstream_version >= FUE5_MAINSTREAM_VERSION_ED_GRAPH_PIN_SOURCE_INDEX，带 fallback)
  6. PinToolTip (FString)
  7. Direction (u8)
  8. PinType (调用 read_ed_graph_pin_type)
  9. DefaultValue (FString, try/except 容错)
  10. AutogeneratedDefaultValue (FString, try/except 容错)
  11. DefaultObject (i32)
  12. DefaultTextValue (FText, 简化跳过)
  13. LinkedTo 数组: 先读 count (i32), 验证 0 <= count <= MAX_LINKEDTO_PER_PIN, 循环调用 read_pin_reference
  14. SubPins 数组: 同上
  15. ParentPin: 调用 read_pin_reference（单个）
  16. ReferencePassThroughConnection (i32 或 serialize pin)
  17. PersistentGuid (EditorOnly, 跳过)
  18. BitField (u32, EditorOnly, 解析 hidden/not_connectable/advanced_view/orphaned_pin)
- read_pin_reference 辅助函数: 读 bNullPtr(i32), if 0 则读 OwningNode(i32)+PinGuid(16 bytes hex), 返回 {"pin_guid": str}

**函数 3: `read_fmember_reference(archive, name_map, import_map, export_map) -> FMemberReference`**
- 按 MemberReference.h L74-95 顺序：
  1. MemberParent (i32, 非零时 resolve_class_name)
  2. MemberScope (FString)
  3. MemberName (FName)
  4. MemberGuid (16 bytes hex)
  5. bSelfContext (bool)
  6. bWasDeprecated (bool)

**函数 4-8: 5 种节点类型读取器**
- `read_k2node_call_function(archive, name_map, import_map, export_map) -> K2NodeCallFunction`
  - 读 FunctionReference (调用 read_fmember_reference) + bDefaultsToPureFunc (bool)
  - 返回 K2NodeCallFunction(function_reference=..., b_defaults_to_pure=...)
- `read_k2node_event(archive, name_map, import_map, export_map) -> K2NodeEvent`
  - 读 EventReference (调用 read_fmember_reference) + bOverrideFunction (bool)
  - 返回 K2NodeEvent(event_reference=..., b_override_function=...)
- `read_k2node_knot(archive) -> K2NodeKnot`: 无额外字段，返回 K2NodeKnot()
- `read_edgraph_node_comment(archive) -> EdGraphNodeComment`: 读 comment_color(4*f32), node_width(i32), node_height(i32), font_size(i32)
- `read_k2node_enhanced_input(archive, name_map) -> K2NodeEnhancedInputAction`: 读 input_action_path (FString)

**函数 9: `create_node_from_archive(archive, name_map, summary, export_map, import_map, node_export, base_node) -> UEdGraphNode`**
- D-07/D-08 工厂模式，根据 base_node.class_name match/case 分派
- case "K2Node_CallFunction": base_node.node_data = read_k2node_call_function(...)
- case "K2Node_Event": base_node.node_data = read_k2node_event(...)

- case _: base_node.node_data 保持 None（未知类型回退）
- 返回 base_node

**函数 10: `read_ue_graph_node(archive, name_map, summary, export_map, import_map, node_export) -> UEdGraphNode`**
- archive.seek(node_export.serial_offset)
- 解析 script_serial PropertyTags（L4037-4163 等价迁移）：
  - script_start = serial_offset + script_serial_offset, script_end = script_start + script_serial_size
  - UE5 >= 1011: 读 SerializationControlExtensions (u8, if ctrl & 0x02 跳过 override_operation)
  - while tell() < script_end: 读 PropertyTag, 根据 tag.name 提取 FunctionReference/EventReference/NodePosX/NodePosY/NodeGuid/NodeComment
  - FunctionReference/EventReference: 解析嵌套 PropertyTags（MemberParent(i32), MemberScope(FString), MemberName(FName), MemberGuid(16 bytes), bSelfContext(bool from tag.bool_val 或 UBOOL), bWasDeprecated(bool)）
- 计算 pins_offset = script_serial_offset + script_serial_size
- archive.seek(serial_offset + pins_offset), 跳过 end_marker (i32)
- 读 pins_count (i32), 验证 0 <= count <= MAX_PINS_PER_NODE
- 循环读 pins: bNullPtr(i32, if 0 则跳过 20 bytes; 否则跳过 OwningNode_1+PinGuid_1), 调用 read_ue_graph_pin
- UE4 格式: if node_guid == "", 读 NodePosX/NodePosY(i32*2), NodeGuid(16 bytes), NodeComment(FString)
- 解析 class_name = resolve_class_name(node_export.class_index, import_map, export_map) or ""
- 调用 create_node_from_archive 设置 node_data
- 返回 UEdGraphNode(node_guid=..., node_pos_x=..., node_pos_y=..., node_comment=..., pins=..., class_name=..., node_data=...)

**函数 11: `read_ue_graph(archive, name_map, summary, export_map, import_map, graph_export, graph_class, graph_export_idx=0) -> UEdGraph`**
- archive.seek(graph_export.serial_offset)
- 读 Schema (i32, 非零时 resolve_class_name)
- 读 nodes_count (i32), 验证 0 <= count <= MAX_NODES_PER_GRAPH
- if nodes_count > 0: 循环读 node_index (i32), export_map[node_index-1], 调用 read_ue_graph_node
- if nodes_count == 0 and graph_export_idx > 0: 遍历 export_map, outer_index.index == graph_export_idx 且 class_name 包含 "K2Node"/"EdGraphNode"/"Node" 的节点, 调用 read_ue_graph_node
- 读 GraphGuid (16 bytes hex)
- 读 bEditable (u8 -> bool)
- 返回 UEdGraph(graph_name=graph_export.object_name, graph_class=graph_class, schema=..., nodes=..., graph_guid=..., b_editable=...)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .uasset file → FArchive | 不可信二进制输入，可能包含恶意构造的数组计数/偏移 |
| script_serial → PropertyTag loop | 嵌套 PropertyTags 可能构造无限循环或超大 size |
| name_map index → read_name | 节点导出中的 FPackageIndex 可能指向不存在的名称条目 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-01 | DoS | read_ue_graph_node (pins_count) | mitigate | 验证 0 <= pins_count <= MAX_PINS_PER_NODE (1000)，超出则抛出 ParseError |
| T-31-02 | DoS | read_ue_graph (nodes_count) | mitigate | 验证 0 <= nodes_count <= MAX_NODES_PER_GRAPH (5000)，超出则抛出 ParseError |
| T-31-03 | DoS | read_ue_graph_pin (linked_to count) | mitigate | 验证 0 <= count <= MAX_LINKEDTO_PER_PIN (100)，超出则抛出 ParseError |
| T-31-04 | Tampering | read_ue_graph_node (script_serial loop) | mitigate | PropertyTag 循环使用 archive.tell() < script_end 边界检查 + "None" 终止符检测 |
