```python
def parse_property_value(tag, archive, name_map, export_map, summary=None, depth=0):
    """分派属性值解析（PROP-02 至 PROP-06, ADVP-01 至 ADVP-06）。
    Unknown types return None (per D-05).
    """
    parsers = _get_parse_functions()
    handler = parsers.get(tag.type)
    if handler is None:
        return None  # D-05: unknown type → None, no exception

    # Dispatch based on handler signature
    if tag.type in ("BoolProperty", "IntProperty", "Int64Property", "Int16Property",
                     "Int8Property", "ByteProperty", "FloatProperty", "DoubleProperty",
                     "StrProperty", "ObjectProperty", "TextProperty"):
        return handler(tag, archive)
    elif tag.type in ("NameProperty", "SoftObjectProperty", "DelegateProperty"):
        return handler(tag, archive, name_map)
    elif tag.type in ("ArrayProperty",):
        return handler(tag, archive, name_map, export_map, summary, depth)
    elif tag.type in ("StructProperty",):
        return handler(tag, archive, name_map, export_map, summary, depth)
    elif tag.type in ("MapProperty", "SetProperty"):
        return handler(tag, archive, name_map, export_map, summary)
    elif tag.type in ("EnumProperty",):
        return handler(tag, archive, name_map, summary)

    return None  # Fallback D-05
```

**Function 2: parse_properties_from_export(export, archive, summary, name_map, export_map, import_map=None) -> List[PropertyValue]**
(per source uasset_read.py lines 6007-6158)

Key implementation points:
1. Calculate property_start: if summary.file_version_ue5 >= UE5_SCRIPT_SERIALIZATION_OFFSET, use `export.serial_offset + export.script_serial_offset`, else `export.serial_offset`
2. archive.seek(property_start)
3. Handle SerializationControlExtensions: if summary.file_version_ue5 >= UE5_PROPERTY_TAG_EXTENSION, read serialization_control u8, and if & 0x02, read overridden_operation u8
4. Calculate property_end: if summary.file_version_ue5 >= UE5_SCRIPT_SERIALIZATION_OFFSET, use `export.serial_offset + export.script_serial_size`, else `export.serial_offset + export.serial_size`
5. Loop: while True, check property_count >= MAX_PROPERTY_COUNT → raise ParseError
6. Try block:
   - current_pos = archive.tell(); if current_pos >= property_end: break
   - tag = read_property_tag(archive, name_map, summary.legacy_file_version, summary.file_version_ue5)
   - If tag.name == "None": break
   - Validate tag.size against remaining property data
   - start_pos = archive.tell()
   - value = parse_property_value(tag, archive, name_map, export_map)
   - expected_end = start_pos + tag.size; if archive.tell() != expected_end: archive.seek(expected_end)
   - properties.append(PropertyValue(name=tag.name, type=tag.type, value=value, array_index=tag.array_index))
   - If import_map is not None and tag.type == "ObjectProperty" and isinstance(value, int): resolve and update
7. Except ParseError: smart continue — seek past tag.size, append Warning PropertyValue
