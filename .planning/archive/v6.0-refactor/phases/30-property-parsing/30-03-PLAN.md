**Function 1: extract_blueprint_variables(properties: List[PropertyValue]) -> List[BlueprintVariable]**

Extract blueprint variables from parsed property data. This function:
1. Takes a list of PropertyValue (already parsed from an export via parse_properties_from_export)
2. Identifies properties that represent blueprint variable descriptions
3. Returns a list of BlueprintVariable instances

Implementation approach:
- Iterate through properties looking for variable-related property names
- For each variable property, extract: var_name, var_type (as FEdGraphPinType), category, property_flags, default_value
- Map property flags to boolean attributes (is_edit_anywhere, is_blueprint_read_only, etc.)
- Handle component variables (is_component=True when type suggests a component)
- Use metadata from property names containing "MetaData" or "Category"

The exact extraction logic should follow the source in uasset_read.py lines 1500-1700:
- Look for properties with names like "VariableName", "VariableType", "VariableCategory", "VariableFlags"
- Map property_flags bitmask to individual boolean flags (provide hex values inline, do NOT import from constants.py):
  - CPF_Edit = 0x00000001 → is_edit_anywhere
  - CPF_EditConst = 0x00000002 → is_edit_instance_only
  - CPF_BlueprintVisible = 0x00000004 → is_blueprint_readable
  - CPF_BlueprintReadOnly = 0x00000010 → is_blueprint_read_only
  - CPF_Net = 0x00000020 → is_net / is_replicated
  - CPF_Transient = 0x00000040 → is_transient
  - CPF_BlueprintAssignable = 0x00000100 → is_blueprint_assignable
  - CPF_RepNotify = 0x10000000 → is_rep_notify
  - CPF_SaveGame = 0x02000000 → is_save_game

**Function 2: parse_component_transform(properties: List[PropertyValue]) -> Dict[str, Any]**

Extract component transform properties from parsed property data:
- Look for "RelativeLocation" (VectorProperty → {X, Y, Z})
- Look for "RelativeRotation" (RotatorProperty → {Pitch, Yaw, Roll})
- Look for "RelativeScale3D" (VectorProperty → {X, Y, Z})
- Look for "Mobility" (ENameProperty or ByteProperty)
- Return dictionary with transform components

Implementation:
- Iterate through properties, match by name
- For VectorProperty: extract X, Y, Z from the struct fields
- For RotatorProperty: extract Pitch, Yaw, Roll from the struct fields
- Return structured transform dict

**Function 3: extract_blueprint_metadata(properties: List[PropertyValue], export_map: List[ObjectExport]) -> BlueprintMetadata**

Combine variable extraction and general metadata into a BlueprintMetadata instance:
- is_blueprint: detect from export class name (contains "Blueprint" or "BP_")
- parent_class: extract from properties
- variables: call extract_blueprint_variables(properties)
- functions: empty list for now (Phase 31 will populate)
- events: empty list for now (Phase 31 will populate)

Return BlueprintMetadata with detected variables and empty function/event lists.
