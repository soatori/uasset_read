## Key Changes

### Task 1: read_ue_graph_pin() 完整重写

**序列化顺序变更（UE 源码 EdGraphPin.cpp L1838-1964 验证）：**

旧实现（错误顺序）：
1. PinId (FGuid) - 起始错误
2. PinName (FName)
3. Direction (uint8)
4. PinType
5. DefaultValue
6. AutogeneratedDefaultValue
7. LinkedTo (仅读 PinId)
8. SubPins (仅读 PinId)
9. ParentPin (条件)
10. Flags (u8)

新实现（正确顺序）：
1. **OwningNode (FPackageIndex)** - 序列化起始字段
2. PinId (FGuid 16 bytes)
3. PinName (FName/FString) - 版本依赖
4. [PinFriendlyName] - EditorOnly，跳过
5. [SourceIndex] - 版本依赖
6. **PinToolTip (FString)** - 新增
7. Direction (uint8)
8. PinType (FEdGraphPinType)
9. DefaultValue (FString)
10. AutogeneratedDefaultValue (FString)
11. **DefaultObject (FPackageIndex)** - 新增
12. DefaultTextValue (FText) - 简化处理
13. **LinkedTo (SerializePinArray)** - 使用 read_pin_array()
14. **SubPins (SerializePinArray)** - 使用 read_pin_array()
15. **ParentPin (SerializePin)** - 使用 read_pin_reference()
16. ReferencePassThroughConnection - 位置同步
17. [PersistentGuid] - EditorOnly，跳过
18. **BitField (uint32)** - 新增，解析显示属性

**关键变更详情：**

| 变更 | 需求ID | 说明 |
|------|--------|------|
| OwningNode 首字段 | - | 解决位置错位根因 |
| PinToolTip 解析 | PIN-01 | FString 字段 |
| DefaultObject 解析 | PIN-03 | FPackageIndex 引用 |
| LinkedTo 使用 read_pin_array | PIN-04 | SerializePin 格式 |
| BitField uint32 解析 | PIN-05 | 8 persistent bits |

**版本条件检查：**
- `framework_version >= FFRAMEWORK_VERSION_PINS_STORE_FNAME (20)`: PinName 使用 FName
- `mainstream_version >= FUE5_MAINSTREAM_VERSION_ED_GRAPH_PIN_SOURCE_INDEX (50)`: 读取 SourceIndex

**函数签名变更：**
```python

# 新签名
def read_ue_graph_pin(archive, name_map, summary, export_map, import_map) -> UEdGraphPin
```

**调用点更新：**
