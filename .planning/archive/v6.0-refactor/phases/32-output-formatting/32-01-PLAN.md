### 2. 迁移 `format_json_full` 到 `json_formatter.py`

等价迁移 `format_json_full(result: ParseResult, include_schema: bool = False) -> Dict`：

**输入**: `ParseResult` 对象
**输出**: Dict，字段顺序和结构与旧版一致

关键实现细节：
- summary dict 使用 `result.summary` 的字段直接构建（不依赖 asdict，保持旧版字段名：`version_ue4`, `version_ue5`, `legacy_version`, `package_flags`, `package_name`）
- blueprint_obj 调用 `format_blueprint_dict()` + `format_graphs_json()` 构建
- **D-02 决策**: 移除 `imports`, `soft_references`, `circular_deps` 三个字段的输出。根据决策记录，这些依赖分析字段不属于格式化模块职责。但需在 `format_json_full` 的 docstring 中注明此变更。
- output_version 固定为 `"4.0"`（D-20-05）
- `include_schema=True` 时调用 `build_schema_info()` 添加 `_schema` 字段

**旧版输出字段**:
```python
output = {
    "status": asdict(build_status_info(result)),
    "output_version": "4.0",
    "summary": summary_dict,
    "exports": format_exports_list(result),
    "blueprint": blueprint_obj,
    "graphs_summary": build_graphs_summary(result.graphs),
    "imports": result.imports,              # 移除（D-02）
    "soft_references": result.soft_references,  # 移除（D-02）
    "circular_deps": result.circular_deps,      # 移除（D-02）
    "errors": result.errors
}
```

**新版输出字段**（移除 3 个后）:
```python
output = {
    "status": status_dict,
    "output_version": "4.0",
    "summary": summary_dict,
    "exports": exports_list,
    "blueprint": blueprint_obj,
    "graphs_summary": graphs_summary,
    "errors": result.errors
}
```

### 3. 迁移 `format_exports_list` 到 `json_formatter.py`

等价迁移 `format_exports_list(result: ParseResult) -> List[Dict]`：

每个 export dict 包含：
- `index`: 索引
- `name`: `exp.object_name`
- `class`: 调用 `get_asset_class(exp, result.import_map, result.export_map)` — 此函数需要从旧版迁移到 helpers.py
- `serial_size`: `exp.serial_size`
- `properties`: 调用 `format_properties_list(exp.properties)` 的结果
- `outer_index`: 调用 `resolve_fpackage_index(exp.outer_index, result)` — 此函数需要从旧版迁移到 helpers.py
- `super_index`: 调用 `resolve_fpackage_index(exp.super_index, result)`
- `parent_class`: 从 `result.blueprint.parent_class` 获取（仅蓝图时）

### 4. 迁移 `format_properties_list` 到 `json_formatter.py`

等价迁移 `format_properties_list(properties: List[PropertyTag]) -> List[Dict]`：

每个 property dict 包含：
- `name`: `prop.name`
- `type`: `prop.type`
- `value`: `str(prop.value)` 或 `"null"`

### 5. 迁移 `format_blueprint_dict` 到 `json_formatter.py`

等价迁移 `format_blueprint_dict(blueprint: BlueprintMetadata, blueprint_name: str = None) -> Dict`：

包含：
- `blueprint_name`: 传入的 blueprint_name 参数
- `parent_class`: `blueprint.parent_class`
- `variables`: 使用 `_format_variable_enhanced()` 格式化
- `functions`: 使用 `_format_function_enhanced()` 格式化（Phase 26 增强）
- `events`: 使用 `_format_event_enhanced()` 格式化（Phase 26 增强）
- `detection_warning`: `blueprint.detection_warning`

同时迁移辅助函数：
- `_format_variable_enhanced(variable: BlueprintVariable) -> dict`
- `_format_function_enhanced(function: BlueprintFunction) -> dict`
- `_format_event_enhanced(event: BlueprintEvent) -> dict`
- `_format_parameter(parameter: FunctionParameter) -> dict`

### 6. 迁移 `format_json_summary` 到 `json_formatter.py`

等价迁移 `format_json_summary(result: ParseResult) -> Dict`：

精简输出，仅包含：
- `status`: `asdict(build_status_info(result))`
- `output_version`: `"4.0"`
- `summary`: 精简版（仅 `package_name`, `version_ue4`, `version_ue5`）
- `exports_count`: `len(result.export_map)`
- `is_blueprint`: `result.blueprint.is_blueprint` if result.blueprint else False
- `errors`: `result.errors`
