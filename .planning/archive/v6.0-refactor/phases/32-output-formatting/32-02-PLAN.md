## Action

### 1. 迁移 `format_text_full` 到 `text_formatter.py`

等价迁移 `format_text_full(result: ParseResult) -> str`：

YAML 风格层级输出，结构：
```
Package: {name}
  Version: UE4={v4}, UE5={v5}
  Flags: 0x{flags}
  Imports: {count}
  Exports: {count}

Exports:
  - Name: {name}
    Class: {class}
    SerialSize: {size}
    Properties:
      - Name: {name}
        Type: {type}
        Value: {value}

Blueprint:
  ParentClass: {parent}
  Variables: {count}
  - Name: {name}
    Type: {type}
    Default: {default}
    Category: {category}

Graphs:
  - Name: {name}
    Class: {class}
    Nodes: {count}
    Connections: {count}
    ExecutionFlows: {count}
      - {event}: {node_count} nodes

ERRORS:
  - {error}
```

依赖 helpers.py 中的 `get_asset_class()` 和 `build_connections_map()`、`build_execution_flows()`（从 graph 模块迁移，Phase 31 已实现）。

### 2. 迁移 `format_text_summary` 到 `text_formatter.py`

等价迁移 `format_text_summary(result: ParseResult) -> str`：

精简输出，每个 export 一行：
```
Package: {name}
Exports: {count}

  - {name} ({class})
  - {name} ({class})

Blueprint:
  Parent: {parent}
  Variables: {count}
```

### 3. 迁移 `format_markdown` 到 `markdown_formatter.py`

等价迁移 `format_markdown(result: ParseResult) -> str`：

Markdown 输出包含：
- 标题: `# Asset: {name}`
- Overview 表格: Package, Version, Status
- Blueprint Details 表格（仅当 is_blueprint=True）
- Graph Summary 含 Mermaid 流程图
- Exports 表格

### 4. 抽取 `_build_mermaid_flowchart` 到 `markdown_formatter.py`（D-06, D-07）

从 `format_markdown()` 中抽出 Mermaid 生成为独立函数：

```python
def _build_mermaid_flowchart(execution_flows: List[Dict]) -> List[str]:
    """
    从 execution_flows 生成 Mermaid graph LR 代码。

    Args:
        execution_flows: build_execution_flows() 的返回值

    Returns:
        List[str]: Mermaid 行列表（不含 ``` 围栏）
    """
```

逻辑等价迁移：
- 对每个 flow，提取 `start_event` 和 `calls`
- 第一个节点: `{event} --> {first_call}`
- 链式连接: `{fn1} --> {fn2}`
- 函数名去掉参数部分（取 `calls[i].split("(")[0]`）
