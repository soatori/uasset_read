确保旧版测试能正确导入和使用新版 formatters 模块，验证输出格式等价性。

- `tests/test_output_formatting.py` — 现有输出格式化测试
- `tests/test_phase14_output_formats.py` — Phase 14 输出格式测试

## Action

### 1. 更新 `src/uasset_read/__init__.py` 完整导出

确保 `__init__.py` 导出所有新增的格式化函数，遵循现有扁平导出模式：

需要导出的函数清单：
- `format_json_full`
- `format_json_summary`
- `format_text_full`
- `format_text_summary`
- `format_markdown`
- `format_exports_list`
- `format_properties_list`
- `format_blueprint_dict`
- `build_status_info`
- `build_graphs_summary`
- `build_schema_info`

同时确保 formatters 子模块可通过 `uasset_read.formatters` 访问。

### 2. 修复测试导入路径

检查 `tests/test_output_formatting.py` 和 `tests/test_phase14_output_formats.py` 中是否有直接从 `uasset_read` 导入格式化函数的语句。

如果测试中使用了 `from uasset_read import format_json_full` 等语句，确保这些导入在 `__init__.py` 更新后能正常工作。

如果测试中使用了内部导入如 `from uasset_read.formatters.json_formatter import format_json_full`，确保导入路径正确。

### 3. 验证 ParseResult 输入兼容性

确保 `format_json_full`, `format_text_full`, `format_markdown` 等函数能正确接收 `ParseResult` 对象作为输入。

`ParseResult` 在 `models/result.py` 中定义，包含：
- `summary`: PackageFileSummary
- `export_map`: List[ObjectExport]
- `import_map`: List[ObjectImport]
- `graphs`: List[UEdGraph]
- `blueprint`: BlueprintMetadata
- `errors`: List[str]
- `is_success`: bool

### 4. 运行现有测试

运行输出格式化相关的测试，确认无回归：
```bash
python -m pytest tests/test_output_formatting.py tests/test_phase14_output_formats.py -v
```

### 5. 新旧输出等价性验证

使用同一测试资产验证新旧版本输出格式一致性：
```python
# 使用新版解析 + 格式化
from uasset_read import parse_uasset, format_json_full
result_new = parse_uasset("BP_FirstPersonCharacter.uasset")
output_new = format_json_full(result_new)

# 对比旧版输出（除 D-02 移除的 imports/soft_references/circular_deps 字段）
# 验证核心字段一致性：status, output_version, summary, exports, blueprint, graphs_summary, errors
```

等价性检查点：
- `output_version` 必须为 `"4.0"`
- `summary` 字段结构一致（package_name, version_ue4, version_ue5 等）
- `exports` 列表长度和每个元素结构一致
- `blueprint` 字段结构一致（parent_class, variables, functions, events）
- `graphs_summary` 列表结构和元素一致

注意：D-02 决策移除的 `imports`, `soft_references`, `circular_deps` 字段不参与对比。
