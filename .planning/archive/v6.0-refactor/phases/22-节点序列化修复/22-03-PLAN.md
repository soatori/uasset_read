## Problem Analysis (Root Cause)

### 核心问题：pins offset 计算错误

**当前实现（uasset_read.py:3055-3062）：**
```python
pins_offset = node_export.script_serial_offset + node_export.script_serial_size + 4
archive.seek(node_export.serial_offset + pins_offset)
```

**实际数据验证：**
- `script_serial_offset = 0`（ScriptSerializationStartOffset，相对于 serial_offset）
- `script_serial_size = 9`（ScriptSerializationEndOffset，相对于 serial_offset）
- 当前计算：pins_offset = 0 + 9 + 4 = 13
- **实际 pins 在 offset 96**（距离 tagged properties 结束有 87 bytes）

**问题根源：**
ScriptSerializationEndOffset 之后还有 87 bytes 的其他 UObject 序列化数据（可能包含 GUID、属性引用等），不属于 tagged properties 范围，但属于 UObject 序列化数据的一部分。

### UE 序列化流程分析

**UObject::Serialize (Obj.cpp:1646-1839)：**
1. `SerializeScriptProperties(...)` → tagged properties (0-9 bytes)
2. PossiblySerializeObjectGuid (可能序列化 GUID)
3. 其他数据（transient、sparse class data 等，通常不在 saved 赞产中）

**UEdGraphNode::Serialize (EdGraphNode.cpp:212-263)：**
1. `Super::Serialize(Ar)` → UObject::Serialize (包含 tagged properties + 其他 UObject 数据)
2. `UEdGraphPin::SerializeAsOwningNode(Ar, Pins)` → Pins array

**关键发现：**
- ScriptSerializationStartOffset/EndOffset 只标记 SerializeTaggedProperties 的范围
- UObject 序列化数据在 EndOffset 之后可能还有其他字段
- Pins array 在 UObject 序列化数据完全结束后才开始

### SerializePin 格式验证

**EdGraphPin.cpp:2132-2223 完整格式（EPinResolveType::OwningNode）：**

1. **SerializePin 前置字段：**
   - `bNullPtr` (bool → i32, 4 bytes) - 总是 false 对于 OwningNode
   - `OwningNode_1` (FPackageIndex, 4 bytes) - 节点自身引用
   - `PinGuid_1` (FGuid, 16 bytes) - Pin ID

2. **UEdGraphPin::Serialize 字段 (1838-1949)：**
   - `OwningNode_2` (FPackageIndex, 4 bytes) - **重复！**
   - `PinId_2` (FGuid, 16 bytes) - **重复！**
   - `PinName` (FName, 8 bytes) - version dependent
   - `[PinFriendlyName]` (FText) - EditorOnly，已确认不存在
   - `[SourceIndex]` (i32) - version dependent
   - `PinToolTip` (FString)
   - `Direction` (uint8)
   - `PinType` (FEdGraphPinType)
   - `DefaultValue` (FString)
   - `AutogeneratedDefaultValue` (FString)
   - `DefaultObject` (FPackageIndex)
   - `DefaultTextValue` (FText)
   - `LinkedTo` (SerializePinArray)
   - `SubPins` (SerializePinArray)
   - `ParentPin` (SerializePin)
   - `ReferencePassThroughConnection` (SerializePin)
   - `[PersistentGuid]` (FGuid) - EditorOnly
   - `[BitField]` (uint32) - EditorOnly

**当前实现跳过的字段：**
- `bNullPtr` (4 bytes) ✓ 正确
- `OwningNode_1` (4 bytes) ✓ 正确
- `PinGuid_1` (16 bytes) ✓ 正确

**但 read_ue_graph_pin 再次读取：**
- `OwningNode_2` (4 bytes) ✓ 正确（重复字段）
- `PinId_2` (16 bytes) ✓ 正确（重复字段）
