- 验证 array_count >= 0，拒绝负值
- 验证 array_count <= MAX_LINKEDTO_PER_PIN (100)，拒绝过大的值
- 如果验证失败，抛出 ParseError

**T-22-09-03 (Injection - read_ue_graph_pin)**:
- 验证 pins_count >= 0，拒绝负值

- 调试输出不包含敏感信息（仅包含解析状态和字段值）
