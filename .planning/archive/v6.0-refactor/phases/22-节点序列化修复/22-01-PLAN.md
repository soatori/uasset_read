# Phase 22 Plan 01: 修复节点序列化解析

## Objective

修复 `read_ue_graph_node` 未正确跳过 UObject 基类序列化数据的问题，使 TEST-02/03/04 通过验证。

## Problem Analysis

**根因（from Phase 21 VERIFICATION.md ISSUE-01）:**
- 当前 `read_ue_graph_node` 直接定位到 `serial_offset` 并立即读取 `pins_count`
- 但 UE 序列化顺序为：UObject::Serialize() → UEdGraphNode properties → Pins array
- UObject::Serialize() 调用 SerializeScriptProperties，序列化所有 UPROPERTY 字段
- UEdGraphNode 有多个 UPROPERTY（NodeComment, NodePosX, NodePosY 等）
- Pins array 来自 SerializeAsOwningNode，在 Super::Serialize() 之后执行

**UE 源码关键证据（EdGraphNode.cpp:212-263）:**
```cpp
void UEdGraphNode::Serialize(FArchive& Ar)
{
    Ar.UsingCustomVersion(FBlueprintsObjectVersion::GUID);
    Super::Serialize(Ar);  // 序列化 UEdGraphNode 的 UPROPERTY 字段
    // ... PostLoad 处理 ...
    if (Ar.CustomVer(...) >= FBlueprintsObjectVersion::EdGraphPinOptimized)
    {
        UEdGraphPin::SerializeAsOwningNode(Ar, Pins);  // Pins array
    }
}
```

**Tagged Properties 格式（Class.cpp:1615-1698）:**
- 可能以 SerializationControlExtensions byte 开始（UE5 >= PROPERTY_TAG_EXTENSION_AND_OVERRIDABLE_SERIALIZATION）
- 循环 PropertyTag + Value 直到 Name == "None"
- PropertyTag 格式：Name (FName) + Type (string) + Size (i32) + Flags (u8) + [条件字段]

在 `read_ue_graph_node` 之前添加辅助函数：

```python
def skip_ue_object_properties(
    archive: FArchive,
    name_map: List[str],
    summary: PackageFileSummary
) -> int:
    """
    跳过 UObject tagged properties，返回跳过的字节数。
    
    格式（UE5 >= PROPERTY_TAG_EXTENSION_AND_OVERRIDABLE_SERIALIZATION）：
    1. SerializationControlExtensions byte（可选）
    2. PropertyTag 循环直到 Name == "None"
    
    Returns:
        跳过的字节数（从调用位置到 Pins array 开始）
    """
    start_pos = archive.tell()
    
    # 1. SerializationControlExtensions（UE5.7 版本检查）
    if summary.file_version_ue5 >= 1003:  # PROPERTY_TAG_EXTENSION_AND_OVERRIDABLE_SERIALIZATION
        serialization_control = archive.read_u8()
        # 如果有 OverridableSerializationInformation (0x02)
        if serialization_control & 0x02:
            override_operation = archive.read_u8()  # EOverriddenPropertyOperation
    
    # 2. PropertyTag 循环（直到 Name == "None")
    property_count = 0
    while property_count < MAX_PROPERTY_COUNT:
        property_count += 1
        
        tag = read_property_tag(
            archive,
            name_map,
            summary.legacy_file_version,
            summary.file_version_ue5
        )
        
        if tag.name == "None":
            break
        
        # 跳过属性值数据（tag.size bytes）
        archive.seek(archive.tell() + tag.size)
    
    return archive.tell() - start_pos
```

修改要点：
- 使用已有的 `read_property_tag` 函数
- 处理 SerializationControlExtensions byte（UE5 >= 1003）
- 循环直到 Name == "None"
- 跳过每个属性值（tag.size bytes）
</action>
