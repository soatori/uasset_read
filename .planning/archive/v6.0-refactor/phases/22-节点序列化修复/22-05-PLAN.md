# Phase 22 Plan 05: 动态扫描定位 pins_offset

## Objective

通过动态扫描方案替代 heuristic_delta，准确定位 pins 数组的起始位置，解决 TEST-02/03 失败问题。

**Purpose:** 解决 heuristic_delta 方案对部分节点类型不准确的问题。
**Output:** PinCategory/PinSubCategory 解析为正确值，TEST-02/03 通过。

## Problem Analysis (Root Cause)

### 核心问题：heuristic_delta 方案不准确

**当前实现（uasset_read.py:3083-3088）：**
```python
if node_export.script_serial_size <= 20:
    heuristic_delta = 87  # EnhancedInputActionEvent pattern
else:
    heuristic_delta = 4   # CallFunction pattern

pins_offset = node_export.script_serial_offset + node_export.script_size + heuristic_delta
```

**实际数据验证（从 22-04-SUMMARY.md）：**
- PinCategory 解析为 `/Game/FirstPerson/Blueprints/BP_FirstPersonCharacter_4294967295`
- 应为 "exec" 或其他类型名
- archive 在读取 pin_type 时位置错误，导致 FName 索引读取垃圾值

**根因：**
- heuristic_delta 的两个分支（87 vs 4）都不适用于某些节点类型
- 不同节点类型的 UObject 序列化数据长度不同
- 固定 delta 无法覆盖所有情况

### 解决方案：动态扫描

通过扫描 archive 数据，找到符合 pins_count pattern 的位置：
1. pins_count 是合理值（1-20）
2. 后续数据符合 SerializePin 格式（bNullPtr == 0）

```python
def read_ue_graph_node(...):
    # 定位到节点序列化数据起始位置
    archive.seek(node_export.serial_offset)

    # Phase 22 FIX-06: 动态扫描定位 pins offset
    #
    # 替代 heuristic_delta 方案，通过扫描找到正确的 pins 起始位置
    # Pattern: pins_count (1-20) + bNullPtr (0) + OwningNode + PinGuid

    # 安全扫描范围：从 script_serial_size 结束位置开始，最多扫描 200 bytes
    scan_start = node_export.serial_offset + node_export.script_serial_offset + node_export.script_serial_size
    scan_end = min(scan_start + 200, node_export.serial_offset + node_export.serial_size)

    archive.seek(scan_start)
    pins_found = False
    pins_offset = scan_start

    while archive.tell() < scan_end:
        try:
            test_pos = archive.tell()
            test_count = archive.read_i32()

            # 验证 pins_count 合理范围
            if 1 <= test_count <= 20:  # 合理的 pins 数量
                # 验证后续数据符合 SerializePin 格式
                test_null = archive.read_i32()  # bNullPtr

                if test_null == 0:  # bNullPtr == 0 表示有效 pin
                    # 验证 OwningNode 是合理的 FPackageIndex
                    test_owning = archive.read_i32()
                    owning_pkg = PackageIndex(test_owning)

                    # OwningNode 应该指向自身（节点导出索引）
                    # 或者是 import/export 引用（合理范围）
                    if owning_pkg.is_import or owning_pkg.is_export or test_owning == 0:
                        # 验证通过，这是 pins 的起始位置
                        pins_offset = test_pos
                        pins_found = True
                        break

            # 继续扫描下一个位置（每次移动 4 bytes）
            archive.seek(test_pos + 4)

        except Exception:
            # 读取失败，继续扫描
            archive.seek(test_pos + 4)
            continue

    if not pins_found:
        # 扫描失败，使用 fallback heuristic
        # 保持原有逻辑作为安全 fallback
        if node_export.script_serial_size <= 20:
            pins_offset = scan_start + 87
        else:
            pins_offset = scan_start + 4

    archive.seek(pins_offset)

    # 1. Pins 数组
    pins_count = archive.read_i32()
    ...
```

**关键改进：**
1. 动态扫描而非固定 delta
2. 验证 pins_count 合理范围（1-20）
3. 验证 SerializePin 前置字段格式（bNullPtr == 0）
4. 验证 OwningNode 是合理的 FPackageIndex
5. 安全 fallback 保留原有 heuristic
