## 修复成果

### 关键发现

**pins offset 规律：**
- EnhancedInputActionEvent 节点：delta = 87 bytes（UObject 其他数据）
- CallFunction 节点：delta = 4 bytes（少量 UObject 数据）
- delta 代表 UObject::Serialize 在 SerializeScriptProperties 之后的其他数据
  （PossiblySerializeObjectGuid 等，见 Obj.cpp:1810）

**版本检查问题：**
- FBlueprintsObjectVersion CustomVersion 不存在（返回 -1）
- 导致错误的版本判断，使用 FString format 而非 FName format
- UE5.7 资产需要使用 file_version_ue5 作为 fallback 判断

### 代码修改

1. **read_ue_graph_node pins offset 计算** (行 3068-3086)
   - 实现 heuristic_delta 方案：基于 script_serial_size 判断
   - script_serial_size <= 20: delta = 87 (EnhancedInputActionEvent)
   - script_serial_size > 20: delta = 4 (CallFunction)

2. **read_ue_graph_pin 版本检查修复** (行 2908-2920)
   - 添加智能版本判断：CustomVersion >= threshold OR file_version_ue5 > 0
   - UE5 资产始终使用 FName format

3. **read_ed_graph_pin_type 版本检查修复** (行 2614-2632)
   - 同样的智能版本判断
   - 确保 PinCategory/PinSubCategory 使用正确格式

## 关键发现

### UE 序列化流程（确认）

```
UObject::Serialize():
  1. SerializeScriptProperties(...) → tagged properties
  2. PossiblySerializeObjectGuid(...) → UObject 其他数据
  3. 其他数据（transient、sparse class data 等）

UEdGraphNode::Serialize():
  1. Super::Serialize(Ar) → UObject::Serialize
  2. UEdGraphPin::SerializeAsOwningNode(Ar, Pins) → Pins array

UEdGraphPin::Serialize (完整格式):
  1. OwningNode (FPackageIndex)
  2. PinId (FGuid)
  3. PinName (FName/FString) - 版本依赖
  4. [PinFriendlyName] (FText) - EditorOnly
  5. [SourceIndex] (i32) - 版本依赖
  6. PinToolTip (FString)
  7. Direction (uint8)
  8. PinType (FEdGraphPinType)
  9. DefaultValue (FString)
  10. AutogeneratedDefaultValue (FString)
  11. DefaultObject (FPackageIndex)
  12. DefaultTextValue (FText)
  13. LinkedTo (SerializePinArray)
  14. SubPins (SerializePinArray)
  15. ParentPin (SerializePin)
  16. ReferencePassThroughConnection (SerializePin)
  17. [PersistentGuid] (FGuid) - EditorOnly
  18. [BitField] (uint32) - EditorOnly
```

### UE5.7 版本系统变化

- FBlueprintsObjectVersion CustomVersion 可能不存在
- file_version_ue5 = 1017 可作为可靠判断依据
- 需要 fallback 机制处理 CustomVersion 缺失情况
