# Plan 11-03: 新增SoftObjectProperty解析器

**Objective:** 支持SoftObjectProperty类型解析，提取组件引用如SkeletalMesh、AnimBlueprint等

## Context

UE5组件引用（如SkeletalMeshComponent的SkeletalMesh属性）使用SoftObjectProperty类型，序列化为FSoftObjectPath（AssetPath + SubPath）。现有parse_property_value()不支持此类型，返回None。

**Goal:** 新增SoftObjectProperty解析器返回`{"asset_path": "/Game/...", "sub_path": "..."}`

## Truths

- SoftObjectProperty序列化格式：FString（AssetPath）+ FString（SubPath）
- UE5标准格式，参考UE源码SoftObjectPath.h
- 需注册到parse_property_value()类型分派表

```python
def parse_soft_object_property(
    tag: PropertyTag,
    archive: FArchive,
    name_map: List[str]
) -> Dict[str, str]:
    """
    解析SoftObjectProperty（FSoftObjectPath）。
    
    UE5格式：
    - AssetPath: FString（如 "/Game/Characters/Mannequin/Animations/Walk")
    - SubPath: FString（如 "" 空字符串表示无子路径，或"SubObject.Path")
    
    Args:
        tag: PropertyTag（包含属性名和类型）
        archive: FArchive二进制读取器
        name_map: NameMap列表
    
    Returns:
        {"asset_path": str, "sub_path": str}
    """
    asset_path = archive.read_fstring()
    sub_path = archive.read_fstring()
    
    return {
        "asset_path": asset_path,
        "sub_path": sub_path
    }
```
