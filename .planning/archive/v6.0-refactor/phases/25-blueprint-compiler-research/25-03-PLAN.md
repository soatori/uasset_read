### 2. 节点到 C++ 映射

**K2Node_CallFunction → C++ 函数调用**:
```cpp
// 蓝图
CallFunction(MemberName="Jump", bSelfContext=True)

// C++
Jump();
```

**K2Node_Event → C++ 事件**:
```cpp
// 蓝图
Event(MemberName="BeginPlay", bOverrideFunction=True)

// C++
virtual void BeginPlay() override;
```

**K2Node_VariableGet → 变量读取**:
```cpp
// 蓝图
VariableGet(MemberName="Health")

// C++
float Health = this->Health;
```

**K2Node_VariableSet → 变量赋值**:
```cpp
// 蓝图
VariableSet(MemberName="Health", Value=100.0f)

// C++
this->Health = 100.0f;
```
