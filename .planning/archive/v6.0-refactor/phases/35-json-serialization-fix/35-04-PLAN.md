# Blueprint 资产元数据属性名称（不是用户定义的变量）
BLUEPRINT_METADATA_PROPERTY_NAMES = frozenset({

在 `extract_blueprint_variables` 的 for 循环中（L154 之后），在 prop_name 获取后立即添加跳过检查：

```python
for prop in properties:
    prop_name = prop.name
    prop_value = prop.value

    # 跳过终止标记、系统属性和蓝图元数据属性
    if prop_name in BLUEPRINT_METADATA_PROPERTY_NAMES:
        continue
```

**不要**修改 `extract_blueprint_metadata` 或 `parse_component_transform` 中的逻辑——它们依赖所有 properties（包括元数据属性）来正确工作。过滤仅在变量提取层面进行。
