### 任务 2：配置pyproject.toml（零依赖、src layout）

<read_first>
- .planning/research/STACK.md — pyproject.toml配置示例（零依赖、src layout）
- .planning/phases/27-project-structure-init/27-CONTEXT.md — D-04/D-05/D-06/D-07决策
</read_first>

<action>
创建pyproject.toml文件，配置零依赖、src layout、项目元数据（per D-04/D-05/D-06/D-07）：

1. **创建pyproject.toml**（如果不存在则创建，存在则覆盖）：
   ```toml
   [build-system]
   requires = ["setuptools>=61.0", "wheel"]
   build-backend = "setuptools.build_meta"

   [project]
   name = "uasset_read"
   version = "5.1.0"  # per D-07
   description = "Unreal Engine .uasset file parser for AI agents"
   readme = "README.md"
   requires-python = ">=3.10"
   dependencies = []  # per D-04: 零依赖
   authors = [
       {name = "uasset_read Contributors"}
   ]
   license = {text = "MIT"}
   keywords = ["unreal", "uasset", "parser", "blueprint", "ue5"]
   classifiers = [
       "Development Status :: 5 - Production/Stable",
       "Intended Audience :: Developers",
       "License :: OSI Approved :: MIT License",
       "Programming Language :: Python :: 3",
       "Programming Language :: Python :: 3.10",
       "Programming Language :: Python :: 3.11",
       "Programming Language :: Python :: 3.12",
       "Topic :: Software Development :: Libraries",
   ]

   [project.optional-dependencies]
   # per D-05: 可选开发依赖
   dev = [
       "pytest>=7.0",
       "pytest-cov>=4.0",
   ]

   [project.scripts]
   # per D-06: 保留CLI入口配置（Phase 28+实现）
   uasset-read = "uasset_read.cli:main"

   [tool.setuptools]
   package-dir = {"" = "src"}  # src layout per D-02

   [tool.setuptools.packages.find]
   where = ["src"]

   [tool.pytest.ini_options]
   testpaths = ["tests"]
   python_files = ["test_*.py"]
   python_classes = ["Test*"]
   python_functions = ["test_*"]
   ```

2. **验证配置**：
   - dependencies = [] 确保零依赖（per D-04）
   - dev可选依赖包含pytest（per D-05）
   - [project.scripts]配置CLI入口（per D-06）
   - version = "5.1.0"（per D-07）
   - package-dir配置src layout（per D-02）

3. **为什么这个配置**：
   - 零依赖：仅使用Python标准库，减少环境配置复杂度
   - src layout：防止意外导入本地源码，测试环境一致
   - 版本5.1.0：与v5.1里程碑对应，语义化版本
   - 可选dev依赖：支持pytest开发测试环境
   - CLI入口配置：为Phase 28+实现CLI模块准备
</action>
