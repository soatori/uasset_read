## Bug Fixes Found During Testing

- **`ue5_mode` parameter bug** (graph.py:486, 283): `read_ftext_with_history` called with `ue5_mode=...` but function doesn't accept that parameter. Caused TypeError → except swallowed → 5-byte position misalignment → linked_to array read wrong bytes. Fixed by removing invalid parameter. This was a pre-existing bug unrelated to Phase 44.

- **PackageIndex.object_name access bug** (object_resources.py:551, 554): `resolve_package_index_to_reference` was calling `get_asset_class_with_linker(exp, None, import_map, export_map, name_map)` with 5 arguments but the function only accepts 2. Also tried accessing `PackageIndex.object_name` which doesn't exist. Fixed by using `get_asset_class(exp, import_map, export_map)` and properly resolving outer_name from export_map. This was a Phase 43 pre-existing bug that blocked Phase 44's smoke test.

- **get_asset_class_with_linker call mismatch** (object_resources.py:551): The function `get_asset_class_with_linker` is designed to work with a linker, but `resolve_package_index_to_reference` is a fallback when linker is not available. Fixed by using `get_asset_class` instead, which works with raw maps.
