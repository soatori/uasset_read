**Function signature (per D-04):**
```python
def parse_uasset_with_linker(
    path: str,
    tolerant: bool = True,
    preload_all: bool = False,
) -> "LinkerParseResult":
```

**Implementation flow:**

1. **Initialize result:** Create `result = LinkerParseResult()`
2. **Open archive:** `archive = FArchive(path, tolerant=tolerant)` wrapped in try block
3. **Extract mmap info:** Set `result.mmap_used` and `result.mmap_warning` from `archive.get_mmap_info()`
4. **Read file header:** Call read_package_summary, read_name_table, read_import_map, read_export_map — assign to result fields
5. **Parse export properties with tolerant mode:**
   - Iterate result.export_map; for each with serial_size > 0:
   - try: `parse_properties_from_export()` → set `export.properties`
   - except: append error to `result.errors`, set `export.properties = []`
   - If properties exist: `export.transforms = extract_component_transforms(export.properties)`
6. **Create and run linker:**
   - `linker = PackageLinker(archive, result.summary, result.name_map, result.import_map, result.export_map)`
   - `linker.link()`
   - `result.linker = linker`
   - `result.all_objects = linker._import_objects + linker._export_objects` (per D-01, LinkerParseResult carries the object graph)
   - `result.root_objects = linker._root_objects`
7. **Optional preload_all:**
   - If `preload_all is True`: iterate `range(len(linker._export_objects))` and call `linker.preload(i)` for each
8. **Call shared post-processing:**
   - `_post_process(path, archive, result.summary, result.name_map, result.import_map, result.export_map, result, tolerant)`
9. **Set is_success:**
   - `result.is_success = len(result.errors) == 0` (note: _post_process also sets this, but it's safe to set again)

**Error handling (per D-02):**
- Wrap entire function body in try/except matching parse_uasset() pattern:
  - `VersionError` → append to result.errors, set is_success=False
  - `ParseError` with partial_result → append to errors, apply partial_result to result if applicable
  - `Exception` → append f"Unexpected error: {e}" to result.errors
- finally: `archive.close()` if archive exists
- Linker errors during link() or preload() are caught by the outer Exception handler → collected into result.errors (tolerant mode)

**Key difference from parse_uasset():**
- parse_uasset() sets is_success AFTER _post_process() — but _post_process() now sets it too
- parse_uasset_with_linker() sets is_success AFTER _post_process() to ensure final state is correct
- The outer except handlers set is_success=False for early failures (before _post_process runs)
