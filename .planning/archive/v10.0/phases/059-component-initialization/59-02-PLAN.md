**`format_cpp_default_value(value: Any, cpp_type: str) -> str`：**

根据 cpp_type 格式化 value 为 C++ 字面量。格式化规则（来自 D-59-03）：

| cpp_type | 格式化规则 | 示例 |
|----------|-----------|------|
| `float` | `{value}f` | `55.f`, `400.0f` |
| `double` | `{value}` 无后缀 | `96.0` |
| `bool` | `true` / `false` | `true` |
| `int32`/`int`/`int64` | 无后缀整数 | `1500` |
| `FString`/`FName` | `TEXT("value")` | `TEXT("value")` |
| `FText` | `FText::FromString("value")` | `FText::FromString("hello")` |
| `uint8`/`byte` | 无后缀 | `255` |
| `E*` (枚举) | 直接使用值 | `EFirstPersonPrimitiveType::FirstPerson` |
| 其他 | `str(value)` | 直接返回 |

实现要点：
- float 类型：使用 `f"{float(value):g}f"` — `:g` 去掉多余零（55.0→55, 400.12→400.12），然后加 f 后缀。但需要注意 55 → `55f` 而非 `55.0f`（UE 约定中 `55.f` 更常见）。推荐：如果值是整数，用 `f"{int(value)}.f"`；如果有小数部分，用 `f"{float(value)}f"`
- bool 类型：检查 value 是否为 True/True/1/"true" 等，返回 "true" 或 "false"
- 字符串类型：使用 `html.escape` 或简单替换 `"` → `\"` 防止注入（与 cpp_header_formatter._format_default_value 模式一致）
- 枚举类型：cpp_type 以 `E` 开头的，直接返回 str(value)（假设值已经是完整枚举路径）

此函数是 Plan 03 的构造函数格式化器的工具函数，需要导出。

**`format_cpp_transform(transforms: Dict[str, Any], component_name: str) -> List[str]`：**

从组件的 transforms 字典生成 C++ transform 赋值语句。Per D-59-06：

- 如果同时有 `relative_location`（VectorValue）和 `relative_rotation`（RotatorValue）：
  - 生成 `SetRelativeLocationAndRotation(FVector(x, y, z), FRotator(pitch, yaw, roll))`
  - 组合调用优先于分离调用（UE 惯例）
- 如果只有 `relative_location`：
  - 生成 `SetRelativeLocation(FVector(x, y, z))`
- 如果只有 `relative_rotation`：
  - 生成 `SetRelativeRotation(FRotator(pitch, yaw, roll))`
- 如果有 `relative_scale`（ScaleValue）：
  - 生成 `SetRelativeScale3D(FVector(sx, sy, sz))`

返回值：`List[str]`，每条 C++ 语句一个字符串。

格式化细节：
- FVector 参数：使用 `f"{val}f"` 格式化 float 值（55.f 格式）
- FRotator 参数顺序：`(pitch, yaw, roll)` — UE FRotator 构造函数按此顺序
- 多行格式化时，使用缩进和对齐：
  ```cpp
  FirstPersonCameraComponent->SetRelativeLocationAndRotation(
      FVector(-2.8f, 5.89f, 0.0f),
      FRotator(0.0f, 90.0f, -90.0f)
  );
  ```

**`format_cpp_component_init(component_name: str, cpp_type: str, transforms: Optional[Dict] = None, properties: Optional[Dict] = None) -> List[str]`：**

为单个组件生成完整的初始化代码块（创建 + attach + transform + 属性赋值）。

参数：
- `component_name`: 变量名
- `cpp_type`: 去指针的 C++ 类型名
- `transforms`: 来自 extract_components 的 transforms 字典（如果有）
- `properties`: 来自 extract_components 的 properties 字典（标量属性）

返回：`List[str]`，包含：
1. `ComponentName = CreateDefaultSubobject<Type>(TEXT("ComponentName"));`
2. 如果有 transform：transform 赋值语句
3. 如果有 properties：`ComponentName->PropertyName = value;` 语句

**`format_cpp_input_action_load(variable_name: str, asset_path: str) -> str`：**

D-59-06 补充：InputAction 变量使用 LoadObject 而非 CreateDefaultSubobject。

返回：`{variable_name} = LoadObject<UInputAction>(nullptr, TEXT("{asset_path}"));`

如果 asset_path 为空或 None，返回空字符串（跳过）。
