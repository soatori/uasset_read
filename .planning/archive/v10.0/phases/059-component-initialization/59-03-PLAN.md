**`build_constructor_sections(ir: CppClassIR) -> Dict[str, List[str]]`：**

将 constructor 字典中的三个列表分类为有注释的代码段：

```python
{
    "creation": [...],     # Component creation 段
    "attach": [...],       # Setup attachments 段
    "transform": [...],    # Transform assignments 段
    "property": [...],     # Property assignments 段
    "load_object": [...],  # InputAction LoadObject 段 (Blocker 1 fix)
}
```

逻辑：

1. **creation 段**：遍历 `ir.constructor["component_creations"]`，对每个 CppComponentCreation 生成：
   `{name} = CreateDefaultSubobject<{cpp_type}>(TEXT("{component_name}"));`

2. **attach 段**：遍历 `ir.constructor["component_assignments"]`，对每个 CppComponentAssignment 生成：
   - 如果有 socket_name：`{child_name}->SetupAttachment({parent_name}, FName("{socket_name}"));`
   - 如果无 socket_name：`{child_name}->SetupAttachment({parent_name});`

3. **transform 段**（Blocker 2 fix）：遍历 `ir.constructor["default_values"]`，筛选 `is_method_call=True` 且 `method_type="transform"` 的条目：
   - 对每个这样的条目，调用 `format_cpp_transform(entry.value, entry.target)` 生成：
     `{component_name}->SetRelativeLocationAndRotation(FVector(...), FRotator(...));`
   - `format_cpp_transform` 来自 Plan 02 的 `cpp_default_value_formatter.py`

4. **property 段**：遍历 `ir.constructor["default_values"]`，对每个 CppDefaultValue 满足 `is_method_call=False` 且 `needs_load_object=False`：
   - 生成 `{target} = {value};`
   - 其中 value 使用 `format_cpp_default_value(value, cpp_type)` 格式化

5. **load_object 段**（Blocker 1 fix）：遍历 `ir.constructor["default_values"]`，筛选 `needs_load_object=True` 的条目：
   - 对每个这样的条目，调用 `format_cpp_input_action_load(entry.target, entry.value)` 生成：
     `{variable_name} = LoadObject<UInputAction>(nullptr, TEXT("{asset_path}"));`
   - `format_cpp_input_action_load` 来自 Plan 02 的 `cpp_default_value_formatter.py`

**`format_cpp_constructor(ir: CppClassIR, components: List[Dict] = None) -> str`：**

组装完整构造函数文本：

```
ClassName::ClassName()
    : Super::ParentClass()
{
    // Component creation
    ...

    // Setup attachments
    ...

    // Transform assignments
    ...

    // Property assignments
    ...

    // InputAction loads (if any)
    ...
}
```

实现要点：
- 函数签名：`ClassName::ClassName()`
- 初始化列表：`    : Super::ClassName()`（**无条件使用** `Super::ClassName()`，D-59-05 规定，**不是** `Super()`）
- 每个代码段之间空一行
- 如果某段为空（无内容），跳过该段（不输出空注释）
- 使用 4 空格缩进
- 组件创建排序：父组件在前，子组件在后。如果 `component_assignments` 中存在 attach 关系，按拓扑排序排列 creation 顺序（被 attach 的组件先创建）
- `load_object` 段放在 property 段之后（如果存在 needs_load_object=True 的条目）

**`format_cpp_component_init` vs `build_constructor_sections` 说明（Warning 3）：**
- `format_cpp_component_init`（Plan 02 的 `cpp_default_value_formatter.py`）是**独立的便捷函数**，用于直接为单个组件生成初始化代码块（创建 + attach + transform + 属性）。适合单元测试和独立使用。
- `build_constructor_sections`（本模块）是**主要的 IR 驱动构造函数生成路径**，消费完整的 CppClassIR 和 constructor 字典，生成完整构造函数。它**不**调用 `format_cpp_component_init`；而是分别调用 `format_cpp_default_value`、`format_cpp_transform`、`format_cpp_input_action_load` 等底层格式化器。
- 两者用途不同，不冗余：一个是组件级工具函数，一个是类级 IR 驱动生成器。
