创建新模块 `cpp_constructor_ir_builder.py`，包含三个数据模型和对应的构建函数。

**数据模型（dataclass）：**

1. `CppComponentCreation` — CreateDefaultSubobject 调用：
   - `variable_name: str` — 变量名（如 "FirstPersonMesh"）
   - `cpp_type: str` — 去指针的 C++ 类型（如 "USkeletalMeshComponent"）
   - `component_name: str` — TEXT() 参数（如 "FirstPersonMesh"）

2. `CppComponentAssignment` — SetupAttachment 调用：
   - `child_name: str` — 子组件变量名
   - `parent_name: str` — 父组件变量名（如 "FirstPersonMesh" 或 "RootComponent"）
   - `socket_name: str` — 插槽名（可为空字符串 ""）

3. `CppDefaultValue` — 属性赋值：
   - `target: str` — 赋值目标（如 "FirstPersonCameraComponent->bUsePawnControlRotation" 或 "TargetArmLength"）
   - `value: str` — 格式化后的值字符串（如 "400.0f", "true", "TEXT(\"value\")"）
   - `cpp_type: str` — C++ 类型（如 "float", "bool", "FString"）
   - `is_method_call: bool` — 是否为方法调用式赋值（如 `GetCapsuleComponent()->InitCapsuleSize(55.f, 96.0f)`）
   - `method_type: str = ""` — 方法调用类型分类（如 "transform" 表示 transform 赋值，空字符串表示普通属性赋值）
   - `needs_load_object: bool = False` — 是否需要 LoadObject 加载（D-59-06 补充：UInputAction* 变量标记为 True）

**构建函数：**

`build_component_creations(ir: CppClassIR) -> List[CppComponentCreation]`：
- 遍历 `ir.properties`，筛选 `category == "component"`
- 从 `prop.cpp_type` 去掉尾部的 `*` 获取模板类型
- 使用 `prop.name` 作为变量名和组件名称
- **特殊处理 InputAction**（D-59-06 补充）：检测 `prop.cpp_type` 是否为 `"UInputAction*"` — 如果是，**不**生成 CreateDefaultSubobject，而是跳过（标记为 `skip=True` 或不在 creations 中），因为 InputAction 通常作为数据资产存在
- 返回 `List[CppComponentCreation]`

关键逻辑示例：
```python
def build_component_creations(ir: CppClassIR) -> List[CppComponentCreation]:
    creations = []
    for prop in ir.properties:
        if prop.category != "component":
            continue
        # D-59-06: InputAction 特殊处理 — 跳过 CreateDefaultSubobject
        if prop.cpp_type == "UInputAction*":
            continue
        cpp_type = prop.cpp_type.rstrip("*").strip()
        creations.append(CppComponentCreation(
            variable_name=prop.name,
            cpp_type=cpp_type,
            component_name=prop.name,
        ))
    return creations
```

在同一模块中追加三个构建函数。

**`build_component_assignments(components: List[Dict]) -> List[CppComponentAssignment]`：**

- 遍历 `components` 列表（来自 `extract_components` 的输出）
- 每个 component 字典检查是否存在 `attach_parent` 或 `AttachParent` 字段
- 如果存在 attach_parent：
  - `child_name` = component 的 `name`
  - `parent_name` = `attach_parent`（如果 parent 是组件名，直接使用；如果是 "Root" 或 "RootComponent"，映射为 "RootComponent"）
  - `socket_name` = 从 `attach_socket_name` 或 `AttachSocketName` 提取（如 "head"），不存在则为空字符串
- 如果不存在 attach_parent，跳过该组件（无 attach 关系）
- 返回 `List[CppComponentAssignment]`

**已知前提（Warning 2）**：当前 `extract_components` 返回的字典**不包含** `attach_parent` 或 `attach_socket_name` 字段。需要在函数中检查组件 properties 中是否有 `AttachParent` 或 `attach_parent` 键。如果有，使用它；否则返回空列表。此数据需要通过扩展 `extract_components` 或从 linker 的组件树中获取。

**`build_default_values(ir: CppClassIR, blueprint_vars: Optional[List[BlueprintVariable]] = None) -> List[CppDefaultValue]`：**

- 遍历 `ir.properties` 中 `category == "variable"` 的条目
- 对于每个变量属性：
  - 如果 `prop.cpp_type == "UInputAction*"`（D-59-06 补充 — Blocker 1 fix）：
    - 检查 `prop.default_value` 是否为非空路径字符串
    - 如果是，创建 `CppDefaultValue(target=prop.name, value=prop.default_value, cpp_type=prop.cpp_type, needs_load_object=True)` — 标记为需要 LoadObject 加载
    - 如果 default_value 为空，跳过（读者需要自行配置 InputAction 资产路径）
  - 如果 `prop.default_value` 为 None 且不是 InputAction 类型，跳过
  - 否则创建 `CppDefaultValue`：
    - `target` = `prop.name`
    - `cpp_type` = `prop.cpp_type`
    - `value` = 暂存为 `str(prop.default_value)`（**不在此处格式化**，格式化由 Plan 02 的 formatter 负责）
    - `needs_load_object` = False（非 InputAction 变量）
- 如果提供了 `blueprint_vars` 参数，也从其中提取 `is_component=False` 的变量，使用 `var.default_value` 和从 `var.var_type` 推导的 cpp_type
- 返回 `List[CppDefaultValue]`

**`build_transform_assignments(ir: CppClassIR, components: List[Dict]) -> List[CppDefaultValue]`：**（Blocker 2 fix — transform 数据流入 IR）

- 遍历 `components` 列表
- 对每个 component，检查其 `transforms` 字典是否包含 `relative_location` 或 `relative_rotation` 等键
- 如果存在 transform 数据：
  - 构建 `target` = `{component_name}`（组件变量名，formatter 会将其扩展为 `{component_name}->SetRelativeLocationAndRotation(...)`）
  - 将 transforms 字典作为 `value` 暂存（保留 VectorValue/RotatorValue 对象，不转为字符串）
  - 创建 `CppDefaultValue(target=target, value=transforms_dict, cpp_type="transform", is_method_call=True, method_type="transform")`
- 返回 `List[CppDefaultValue]`，调用方将其追加到 `ir.constructor["default_values"]`

关键逻辑示例：
```python
def build_transform_assignments(ir: CppClassIR, components: List[Dict]) -> List[CppDefaultValue]:
    entries = []
    for comp in components:
        transforms = comp.get("transforms", {})
        if not transforms:
            continue
        has_loc = "relative_location" in transforms
        has_rot = "relative_rotation" in transforms
        if not has_loc and not has_rot:
            continue
        entries.append(CppDefaultValue(
            target=comp["name"],
            value=transforms,
            cpp_type="transform",
            is_method_call=True,
            method_type="transform",
        ))
    return entries
```
