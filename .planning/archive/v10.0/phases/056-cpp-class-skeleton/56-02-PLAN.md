**Main function signature:**
```python
def extract_cpp_class_skeleton(result: LinkerParseResult) -> CppClassIR:
    """Extract C++ class skeleton from LinkerParseResult.
    
    Per D-02: Walk ClassParent chain for inheritance.
    Per D-03: Use ue_path_to_cpp_type for type mapping.
    Per D-04: Use cpf_flags_to_uproperty_marks for UPROPERTY marks.
    Per D-05: Populate header_meta with includes and generated_include.
    Per D-06: Return CppClassIR with properties filled, methods/constructor empty.
    """
```

**Implementation steps:**

1. **Extract class name:** From `result.summary.package_name` (first name_map entry). Convert to C++ style: if name starts with `BP_`, prefix with `A` for Actors or keep as-is. Use `BlueprintMetadata.parent_class` to determine: if parent is Actor-derived (e.g., Character, Pawn, GameMode), prefix with `A`; if Component-derived, prefix with `U`.

2. **Resolve inheritance chain (D-02):**
   - Start from `result.blueprint.parent_class` (e.g., `"/Script/Engine.Character"`)
   - Call `ue_package_path_to_cpp_class()` to convert to C++ name (`"ACharacter"`)
   - If deeper chain needed: walk ImportMap via `PackageLinker` to find ClassParent entries
   - Max depth: 50 hops (safety limit per threat model)
   - Set `ir.parent_class` to the ultimate engine base class

3. **Extract component properties:**
   - Iterate `result.blueprint.variables` where `is_component=True`
   - For each: `cpp_type = ue_path_to_cpp_type(var.var_type)` + append `*` (components are pointers in C++)
   - `uproperty_marks = cpf_flags_to_uproperty_marks(var.property_flags, is_component=True)`
   - `category = "component"`, `default_value = None`
   - Create `CppProperty` and append to `ir.properties`
   - Also iterate `result.components` list for SCS components not in blueprint.variables

4. **Extract variable properties:**
   - Iterate `result.blueprint.variables` where `is_component=False`
   - For each: `cpp_type = ue_path_to_cpp_type(var.var_type.pin_category + '.' + var.var_type.pin_subcategory)` — construct the UE type path from FEdGraphPinType
   - `uproperty_marks = cpf_flags_to_uproperty_marks(var.property_flags)`
   - `category = "variable"`, `default_value = var.default_value`
   - Create `CppProperty` and append

5. **Build header_meta:**
   - `CppHeaderMeta.build_from_parent(parent_class)` for includes
   - Set `generated_include = f'"{ir.name}.generated.h"'`

6. **Leave methods=[] and constructor empty** — per Phase 56 constraint.
