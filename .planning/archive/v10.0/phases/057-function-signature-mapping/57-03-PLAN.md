  <action>
Add to extract_cpp_skeleton.py:

1. **_derive_call_target(pins: List[UEdGraphPin], b_self_context: bool) -> Tuple[str, str]**:
   - If b_self_context=True: return ("this", "this")
   - If b_self_context=False: find the "self" pin (pin_name=="self")
     - If found: extract from pin.pin_type.pin_subcategory_object (resolved via linker or raw path)
       - Use ue_path_to_cpp_type() on the resolved path → e.g., "ACharacter"
       - Return (cpp_type, "pointer") — caller uses `->` for pointer access
     - If self pin not found or type unresolvable: return ("Unknown", "pointer")

2. **extract_cpp_call_statements(graphs: List[UEdGraph], linker: Optional[Any] = None) -> List[CppCallStatement]**:
   - Iterate all graphs, for each graph.nodes:
     - Find nodes where class_name == "K2Node_CallFunction"
     - For each call node:
       a. Get function_reference from node_data dict or node.function_reference attribute
       b. If function_reference is None or member_name is None/"None": skip
       c. Get b_self_context from function_reference
       d. Derive target: _derive_call_target(node.pins, b_self_context)
       e. Extract args: iterate pins, skip if pin_category=="exec", pin_name=="self", pin_name=="then"
          - For each data pin: append _sanitize_identifier(pin.pin_name) to args list
       f. Create CppCallStatement(method_name=member_name, target=target, target_type=target_type, args=args, is_self_context=b_self_context)
       g. Append to results
   - Return List[CppCallStatement]

Per D-57-05: Never add "Super::" prefix. Even if member_parent points to parent class, output "this->Jump()" not "Super::Jump()".
  </action>
