  <action>
Add to cpp_header_formatter.py:

1. **_format_method_declaration(method: CppMethodIR) -> List[str]**: Renders a single CppMethodIR as .h declaration lines.
   - If method.ufunction_specifiers is non-empty:
     - Build UFUNCTION line: `    UFUNCTION({", ".join(method.ufunction_specifiers)})`
     - Append to lines
   - Build parameter string: `", ".join(f"{p.cpp_type} {p.name}" for p in method.parameters)`
   - Build declaration: `    {return_type} {cpp_name}({params})`
   - If method.is_override: append ` override` before `;`
   - If method.is_const: append ` const` before `;` or ` override`
   - Append `;` to declaration
   - Return lines list

   Examples:
   - Move → `    UFUNCTION(BlueprintCallable)\n    void Move(double LeftRight, double ForwardBackward);`
   - PrimaryThumbstick → `    void PrimaryThumbstick(double Axis_X, double Axis_Y) override;` (no UFUNCTION, has override)
   - Pure function → `    UFUNCTION(BlueprintPure)\n    FVector GetVelocity() const;`

2. **Integrate into format_cpp_header()**:
   - After the properties section (line ~122, before `};`), add methods section:
     - If ir.methods is non-empty:
       - Add empty line
       - Add `public:` if not already present (check if "public:" already in lines)
       - Add `    // Blueprint Functions` comment
       - For each method in ir.methods: extend lines with _format_method_declaration(method), add empty line between methods
   - Order: properties first, then methods (methods are public in UE convention)

   Note: Current format_cpp_header has properties under `protected:`. Methods should be under `public:`. Need to restructure slightly:
   - After GENERATED_BODY(): add `public:` section
   - Constructor stays in public
   - Add methods in public section after constructor
   - Keep properties in protected section
  </action>

   - For each statement:
     - Determine access operator: `->` (pointer access, standard for UE)
     - Build call: `{target}->{method_name}({", ".join(args)})`
     - Add semicolon: `{target}->{method_name}(...);`
   - Join all statements with newlines
   - Add `// Call Reference` header comment
   - Return complete text

   Examples:
   - CppCallStatement(method_name="Jump", target="this", args=[]) → `this->Jump();`
   - CppCallStatement(method_name="Move", target="this", args=["LeftRight", "ForwardBackward"]) → `this->Move(LeftRight, ForwardBackward);`
