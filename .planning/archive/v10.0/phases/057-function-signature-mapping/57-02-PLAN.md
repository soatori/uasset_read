Add these helper functions to extract_cpp_skeleton.py:

1. **_sanitize_identifier(name: str) -> str**: Convert UE pin names to valid C++ identifiers.
   - Remove spaces, slashes, special chars: replace with empty string (not underscore) to match UE convention
   - "Left / Right" → "LeftRight", "Forward / Backward" → "ForwardBackward"
   - "Primary Thumbstick" → "PrimaryThumbstick"
   - Use regex: re.sub(r'[^A-Za-z0-9_]', '', name)
   - Handle leading digits: prepend underscore if starts with digit
   - Follow existing _sanitize_class_name pattern but without underscores for spaces

2. **_extract_cpp_type_from_pin(pin: UEdGraphPin) -> str**: Convert a single pin to C++ type string.
   - Skip if pin.pin_type.pin_category == "exec" or pin.pin_type.pin_category == "delegate"
   - Get base type:
     - If pin_category in ("object", "struct"): use pin_subcategory_object resolved path (via linker if available, else pin_subcategory string)
     - Otherwise: use pin_subcategory or pin_category directly
   - Convert via ue_path_to_cpp_type()
   - Apply direction modifier per D-57-06:
     - (is_reference=True, is_const=True) → "const {type}&"
     - (is_reference=True, is_const=False) → "{type}&"
     - Otherwise → "{type}" (value)
   - For object types: always add "*" suffix (pointers)

3. **_extract_parameters_from_pins(pins: List[UEdGraphPin], is_event: bool = False) -> List[CppCallParameter]**: Extract function parameters from pin list.
   - Filter out: exec pins (pin_category=="exec"), delegate pins (pin_category=="delegate")
   - Filter out: hidden pins (hidden=True), parent pins that have sub_pins (bHidden pins)
   - For event nodes (is_event=True): skip "OutputDelegate" and "then" pins by name
   - For each valid pin: create CppCallParameter(name=_sanitize_identifier(pin.pin_name), cpp_type=..., direction="input")
   - Skip SubPin parent pins (pins that have sub_pins and are marked hidden)
  </action>

1. **_infer_ufunction_specifiers(pins: List[UEdGraphPin], node_class_name: str, is_override: bool) -> List[str]**: Per D-57-03.
   - If is_override=True: return [] (override methods get no UFUNCTION, per D-57-04)
   - has_exec_input = any(pin for pin in pins if pin.pin_type.pin_category == "exec" and pin.direction == 0)
   - has_exec_output = any(pin for pin in pins if pin.pin_type.pin_category == "exec" and pin.direction == 1)
   - If has_exec_input or has_exec_output: return ["BlueprintCallable"] (impure function)
   - Else: return ["BlueprintPure"] (pure function, no exec pins)

2. **_build_cpp_method_from_entry(fe_node: K2NodeFunctionEntry, blueprint_functions: Dict) -> CppMethodIR**:
   - Get function name from fe_node.function_reference.member_name (handle None/"None"/path forms)
   - Dual-source cross-validation (D-57-01):
     - Primary: Look up function_name in blueprint_functions dict → use BlueprintFunction.return_type and BlueprintFunction.parameters
     - Secondary: Extract from fe_node.pins via _extract_parameters_from_pins
     - If both available and parameter count differs: logger.warning with function name, use blueprint_functions as source of truth
     - If only pins available: use pin extraction as fallback
   - Return type: blueprint_functions return_type or "void" if empty/missing
   - UFUNCTION specifiers: _infer_ufunction_specifiers(fe_node.pins, "K2Node_FunctionEntry", is_override=False)
   - source_node_type="K2Node_FunctionEntry"

   - Extract parameters from event_node.pins via _extract_parameters_from_pins(pins, is_event=True)
   - return_type = "void" (events don't return values)
   - ufunction_specifiers = [] (override methods get no UFUNCTION per D-57-04)
   - is_override = True
   - source_node_type = "K2Node_Event"

**extract_cpp_functions(graphs: List[UEdGraph], blueprint_functions: Optional[List] = None, linker: Optional[Any] = None) -> Tuple[CppClassIR, List[CppMethodIR]]**

Algorithm:
1. Build blueprint_functions lookup dict: {func.name: func for func in blueprint_functions or []}
2. Initialize methods: List[CppMethodIR] = []
3. For each graph in graphs:
   a. Iterate graph.nodes, find K2Node_FunctionEntry nodes (node.class_name == "K2Node_FunctionEntry")
      - Call _build_cpp_method_from_entry(fe_node, blueprint_functions) → append to methods
   b. Iterate graph.nodes, find K2Node_Event nodes with b_override_function=True
      - Call _build_cpp_method_from_event(event_node) → append to methods
4. Return (methods, ) — the caller will attach methods to CppClassIR.methods
   - Actually, return just List[CppMethodIR] — the integration task wires it into CppClassIR

Signature: `extract_cpp_functions(graphs, blueprint_functions=None, linker=None) -> List[CppMethodIR]`

Add to extract_cpp_class_skeleton(): after extracting properties, call extract_cpp_functions(result.graphs, result.blueprint.functions if available, result.linker) and set ir.methods = result.
