# Requirements: uasset_read v3.0

**Defined:** 2026-05-03
**Core Value:** 补齐缺失数值解析，输出可用结果，打包成Claude Code skill

## v1 Requirements

### 数据提取 (EXTR)

- [x] **EXTR-01**: ExportMap属性值提取 — 从ExportMap中提取组件属性值、变量默认值、输入动作引用
- [x] **EXTR-02**: BlueprintVariables完整提取 — 提取蓝图变量名称、类型、默认值、元数据（Category、BlueprintReadWrite等）
- [x] **EXTR-03**: 组件变量区分 — 区分组件变量（SkeletalMeshComponent等）和普通变量
- [x] **EXTR-04**: 组件变换属性解析 — 解析组件的RelativeLocation/RelativeRotation/RelativeScale3D属性
- [x] **EXTR-05**: 变量默认值类型覆盖 — 支持数值、字符串、布尔、向量、对象引用等类型默认值

### 输出优化 (OUT)

- [x] **OUT-01**: status字段 — 添加JSend style status字段（success/fail/error），AI一眼判断解析结果
- [x] **OUT-02**: execution_flows顶层化 — 将execution_flows从graphs[]内提升至顶层graphs_summary字段
- [x] **OUT-03**: 摘要模式 — 添加--summary标志，输出精简摘要减少70%+ token
- [x] **OUT-04**: Markdown输出格式 — 添加--markdown标志，输出Markdown格式（人类+AI双重友好）
- [x] **OUT-05**: Field描述增强 — 关键字段添加语义注释（parent_class、variables等含义说明）
- [x] **OUT-06**: 输出格式冻结 — Phase 14完成后冻结输出格式，确保API稳定供skill使用

### Skill封装 (SKILL)

- [x] **SKILL-01**: SKILL.md定义 — 创建SKILL.md主文件（YAML Frontmatter格式，触发词、能力范围）
- [x] **SKILL-02**: knowledge知识库 — 编写5-6个知识文件：blueprint-semantics.md、node-types.md、pin-type-mapping.md、cpp-conversion.md、common-patterns.md、troubleshooting.md
- [x] **SKILL-03**: examples示例 — 编写3-4个示例文件：basic-usage.md、blueprint-analysis.md、cpp-conversion.md
- [x] **SKILL-04**: skill集成测试 — 验证skill触发、调用parse_uasset() API、输出解读正确

### 修复 (FIX) — Phase 16-17

- [x] **FIX-01**: Bool序列化大小 — 修正bool字段从1 byte改为4 bytes (UE 5.7)
- [x] **FIX-02**: ImportMap解析 — ImportMap使用正确的read_bool()
- [x] **FIX-03**: 蓝图图结构 — UEdGraph/Node/Pin使用正确的read_bool()
- [x] **FIX-04**: 偏移计算 — ScriptSerializationStartOffset = serial_offset + script_serial_offset
- [x] **FIX-05**: SerializationControlExtensions — UE5 >= 1011 头部处理
- [x] **FIX-06**: PropertyTag Extensions — HAS_EXTENSIONS (0x04) 标志检测
- [x] **FIX-07**: 阈值修复 — PROPERTY_TAG_COMPLETE_TYPE_NAME = 1012

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Pydantic迁移 | 手动Field描述足够；迁移成本待评估 |
| FastMCP封装 | skill封装优先；MCP Server延后 |
| 多资产批量输出 | 超出v3.0范围 |
| TypeScript定义生成 | 次要，可文档化 |
| 实时解析/监控 | 批量解析场景，无需实时功能 |
| Cooked资产解析 | Cooked资产已剥离图数据 |
| 蓝图字节码反编译 | 专注于编辑器保存的资产 |
| 自动C++代码生成 | 仅提供参考级别JSON |
