## 超出范围

明确排除，记录以防范围蔓延。

| 功能 | 原因 |
|------|------|
| 自动 C++ 代码生成 | 仅提供参考级别 JSON，不实现自动转换 |
| Cooked 资产解析 | Cooked 资产已剥离图数据；使用不同序列化格式 |
| 蓝图字节码反编译 | 编译蓝图使用字节码格式；专注于编辑器保存的资产 |
| 节点可视化 | 复杂 UI 工作；AI agent 无需视觉预览 |
| 资产修改/写入 | 超出 PROJECT.md 范围；仅支持只读解析 |
| 自定义节点类型处理器 | 游戏特定自定义节点需要游戏特定知识 |
