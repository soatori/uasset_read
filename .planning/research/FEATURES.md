# 蓝图图功能全景

**领域：** Unreal Engine .uasset 蓝图图解析（UEdGraph、K2Node、UEdGraphPin）
**研究日期：** 2026-05-02
**备注：** 专注于未烘焙/编辑器保存的蓝图资产（含完整图数据）

---

## 执行摘要

蓝图图解析是理解蓝图逻辑的核心。蓝图在 .uasset 中以 `UEdGraph` → `UEdGraphNode` → `UEdGraphPin` 层级结构存储。关键发现：

1. **节点类型丰富**：K2Node_CallFunction（函数调用）、K2Node_Event（事件）、K2Node_Knot（线缆中继）、EdGraphNode_Comment（注释）等
2. **引脚连接机制**：通过 `LinkedTo` 数组和 `ParentPin/SubPins` 实现执行流和数据流追踪
3. **引脚类型系统**：PinCategory（exec/object/struct/real/bool）、ContainerType（None/Array/Set/Map）、版本感知字段（bIsConst、bIsUObjectWrapper）
4. **解析依赖**：需先解析导出表确定图节点位置；需 NameMap 支持引脚名称解析

---

## 核心数据结构（UE 5.7）

### UEdGraph（蓝图图）

蓝图图是节点的容器，对应一个函数或事件图。

| 字段 | 类型 | 说明 | 解析重要性 |
|------|------|------|------------|
| Schema | UEdGraphSchema* | 图模式（决定连接规则） | 确定有效连接 |
| Nodes | TArray<UEdGraphNode*> | 图中所有节点 | 核心数据 |
| GraphGuid | FGuid | 图唯一标识 | 图去重/引用 |
| bEditable | bool | 编辑器中是否可编辑 | 辅助确认 |
| b.allowDeletion | bool | 是否允许删除 | 辅助确认 |

**解析要点：**
- 位于导出表中（ClassIndex 包含 "EdGraph"）
- `UbergraphPages` → `UEdGraph`（事件图）
- `FunctionGraphs` → `UEdGraph`（函数图）

---

### UEdGraphNode（节点基类）

所有蓝图节点的基类。

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| Pins | TArray<UEdGraphPin*> | 节点的所有引脚 | 执行流 + 数据引脚 |
| NodePosX | int32 | X 坐标 | 2368 |
| NodePosY | int32 | Y 坐标 | -1600 |
| NodeGuid | FGuid | 节点唯一标识 | `5D89F5E1475AA873E70CA38F90E53945` |
| NodeComment | FString | 节点注释 | "Camera Input" |
| NodeName | FName | 节点实例名 | `K2Node_CallFunction_11` |

**解析要点：**
- 所有节点都有坐标和 Guid（用于引用）
- 注释用于 AI 理解（如 "Movement Input"）

---

### UEdGraphPin（引脚）

数据/执行流的端点，通过 `LinkedTo` 连接节点。

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| PinId | FGuid | 引脚唯一标识 | `B385978745DF60A304C47792A02C0269` |
| PinName | FName | 引脚名称 | `"execute"` / `" returnValue"` |
| Direction | EEdGraphPinDirection | 方向 | `EGPD_Input` / `EGPD_Output` |
| PinType | FEdGraphPinType | 类型结构 | 见下方 |
| DefaultValue | FString | 默认值字符串 | `"0.0"` |
| LinkedTo | TArray<UEdGraphPin*> | 连接到的引脚 | `[K2Node_Event_4 PinId...]` |
| SubPins | TArray<UEdGraphPin*> | 拆分子引脚 | `[X, Y]` for Vector2D |
| ParentPin | UEdGraphPin* | 父引脚（拆分来源） | `B1FD31FC4491F9E880F9549F8EBB231B` |
| bHidden | bool | 是否隐藏 | false |
| bOrphanedPin | bool | 孤立引脚 | false |
| bDefaultValueIsReadOnly | bool | 默认值只读 | false |

**方向枚举 EEdGraphPinDirection：**
| 值 | 名称 | 说明 |
|-----|------|------|
| EGPD_Input | 输入 | 数据流入节点 |
| EGPD_Output | 输出 | 数据流出节点 |
| EGPD_None | 无 | 双向或特殊 |

**解析要点：**
- `LinkedTo` 存储对端引脚的 PinId（需二次查找映射）
- `SubPins` + `ParentPin` 实现结构体/数组拆分显示
- `DefaultValue` + `AutogeneratedDefaultValue` 区分用户/自动生成

---

### FEdGraphPinType（引脚类型）

完整定义引脚承载的数据类型（来自 EdGraphPin.h lines 76-225）。

| 字段 | 类型 | 说明 | 取值示例 |
|------|------|------|----------|
| pin_category | FName | 主类别 | `"exec"` / `"object"` / `"struct"` / `"real"` / `"bool"` |
| pin_sub_category | FName | 子类别 | `""` / `"Int"` / `"double"` |
| pin_sub_category_object | FPackageIndex | 子类别对象引用 | `/Script/Engine.Character` |
| container_type | int32 | 容器类型 | 0=None, 1=Array, 2=Set, 3=Map |
| is_reference | bool | 是否引用传递 | false |
| is_const | bool | 是否常量（UE4 >= 521） | false |
| is_weak_pointer | bool | 是否弱指针 | false |
| is_uobject_wrapper | bool | 是否 UObject 包装（UE5+） | false |
| meta_data | TMap<FName,FString> | 元数据 |  |

**PinCategory 常见值：**
| 值 | 说明 | 对应 Python 类型 |
|----|------|-----------------|
| `exec` | 执行流引脚 | None（控制流） |
| `object` | 对象引用 | str（类名字符串） |
| `struct` | 结构体 | dict（嵌套结构） |
| `real` | 浮点数 | float |
| `bool` | 布尔 | bool |
| `int` | 整数 | int |
| `string` | 字符串 | str |
| `name` | 名称 | str |
| `delegate` | 代理 | str（函数名） |
| `panel` | UI 面板 | - |

**ContainerType 枚举：**
| 值 | 名称 | 说明 |
|----|------|------|
| 0 | none | 单值 |
| 1 | array | 数组 |
| 2 | set | 集合 |
| 3 | map | 映射 |

## 核心节点类型分类

### 1. 执行流控制节点（Execution Control）

| 节点类 | UEdGraphPin 引脚 | 典型用途 |
|--------|------------------|----------|
| **K2Node_Event** | `then` (Output exec), `OutputDelegate` (Output delegate) | 事件响应（触摸、输入、生命周期） |
| **K2Node_CallFunction** | `execute` (Input exec), `then` (Output exec), `self` (Input object), 函数参数 | 调用 C++/蓝图函数 |
| **K2Node_FunctionEntry** | `then` (Output exec), 函数参数 (Output) | 函数入口点 |
| **K2Node_FunctionResult** | `execute` (Input exec), 函数返回值 (Input) | 函数返回点 |

## 引脚连接机制详解

### 连接映射方式

连接通过 `LinkedTo` 数组实现，但**不是直接存储节点引用**：

1. **存储格式**：`LinkedTo=(K2Node_Event_4 5B51114047AD12FFBCC0B4B41D99E92B,)`
   - 第一部分：节点名（`K2Node_Event_4`）
   - 第二部分：PinId GUID（`5B51114047AD12FFBCC0B4B41D99E92B`）

2. **解析步骤**：
   ```
   step 1: 从 LinkedTo 提取 (node_name, pin_id_guid)
   step 2: 遍历所有节点找到匹配 node_name
   step 3: 遍历该节点的 Pins 找到匹配 pin_id_guid
   step 4: 构建连接边：(current_pin, target_pin)
   ```

3. **子引脚连接**：`ParentPin` + `SubPins` 实现拆分显示
   ```
   Primary Pin (ActionValue, struct Vector2D)
   ├── SubPin (ActionValue_X, double) → Connected to Function Arg X
   └── SubPin (ActionValue_Y, double) → Connected to Function Arg Y
   ```

### 连接示例解析

从编辑器导出的连接：
```
K2Node_EnhancedInputAction_2 (Triggered)
  → LinkedTo: K2Node_CallFunction_11 (execute)

K2Node_EnhancedInputAction_2 (ActionValue_X)
  → LinkedTo: K2Node_CallFunction_11 (Yaw)
```

**语义：**
1. 触摸输入事件触发时，执行流到达 `K2Node_CallFunction_11`（Aim 函数）
2. 同时，输入的 X 值传递给 `Yaw` 参数

```

  ↓

  ↓

  ↓
  读取：Nodes 数组（UEdGraphNode*）
  ↓

  ↓

  ↓

  ↓

```

## 表类型 vs 差异化功能

### Table Stakes（基线功能）

用户期望蓝图解析器具备的基本能力：

| 功能 | 为什么期望 | 复杂度 | 测试验证 |
|------|------------|--------|----------|
| 事件图解析 | 蓝图核心行为是事件驱动 | 中 | K2Node_Event + LinkedTo |
| 函数调用节点识别 | 调用是逻辑组成单元 | 中 | K2Node_CallFunction + FunctionReference |
| 引脚类型提取 | 需知道引脚承载的数据类型 | 中 | FEdGraphPinType 10 字段 |
| 执行流追踪 | 了解蓝图执行顺序 | 高 | 链式 LinkedTo 遍历 |
| 变量读写节点 | 理解数据流 | 中 | K2Node_VariableGet/Set |

### Differentiators（差异化功能）

超越基本解析的高级能力：

| 功能 | 价值主张 | 复杂度 | 实现优先级 |
|------|----------|--------|------------|
| 输出节点上下文信息 | AI 需要语义理解（如 "jump action"） | 高 | v2.0 后期 |
| 节点分组识别 | 通过注释框理解逻辑分组 | 低 | v2.0 早期 |
| 路径追踪 | 从入口事件到输出函数的完整路径 | 高 | v2.1 |
| 依赖倒排索引 | 通过输入动作反查使用位置 | 高 | v2.1+ |
| 类 C++ 代码生成 | 输出近似等价的 C++ 伪代码 | 极高 | v3.0 |

---

## 反功能（Anti-Features）

明确不支持的功能（超出 v2.0 范围）：

| 反功能 | 避免原因 | 替代方案 |
|--------|----------|----------|
| 蓝图字节码反编译 | cooked 资产无图数据；需专门 VM 解析 | 专注于编辑器保存资产 |
| 节点执行模拟 | 需要完整的运行时环境 | 输出可翻译为伪代码 |
| 节点编辑/修改 | 修改需完整序列化支持 | 仅支持只读解析 |
| 高级优化节点识别 | 需编译器语义知识 | 输出节点原始数据 |
| 节点历史追踪 | 需版本控制系统 | 仅解析当前文件状态 |

## 解析算法建议

### 节点解析流程

```python
def parse_uasset_graphs(export_map, name_map, archive, summary):
    """Parse all graph nodes from export map"""
    graphs = []
    
    # Step 1: Find all UEdGraph exports
    graph_exports = [e for e in export_map 
                     if is_graph_export(e, name_map)]
    
    for graph_export in graph_exports:
        graph = parse_graph(graph_export, export_map, name_map, archive, summary)
        graphs.append(graph)
    
    return graphs


def parse_graph(graph_export, export_map, name_map, archive, summary):
    """Parse UEdGraph from export"""
    archive.seek(graph_export.serial_offset)
    
    # UEdGraph structure (simplified)
    schema = archive.read_package_index()
    nodes = []
    
    # Read Nodes array
    node_count = archive.read_i32()
    for _ in range(node_count):
        node_export_index = archive.read_package_index()
        node = parse_node_from_export(node_export_index, export_map, 
                                       name_map, archive, summary)
        nodes.append(node)
    
    graph_guid = archive.read_guid()
    b_editable = archive.read_u8() > 0
    
    return {
        "graph_guid": str(graph_guid),
        "b_editable": b_editable,
        "nodes": nodes,
    }


def parse_node_from_export(node_export_idx, export_map, name_map, archive, summary):
    """Parse UEdGraphNode from export index"""
    node_export = export_map[node_export_idx.to_export_index()]
    
    # Seek to node data
    archive.seek(node_export.serial_offset)
    
    # Read common node fields
    pins = []
    pin_count = archive.read_i32()
    
    for _ in range(pin_count):
        pin = parse_pin(archive, name_map, summary)
        pins.append(pin)
    
    node_pos_x = archive.read_i32()
    node_pos_y = archive.read_i32()
    node_comment = archive.read_fstring()
    node_guid = archive.read_guid()
    
    # Node-specific fields (via ClassIndex dispatch)
    class_name = node_export.class_name
    if class_name == "K2Node_CallFunction":
        function_ref = parse_function_reference(archive)
        extra = {"function_reference": function_ref}
    elif class_name == "K2Node_Event":
        event_ref = parse_event_reference(archive)
        extra = {"event_reference": event_ref}
    else:
        extra = {}
    
    return {
        "node_name": node_export.object_name,
        "node_guid": str(node_guid),
        "node_pos": {"x": node_pos_x, "y": node_pos_y},
        "node_comment": node_comment,
        "pins": pins,
        "class_name": class_name,
        "extra": extra,
    }


def parse_pin(archive, name_map, summary):
    """Parse UEdGraphPin"""
    pin_id = archive.read_guid()
    pin_name = read_name_or_text(archive, name_map, summary)
    direction = archive.read_u8()  # EEdGraphPinDirection
    
    # Parse FEdGraphPinType
    pin_type = parse_pin_type(archive, summary)
    
    default_value = archive.read_fstring()
    
    # Read LinkedTo (connections)
    linked_to = []
    linked_count = archive.read_i32()
    for _ in range(linked_count):
        linked_pin_id = archive.read_guid()
        linked_to.append(str(linked_pin_id))
    
    # SubPins (for struct拆分)
    sub_pins = []
    if archive.read_u8() > 0:  # has_subpins
        sub_pin_count = archive.read_i32()
        for _ in range(sub_pin_count):
            sub_pin = parse_pin(archive, name_map, summary)
            sub_pins.append(sub_pin)
    
    parent_pin_id = archive.read_guid() if archive.read_u8() > 0 else None
    
    return {
        "pin_id": str(pin_id),
        "pin_name": pin_name,
        "direction": direction,
        "pin_type": pin_type,
        "default_value": default_value,
        "linked_to": linked_to,  # PinId GUIDs
        "sub_pins": sub_pins,
        "parent_pin": str(parent_pin_id) if parent_pin_id else None,
    }


def parse_pin_type(archive, summary):
    """Parse FEdGraphPinType with version awareness"""
    pin_category = read_name_or_text(archive, name_map, summary)
    pin_sub_category = read_name_or_text(archive, name_map, summary)
    pin_sub_category_object = archive.read_package_index()
    
    # Container type (added in FFrameworkObjectVersion::EdGraphPinContainerType)
    container_type = 0
    if summary.version >= FRAMEWORK_OBJECT_VERSION_EDGRAPH_PIN_CONTAINER_TYPE:
        container_type = archive.read_u8()
    
    # bIsConst (added in VER_UE4_SERIALIZE_PINTYPE_CONST)
    is_const = False
    if summary.version >= UE4_SERIALIZE_PINTYPE_CONST:
        is_const = archive.read_u8() > 0
    
    # bIsUObjectWrapper (added in FReleaseObjectVersion::PinTypeIncludesUObjectWrapperFlag)
    is_uobject_wrapper = False
    if summary.version >= RELEASE_OBJECT_VERSION_PIN_TYPE_UOBJECT_WRAPPER:
        is_uobject_wrapper = archive.read_u8() > 0
    
    is_weak_pointer = False  # Placeholder for future
    
    return {
        "pin_category": pin_category,
        "pin_sub_category": pin_sub_category,
        "pin_sub_category_object": pin_sub_category_object.index,
        "container_type": container_type,
        "is_const": is_const,
        "is_uobject_wrapper": is_uobject_wrapper,
        "is_weak_pointer": is_weak_pointer,
    }
```
