### K2Node_FunctionEntry Pin 结构

FunctionEntry 节点的 Pins 包含:
- 输入 Pin (Direction=0): 函数参数（self, 参数1, 参数2, ...）
- 输出 Pin (Direction=1): ReturnValue（如果有返回值）

参数 Pin 的 `pin_type.pin_category` 决定参数类型。

### Task 5: 从 Function 节点提取参数签名 (GAP-07)

**问题:** `build_function_graphs()` 的签名全空（`return_type="", parameters=[]`）。

**根因分析:**
1. 当前从 `blueprint_functions` 获取签名，但 Function 节点可能不在该列表
2. FunctionEntry 节点的 Pins 包含参数信息，但未被提取
3. 需从 Pin 的 `pin_name` + `pin_type` 构建参数列表

**文件:** `src/uasset_read/graph/flow_builder.py`

**Action:**

1. **在 `build_function_graphs()` 中添加 Pin-based 签名提取:**
   ```python
   def _extract_signature_from_pins(fe_node: UEdGraphNode) -> Dict:
       """从 FunctionEntry 节点的 Pins 提取签名。"""
       return_type = ""
       parameters = []
       
       for pin in fe_node.pins:
           if pin.pin_type.pin_category == "exec":
               continue  # 跳过 exec pin
           
           if pin.direction == 1 and pin.pin_name == "ReturnValue":
               # 返回值
               return_type = pin.pin_type.pin_subcategory or pin.pin_type.pin_category
           elif pin.direction == 0:
               # 输入参数
               param_type = pin.pin_type.pin_subcategory or pin.pin_type.pin_category
               if pin.pin_name.lower() not in ("self", "target"):
                   parameters.append({
                       "name": pin.pin_name,
                       "type": param_type,
                       "direction": "input"
                   })
       
       return {"return_type": return_type, "parameters": parameters}
   ```

2. **在 `build_function_graphs()` 中调用:**
   - 如果 `blueprint_functions` 查找失败，使用 Pin-based 提取作为 fallback

**Verify:**
```xml
<verify>
  <automated>pytest tests/test_graph_parser_fix.py::test_function_signature_extraction -v</automated>
</verify>
```

**Done:** 函数签名包含正确的参数列表（name + type），`return_type` 不为空字符串（如果有返回值）。
