# Plan 16-01: FArchive.read_bool() + ExportMap 修复

## Objective

在 FArchive 类添加 `read_bool()` 方法，并修复 ExportMap 中的 7 个 bool 字段，使导出表条目大小计算正确。

**Purpose:** UE bool 序列化使用 4-byte uint32（自 UE3 开始的标准），当前错误使用 1-byte read_u8() 导致每条目少读 21 bytes，累积偏移错误使 serial_offset 出现无效负值。

**Output:** FArchive.read_bool() 方法 + ExportMap 7 个 bool 字段修复

```python
def read_u32(self) -> int:
    """读取 unsigned 32-bit integer（支持字节交换）"""
    fmt = '>' if self._byte_swapping else '<'
    return struct.unpack(fmt + 'I', self.read(4))[0]
```

```python
    """
    读取 UE bool 值（序列化为 uint32，4 bytes）。

    "Serialize bool as if it were UBOOL (legacy, 32 bit int)"
```
