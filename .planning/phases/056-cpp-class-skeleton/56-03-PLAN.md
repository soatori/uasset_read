**Main function:**
```python
def format_cpp_header(ir: CppClassIR) -> str:
    """Convert CppClassIR to standard UE .h header text.
    
    Per D-05: Includes pragma_once, includes[], forward_declarations[],
    generated_include (last), UCLASS, GENERATED_BODY, UPROPERTY declarations.
    """
```

**Output format (UE standard .h structure):**
1. `#pragma once` (if `ir.header_meta.pragma_once`)
2. Blank line
3. `#include "CoreMinimal.h"` (always added — UE convention)
4. `#include` lines from `ir.header_meta.includes` (sorted)
5. `#include` for `ir.header_meta.generated_include` (always last)
6. Blank line
7. `UCLASS(Blueprintable)` (or `UCLASS()` if no special flags — use `Blueprintable` as default for Blueprint-generated classes)
8. `class {ir.name} : public {ir.parent_class}`
9. `{`
10. `    GENERATED_BODY()`
11. Blank line
12. `public:` (always — UE convention)
13. `    {ir.name}();` (default constructor declaration)
14. Blank line
15. `protected:` (for properties)
16. For each property in `ir.properties`:
    - Components: `UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Components", meta = (AllowPrivateAccess = "true"))`
    - Variables with category: `UPROPERTY({marks}, Category = "{category}")`
    - Variables without category: `UPROPERTY({marks})`
    - Then: `    {cpp_type} {name};` (no default if None)
    - Or: `    {cpp_type} {name} = {default_value}f;` (for float, add `f` suffix)
    - If `cpp_comment` is set: add `// {cpp_comment}` after declaration
17. `};`
18. Trailing newline

**Default value formatting rules:**
- `float`/`double`: append `f` suffix → `600.0f`
- `int`/`int32`/`int64`: no suffix → `42`
- `bool`: use `true`/`false` → `true`
- `FName`: wrap in `TEXT()` → `TEXT("MyName")`
- `FText`: wrap in `NSLOCTEXT()` → `NSLOCTEXT("...", "...", "...")` — skip for now (too complex), comment instead
- `FString`: wrap in `TEXT()` → `TEXT("Hello")`
- `nullptr` for component pointer types with no default
- `0` for numeric types with None default
