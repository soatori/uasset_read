# 63 — 表达式树 → C++ 伪代码

**Goal**: 将 KismetExpression AST 翻译为可读的 C++ 伪代码，对标 CUE4Parse 的 `BlueprintDecompilerUtils.GetLineExpression()` 和 `MathFunctionCleaner`。

**Depends on**: Phase 62

**Requirements**: TRANSLATE-01, TRANSLATE-02, TRANSLATE-03, TRANSLATE-04

**Success Criteria** (what must be TRUE):
1. 每个 KismetExpression 节点翻译为等价的 C++ 代码行（变量引用 → `MyVar`，函数调用 → `UKismetMathLibrary::Add_FloatFloat(a, b)` 或美化后 `a + b`）
2. 控制流表达式（Jump/JumpIfNot/PushExecutionFlow/PopExecutionFlow）恢复为结构化的 C++ 代码（`if/else/for/while/switch`），而非 goto 语句
3. 引擎数学库调用美化翻译：`Add_IntInt(a, b)` → `a + b`，`MakeVector(x, y, z)` → `FVector(x, y, z)`
4. 赋值表达式正确翻译为 C++ 赋值语句（含类型后缀：`400.0f` 等）
