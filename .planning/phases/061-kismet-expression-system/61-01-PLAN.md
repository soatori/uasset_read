# 61-01-PLAN.md — EExprToken 枚举 + KismetExpression 基类 + 常量/变量表达式子类

## Objective

建立 Kismet 字节码表达式体系的根基：定义完整的 Token 枚举和基类架构，覆盖常量与变量引用两大核心类别。对标 CUE4Parse 的 `EExprToken.cs` 和 `KismetExpression.cs`，用 Python 3.10+ `match/case` 重构。

## Context

Phase 58 的 `CppFunctionBodyExtractor` 仅能处理 UEdGraphNode 层面的执行流，无法解析函数内部的字节码指令。CUE4Parse 用 57+ 个 `KismetExpression` 子类逐个处理 EExprToken——这是实现"函数体逻辑完整翻译"的前提。

**关键技术决策：**
- CUE4Parse 用继承链（`EX_VariableBase` → `EX_LocalVariable`）——Python 改用 `@dataclass` + `match/case` 模式，避免深层继承
- CUE4Parse 的 `KismetExpression` 内置 JSON 序列化——Python 拆分为 IR 层和格式化层，保持 Phase 58 已有的 `cpp_json_ir.py` 架构
