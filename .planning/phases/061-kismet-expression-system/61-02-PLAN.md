## Objective

## Context

Phase 58 只能处理 graph 层面的节点连接。Phase 61-01 定义了 EExprToken 枚举和 KismetExpression 数据类。61-02 负责将这两者串联：从 `FFunction.ScriptBytecode` 的 `bytes` 对象中逐字节解析，返回 `KismetExpression` 树。

CUE4Parse 的 FKismetArchive 继承 FArchive，用 `this[index++]` 逐字节读取。Python 用 `io.BytesIO` 或直接 `bytes` 索引即可。

在 `src/uasset_read/kismet/kismet_archive.py` 中添加 `ReadExpression()` 方法：

```python
def ReadExpression(self) -> KismetExpression:
    token = self.read_byte()
    expr_token = EExprToken(token)

    match expr_token:
        # 常量
        case EExprToken.EX_IntConst:
            return KismetIntConst(value=self.read_int(), token=expr_token)
        case EExprToken.EX_FloatConst:
            return KismetFloatConst(value=self.read_float(), token=expr_token)
        case EExprToken.EX_StringConst:
            return KismetStringConst(value=self.read_string(), token=expr_token)
        # ... 更多常量

        # 变量
        case EExprToken.EX_LocalVariable:
            return self._read_var_ref(expr_token, "local")
        case EExprToken.EX_InstanceVariable:
            return self._read_var_ref(expr_token, "instance")

        # 函数调用
        case EExprToken.EX_FinalFunction:
            return self._read_final_function(expr_token)
        case EExprToken.EX_Context:
            return self._read_context(expr_token)

        # 控制流
        case EExprToken.EX_Jump:
            return KismetJump(offset=self.read_uint32(), token=expr_token)
        case EExprToken.EX_JumpIfNot:
            return self._read_jump_if_not(expr_token)

        # 终止标记
        case EExprToken.EX_EndOfScript | EExprToken.EX_EndFunctionParms:
            return KismetNoOp(token=expr_token)

        case _:
            raise KismetParseError(f"Unsupported token: {expr_token}")
```

辅助方法：
- `_read_var_ref(token, scope) -> KismetVarRef` — 读取变量引用
- `_read_final_function(token) -> KismetCall` — 读取 FinalFunction 调用
- `_read_context(token) -> KismetContext` — 读取对象上下文
- `_read_jump_if_not(token) -> KismetJumpIf` — 读取条件跳转
- `_read_expression_array(end_token) -> list[KismetExpression]` — 读取表达式数组（用于数组/Map/Struct 常量）

**对标 CUE4Parse:**
- CUE4Parse 用 `switch` 分派 100+ case → Python 用 `match/case`（3.10+ 原生支持）
- CUE4Parse 每个 EX_* 类在构造函数中递归调用 `Ar.ReadExpression()` → Python 同样递归，但返回 dataclass

</action>

<acceptance_criteria>
- ReadExpression 正确识别并读取 30+ 种 Token
- 递归读取嵌套表达式（如 EX_Context → EX_FinalFunction → EX_IntConst）
- EX_EndOfScript 返回 KismetNoOp 不抛异常
- 未知 Token 抛出带详细错误信息的 KismetParseError
- _read_expression_array 在遇到 end_token 时停止
</acceptance_criteria>
