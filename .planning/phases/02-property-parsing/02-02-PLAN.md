ArrayProperty 模式 (PropertyArray.cpp 第 128-824 行):
1. 读取元素计数 (int32) - 标签后第一个数据
2. 为每个元素循环 (0 到 count-1):
   - 读取内部属性（复杂类型可能为 PropertyTag）
   - 根据内部类型调用适当解析器
3. 通过 tag.size 边界处理未知类型
4. 深度限制 (D-18: 最大 10) 防止无限递归

```python
def parse_array_property(
    tag: PropertyTag,
    archive: FArchive,
    name_map: List[str],
    export_map: List[ObjectExport],
    depth: int = 0
) -> List[Any]:
    """解析 ArrayProperty: 读取计数 + 循环元素。"""
    if depth > 10:
        raise ParseError("数组深度超过最大值 (10)")
    
    count = archive.read_i32()
    elements: List[Any] = []
    
    for i in range(count):
        element = parse_inner_element(tag, archive, name_map, export_map, depth + 1)
        elements.append(element)
    
    return elements
```

D-16 关键: 计数 + 循环模式，而非直接字节读取。

模式 (Class.cpp 第 1688-1900 行, SerializeVersionedTaggedProperties):
1. Seek 到 export.serial_offset
2. 循环直到 tag.Name == "None":
   - 读取 PropertyTag
   - 如果 Name == "None": break (结束标记)
   - 获取起始位置
   - 分派到类型特定解析器
   - Seek 到 start + tag.size (边界验证)
   - 将 PropertyValue 存储到结果列表
3. 返回 PropertyValue 列表

错误处理 (CONTEXT.md D-25, D-26):
- 未知类型: seek(start + tag.size) 跳过
- 单属性失败: 记录警告，继续下一个属性

```python
def parse_properties_from_export(
    export: ObjectExport,
    archive: FArchive,
    summary: PackageFileSummary,
    name_map: List[str],
    export_map: List[ObjectExport]
) -> List[PropertyValue]:
    """从导出属性序列化解析所有属性。"""
    archive.seek(export.serial_offset)
    properties: List[PropertyValue] = []
    
    while True:
        tag = read_property_tag(archive, name_map, summary.legacy_file_version, summary.file_version_ue5)
        if tag.name == "None":
            break
        
        start_pos = archive.tell()
        value = parse_property_value(tag, archive, name_map, export_map)
        archive.seek(start_pos + tag.size)  # 确保正确位置
        
        properties.append(PropertyValue(
            name=tag.name,
            type=tag.type,
            value=value,
            array_index=tag.array_index
        ))
    
    return properties
```

    tag: PropertyTag,
    archive: FArchive,
    name_map: List[str],
    export_map: List[ObjectExport]
) -> Any:
