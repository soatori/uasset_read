**目标**

实现 Phase 2 的版本感知 PropertyTag 解析和标志处理。

目的: 处理 UE4 和 UE5 之间的 PropertyTag 格式差异，并实现 HasPropertyGuid 和 HasArrayIndex 标志的条件字段读取。这是完整属性标签解析的最后一块。

输出: 版本感知 read_property_tag, 标志处理, 和集成测试。

**上下文**

@uasset_read.py (现有 FArchive, 计划 02-01 的 PropertyTag)
@.planning/phases/02-property-parsing/02-RESEARCH.md (版本差异)

来自 RESEARCH.md 版本模式:

**UE5 (新格式, >= PROPERTY_TAG_COMPLETE_TYPE_NAME = 1000):**
1. Name (FName)
2. Type (通过 FPropertyTypeName 的完整 TypeName 字符串)
3. Size (int32)
4. Flags (EPropertyTagFlags - 内联 u8)
5. [ArrayIndex] - 如果 HasArrayIndex 标志 (0x01)
6. [PropertyGuid] - 如果 HasPropertyGuid 标志 (0x02)

**UE4 (旧格式, < PROPERTY_TAG_COMPLETE_TYPE_NAME):**
1. Name (FName)
2. Type (仅短 FName)
3. Size (int32)
4. ArrayIndex (int32 - 总是存在)
5. [StructName + StructGuid] - 如果 Type == StructProperty
6. [BoolVal] - 如果 Type == BoolProperty
7. [EnumName] - 如果 Type == ByteProperty 或 EnumProperty
8. [InnerType] - 如果 Type == ArrayProperty/OptionalProperty
9. PropertyGuid (条件性)
10. PropertyExtensions

来自 PropertyTag.h 标志:
- HasArrayIndex = 0x01 → 读取 int32 ArrayIndex
- HasPropertyGuid = 0x02 → 读取 16 字节 PropertyGuid
- HasPropertyExtensions = 0x04 → 跳过扩展数据（推迟到 Phase 3）
- BoolTrue = 0x10 → tag.bool_val = 1

Wave 3 依赖 Wave 2，因为完整 PropertyTag 解析需要完整导出属性循环 (Wave 2) 进行测试。

<action>实现 UE5 PropertyTag 格式读取器 (PropertyTag.cpp 第 436-545 行)。

UE5 格式 (PROPERTY_TAG_COMPLETE_TYPE_NAME >= 1000):
1. 读取 Name 为 FName (archive.read_name(name_map))
2. 读取 Type 为 FString (通过 archive.read_fstring() 的完整 TypeName)
3. 读取 Size 为 int32
4. 读取 Flags 为 u8
5. 如果 Flags & HAS_ARRAY_INDEX: 读取 ArrayIndex (int32), 否则 0
6. 如果 Flags & HAS_PROPERTY_GUID: 读取 PropertyGuid (16 字节), 否则 None
7. 如果 Flags & HAS_BINARY_OR_NATIVE: 跳过（未实现）
8. 如果 Flags & BOOL_TRUE: 设置 tag.bool_val = 1

BoolVal 存储在 tag.bool_val (来自 BoolTrue 标志):
```python
def read_property_tag_ue5(archive: FArchive, name_map: List[str]) -> PropertyTag:
    """读取 UE5 PropertyTag 格式。"""
    tag = PropertyTag()
    tag.name = archive.read_name(name_map)
    tag.type = archive.read_fstring()  # 完整 TypeName
    tag.size = archive.read_i32()
    tag.flags = archive.read_u8()
    tag.array_index = 0
    tag.property_guid = None
    tag.bool_val = 0
    
    if tag.flags & PROP_TAG_HAS_ARRAY_INDEX:
        tag.array_index = archive.read_i32()
    
    if tag.flags & PROP_TAG_HAS_PROPERTY_GUID:
        tag.property_guid = archive.read(16)
    
    # BoolTrue 标志意味着 bool_val = 1
    if tag.flags & PROP_TAG_BOOL_TRUE:
        tag.bool_val = 1
    
    return tag
```
