1. **导入语句**：
   ```python

   import os

2. **常量定义**（来自 UE 源码）：

   UE5_VERSION_MIN = 1000  # D-04: UE5 版本最低值
   LEGACY_FILE_VERSION_MIN = -9
   LEGACY_FILE_VERSION_MAX = -2
   ```

3. **FArchive 类**（D-01 要求单一类，非分层）：
   - 属性：
     - `_file: BinaryIO` — 文件句柄
     - `_path: str` — 文件路径
     - `_byte_swapping: bool = False` — 字节交换标志（D-11）
     - `_file_size: int` — 文件大小（用于边界检查 D-14）
   
   - 方法（使用 struct.unpack 配合显式字节序 '<' 小端）：
     - `__init__(self, path: str)` — 打开文件、获取大小
     - `read(self, size: int) -> bytes` — 基础读取，若 `_byte_swapping` 为 True 则反转字节
     - `seek(self, pos: int) -> None` — 定位（先验证 `pos < self._file_size`，D-14）
     - `tell(self) -> int` — 当前位置
     - `close(self) -> None` — 关闭文件
     - `set_byte_swapping(self, enabled: bool) -> None` — 设置字节交换
     - `read_u8(self) -> int` — `struct.unpack('<B', self.read(1))[0]`
     - `read_i32(self) -> int` — `struct.unpack('<i', self.read(4))[0]`
     - `read_u32(self) -> int` — `struct.unpack('<I', self.read(4))[0]`
     - `read_i64(self) -> int` — `struct.unpack('<q', self.read(8))[0]`
     - `read_u64(self) -> int` — `struct.unpack('<Q', self.read(8))[0]`
     - `read_f32(self) -> float` — `struct.unpack('<f', self.read(4))[0]`
     - `read_fstring(self) -> str` — D-10 仅 UTF-8：读取 int32 长度，若 >0 则 `self.read(length).decode('utf-8').rstrip('\x00')`，若 <0 则返回空字符串，若 ==0 则返回空字符串
     - `read_name(self, name_map: List[str]) -> str` — 读取 u32 索引 + u32 实例号，从 name_map 查找，若 number > 0 则返回 `"{base}_{number}"`

4. **错误处理**（D-15 优雅降级）：
   - 创建 `class UAssetError(Exception)` 自定义异常基类
   - 创建 `class VersionError(UAssetError)` — 版本不支持错误
   - 创建 `class ParseError(UAssetError)` — 解析错误（带部分结果）

5. **边界验证**（D-14）：
   - 在 `seek()` 中：若 `pos > self._file_size`，抛 `ParseError(f"Offset {pos} exceeds file size {self._file_size}")`
   - 在 `read()` 中：若剩余字节不足，抛 `ParseError(f"Cannot read {size} bytes at position {self.tell()}")`
</action>

<action>
在 `uasset_read.py` 中 dataclass 定义之后，创建以下解析函数：

1. **read_package_summary(archive: FArchive) -> PackageFileSummary**：
   - 定位到文件开头 `archive.seek(0)`
   - 读取 tag: `archive.read_u32()`
   - **字节序检测（CORE-02/D-11）**：
     ```python
     if tag == PACKAGE_FILE_TAG_SWAPPED:
         archive.set_byte_swapping(True)
         tag = PACKAGE_FILE_TAG
     elif tag != PACKAGE_FILE_TAG:
         raise VersionError(f"Invalid package tag: {hex(tag)}")
     ```
   - 读取 legacy_file_version: `archive.read_i32()`
   - **版本验证（CORE-08/D-04）**：
     ```python
     if legacy_file_version < LEGACY_FILE_VERSION_MIN or legacy_file_version > LEGACY_FILE_VERSION_MAX:
         raise VersionError(f"Unsupported legacy version: {legacy_file_version}")
     ```
   - 若 legacy_file_version >= -8（UE5+），读取 file_version_ue4、file_version_ue5
   - 读取 file_version_licensee
   - **UE5 版本验证（D-04）**：
     ```python
     if file_version_ue5 < UE5_VERSION_MIN:
         raise VersionError(f"Unsupported UE5 version: {file_version_ue5}")
     ```
   - 读取 custom_versions 数组：count = `archive.read_u32()`，循环读取 guid（16 bytes）+ version
   - 读取 package_flags（D-12 仅存储）
   - 读取 name_count、name_offset
   - 读取 soft_object_paths_count、soft_object_paths_offset
   - 读取 import_count、import_offset
   - 读取 export_count、export_offset
   - 继续读取所有后续字段（参考 PackageFileSummary.h）
   - 返回 PackageFileSummary

2. **read_name_table(archive: FArchive, summary: PackageFileSummary) -> List[str]**（CORE-03/D-09）：
   - 定位到 name_offset: `archive.seek(summary.name_offset)`
   - 循环 name_count 次：
     - 读取字符串（版本自适应）：
       - UE5+ 使用 UTF-8：`archive.read_fstring()`
       - 旧版本可能需要特殊处理（但 D-03 仅 UE5.x）
     - 添加到 name_map 列表
   - 返回 name_map

3. **read_import_map(archive: FArchive, summary: PackageFileSummary, name_map: List[str]) -> List[ObjectImport]**（CORE-04）：
   - 定位到 import_offset: `archive.seek(summary.import_offset)`
   - 循环 import_count 次：
     - class_package: `archive.read_name(name_map)`
     - class_name: `archive.read_name(name_map)`
     - outer_index: `PackageIndex(archive.read_i32())`
     - object_name: `archive.read_name(name_map)`
     - 创建 ObjectImport 添加到列表
   - 返回 import_map

4. **read_export_map(archive: FArchive, summary: PackageFileSummary, name_map: List[str]) -> List[ObjectExport]**（CORE-05）：
   - 定位到 export_offset: `archive.seek(summary.export_offset)`
   - 循环 export_count 次：
     - class_index: `PackageIndex(archive.read_i32())`
     - super_index: `PackageIndex(archive.read_i32())`
     - outer_index: `PackageIndex(archive.read_i32())`
     - object_name: `archive.read_name(name_map)`
     - object_flags: `archive.read_u32()`
     - serial_size: `archive.read_i64()`
     - serial_offset: `archive.read_i64()`
     - 若版本 >= SCRIPT_SERIALIZATION_OFFSET（检查 UE 源码），读取 script_serial_size、script_serial_offset
     - 创建 ObjectExport 添加到列表
   - 返回 export_map

5. **parse_uasset(path: str) -> ParseResult**（主入口）：
   - 创建 FArchive(path)
   - try:
     - summary = read_package_summary(archive)
     - name_map = read_name_table(archive, summary)
     - import_map = read_import_map(archive, summary, name_map)
     - export_map = read_export_map(archive, summary, name_map)
     - 返回 ParseResult(summary=summary, name_map=name_map, import_map=import_map, export_map=export_map, is_success=True)
   - except VersionError as e:
     - 返回 ParseResult(errors=[str(e)], is_success=False)（CORE-08/D-15）
   - except ParseError as e:
     - 返回 ParseResult(errors=[str(e)], summary=summary 若已解析, is_success=False)（D-15 部分结果）
   - finally: archive.close()

6. **get_asset_class(export: ObjectExport, import_map: List[ObjectImport], export_map: List[ObjectExport]) -> Optional[str]**（CORE-06）：
   - 若 export.class_index.is_import: 从 import_map 获取类名
   - 若 export.class_index.is_export: 从 export_map 获取类名
   - 返回类名字符串或 None
</action>

## Success Criteria

Phase 1 成功标准（来自 ROADMAP.md）：

1. **给定**任意有效 .uasset 文件，**当**解析器读取文件头，**则**PackageFileSummary 包含正确的魔术标签（0x9E2A83C1）、版本号（UE5 >= 1000）和偏移（name_offset、import_offset、export_offset）。

2. **给定**带有交换字节序魔术标签（0xC1832A9E）的文件，**当**解析器检测到它，**则**启用字节交换，后续所有读取正确（可验证通过 test_byte_swapping_detection）。

3. **给定**有效 .uasset 文件，**当**解析器读取名称表和映射表，**则**NameMap、ImportMap 和 ExportMap 包含所有条目及正确值（可验证通过 test_name_table_extraction、test_import_map、test_export_map）。

4. **给定**不支持的版本 .uasset（legacy_version=-1 或 ue5_version < 1000），**当**解析器检测版本，**则**返回清晰错误信息而不崩溃（可验证通过 test_unsupported_version）。
