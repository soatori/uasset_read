<objective>
修复 UE4 文件缺失的 LocalizationId 和 GatherableTextData 字段。

**根本原因：** UE4 文件（legacy > -8, FileVersionUE4 >= certain version）在 NameOffset 和 ImportCount 间有两个可选字段：
1. LocalizationId（FString）- NameOffset 后
2. GatherableTextData（Count + Offset）- LocalizationId 后

当前代码跳过这些字段，导致 ImportOffset 读取垃圾值。

**影响：** Lyra Character_Default.uasset（legacy=-7, UE4 v521）失败：
- ImportOffset = 910241842（垃圾值）而非 4776
- ImportCount = 垃圾值，触发边界错误
- 所有 ImportMap/ExportMap 解析失败

**UE 源码参考（PackageFileSummary.cpp lines 289-300）：**
```cpp
// LocalizationId - FString（FileVersionUE >= VER_UE4_ADDED_PACKAGE_SUMMARY_LOCALIZATION_ID）
if (Ar.UE4Version() >= VER_UE4_ADDED_PACKAGE_SUMMARY_LOCALIZATION_ID)
    Ar << Sum.LocalizationId;

// GatherableTextData - Count + Offset（FileVersionUE >= VER_UE4_SERIALIZE_TEXT_IN_PACKAGES）
if (Ar.UE4Version() >= VER_UE4_SERIALIZE_TEXT_IN_PACKAGES)
{
    Ar << Sum.GatherableTextDataCount;
    Ar << Sum.GatherableTextDataOffset;
}

// Import/Export counts and offsets 在这些之后
Ar << Sum.ImportCount << Sum.ImportOffset;
Ar << Sum.ExportCount << Sum.ExportOffset;
```

目的：添加 LocalizationId 和 GatherableTextData 字段以启用 UE4 文件解析。
输出：真实 UE4 文件的正确 ImportOffset/ExportOffset。
</objective>
