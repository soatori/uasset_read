<objective>
Fix LocalizationId and GatherableTextData missing fields for UE4 files.

**Root Cause:** UE4 files (legacy > -8, FileVersionUE4 >= certain version) have two optional fields between NameOffset and ImportCount:
1. LocalizationId (FString) - after NameOffset
2. GatherableTextData (Count + Offset) - after LocalizationId

Current code skips these fields, causing ImportOffset to read garbage value.

**Impact:** Lyra Character_Default.uasset (legacy=-7, UE4 v521) fails:
- ImportOffset = 910241842 (garbage) instead of 4776
- ImportCount = garbage value, triggering bounds error
- All ImportMap/ExportMap parsing fails

**UE Source Reference (PackageFileSummary.cpp lines 289-300):**
```cpp
// LocalizationId - FString (FileVersionUE >= VER_UE4_ADDED_PACKAGE_SUMMARY_LOCALIZATION_ID)
if (Ar.UE4Version() >= VER_UE4_ADDED_PACKAGE_SUMMARY_LOCALIZATION_ID)
    Ar << Sum.LocalizationId;

// GatherableTextData - Count + Offset (FileVersionUE >= VER_UE4_SERIALIZE_TEXT_IN_PACKAGES)
if (Ar.UE4Version() >= VER_UE4_SERIALIZE_TEXT_IN_PACKAGES)
{
    Ar << Sum.GatherableTextDataCount;
    Ar << Sum.GatherableTextDataOffset;
}

// Import/Export counts and offsets come AFTER these
Ar << Sum.ImportCount << Sum.ImportOffset;
Ar << Sum.ExportCount << Sum.ExportOffset;
```

Purpose: Add LocalizationId and GatherableTextData fields to enable UE4 file parsing.
Output: Correct ImportOffset/ExportOffset for real UE4 files.
</objective>
