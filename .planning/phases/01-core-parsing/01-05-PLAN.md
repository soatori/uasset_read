<objective>
Fix two blocker bugs preventing real UE5 file parsing:

1. **Missing PackageName FString field** - Parser jumps from TotalHeaderSize directly to PackageFlags, missing the PackageName FString that exists in all UE4/UE5 files.

2. **Incorrect inline names condition** - Condition `legacy >= -5` incorrectly triggers inline names handling for legacy=-7, when NameOffset should always be read for modern files (legacy < 0).

Purpose: Enable parsing of real UE5 files like Lyra Character_Default.uasset.
Output: Correct header field sequence matching UE PackageFileSummary.cpp.
</objective>
