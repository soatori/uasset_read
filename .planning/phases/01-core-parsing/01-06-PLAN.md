    **当前代码：**
    ```python
    if length < 0:
        # UTF-16 encoding（legacy format，UE5 deprecated）
        self.read(-length * 2)  # 潜在溢出
        return ""
    ```

    **修复后代码：**
    ```python
    if length < 0:
        # UTF-16 encoding（legacy format，UE5 deprecated）
        utf16_len = -length * 2
        if utf16_len > 10_000_000:  # 溢出合理性检查
            raise ParseError(f"UTF-16 string length {utf16_len} too large")
        self.read(utf16_len)
        return ""
    ```

    **注意：** 对于 length = INT_MIN（-2147483648），-length * 2 = 4GB 读取会失败。
    合理性检查在尝试读取前防止此边缘情况。
