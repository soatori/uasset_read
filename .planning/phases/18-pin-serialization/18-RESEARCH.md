# Phase 18: Pin序列化解析 - Research

**Researched:** 2026-05-04
**Domain:** UE 5.7 UEdGraphPin 序列化格式解析
**Confidence:** HIGH

## Summary

Phase 18 需要修复 UEdGraphPin 序列化解析，使其与 UE 5.7 源码完全一致。根因分析表明当前实现存在严重问题：

1. **序列化顺序错误**: 当前实现跳过了 OwningNode、PinToolTip、DefaultObject、DefaultTextValue 等关键字段，导致后续字段读取位置错位
2. **LinkedTo 格式完全错误**: 当前仅读取 PinId GUID，实际上应读取完整的 Pin 引用结构（OwningNode + PinGuid + 条件序列化）
3. **版本依赖缺失**: 多个字段依赖 FFrameworkObjectVersion、FUE5MainStreamObjectVersion 等 CustomVersion 检查
4. **BitField 格式错误**: 当前读取 u8，实际上应读取 uint32（包含 8 persistent bits + transient bits）
5. **WITH_EDITORONLY_DATA 处理缺失**: 很多字段仅在编辑器模式下序列化

**Primary recommendation:** 按 UE 源码 EdGraphPin.cpp L1838-1964 的完整序列化顺序重新实现，包括版本检查、EditorOnly 处理、BitField 解析。

```cpp
{
    // 1. bNullPtr flag [L2137-2144]
    bool bNullPtr = (PinRef == nullptr);
    Ar << bNullPtr;  // bool (serialized as uint8)

    if (!bNullPtr)
    {
        // 2. OwningNode (UEdGraphNode*) [L2175-2176]
        UEdGraphNode* LocalOwningNode = nullptr;
        Ar << LocalOwningNode;  // FPackageIndex reference

        // 3. PinGuid (FGuid - 16 bytes) [L2177]
        FGuid PinGuid;
        Ar << PinGuid;  // 16 bytes

        // ResolveType determines handling [L2193-2291]
        if (ResolveType == EPinResolveType::OwningNode)
        {
            // OwningNode type: full pin serialization
            if (Ar.IsLoading())
            {
                // Create or reuse pin instance
                PinRef = UEdGraphPin::CreatePin(LocalOwningNode);
            }
            PinRef->Serialize(Ar);  // Recursively serialize full pin
        }
        else
        {
            // LinkedTo/SubPins/ParentPin type: reference only
            // Lookup existing pin by OwningNode + PinGuid
            // Store unresolved reference if pin not yet loaded
        }
    }

    return true;
}
```

- **LinkedTo/SubPins**: 存储 `bNullPtr + OwningNode + PinGuid`（引用格式）
- **OwningNode**: 存储 `bNullPtr + OwningNode + PinGuid + CompletePin`（完整序列化）

### Pattern 1: 版本条件序列化

**What:** UE 使用 CustomVersion 决定是否序列化特定字段。

**When to use:** 每个新增字段都需要检查版本阈值。

**Example:**
```python
# Source: EdGraphPin.cpp L1847-1856
if summary.custom_version.get(FFrameworkObjectVersion.GUID, 0) >= FFrameworkObjectVersion.PinsStoreFName:
    pin_name = archive.read_name(name_map)  # FName (int32)
else:
    pin_name = archive.read_fstring()  # FString (legacy)
```

### Pattern 2: EditorOnly 字段处理

**What:** WITH_EDITORONLY_DATA 字段仅在编辑器资产中存在。

**When to use:** 对于 cooked 资产，跳过这些字段；对于编辑器资产，必须读取。

**Example:**
```python
# Source: EdGraphPin.cpp L1858-1863, L1894-1948
# 假设编辑器资产（未 cooked），必须读取
if not is_cooked_asset:
    # PinFriendlyName (FText)
    pin_friendly_name = read_ftext(archive)

    # PersistentGuid (FGuid)
    persistent_guid_bytes = archive.read_bytes(16)
    persistent_guid = persistent_guid_bytes.hex()

    # BitField (uint32)
    bitfield = archive.read_u32()
    hidden = bool(bitfield & (1 << 0))
    not_connectable = bool(bitfield & (1 << 1))
    advanced_view = bool(bitfield & (1 << 4))
    orphaned_pin = bool(bitfield & (1 << 5))
```

### Pattern 3: SerializePin 引用格式

**What:** LinkedTo/SubPins 数组存储 Pin 引用，而非完整 Pin。

**When to use:** 对于 LinkedTo、SubPins、ParentPin 字段。

**Example:**
```python
# Source: EdGraphPin.cpp L2132-2296
def read_pin_reference(archive, name_map):
    """读取 Pin 引用格式（用于 LinkedTo/SubPins/ParentPin）"""
    b_null_ptr = archive.read_bool()
    if b_null_ptr:
        return None

    owning_node_index = archive.read_i32()  # FPackageIndex
    pin_guid_bytes = archive.read_bytes(16)
    pin_guid = pin_guid_bytes.hex()

    return {
        "owning_node": owning_node_index,
        "pin_guid": pin_guid
    }
```

### Anti-Patterns to Avoid

- **跳过 OwningNode**: 当前实现从 PinId 开始，导致所有后续字段错位
- **LinkedTo 仅读 PinId**: 缺失 OwningNode 引用，无法构建连接映射
- **BitField 读 u8**: 实际是 uint32，读取错误导致后续字段错位
- **忽略版本检查**: 多个字段依赖版本，跳过检查导致读取错误格式

## Common Pitfalls

### Pitfall 1: OwningNode 字段跳过

**What goes wrong:** 当前实现从 PinId 开始读取，跳过了 OwningNode 字段。

**Why it happens:** Phase 7 实现时未完整对照 UE 源码，假设 OwningNode 是节点持有者信息而非 Pin 序列化字段。

**How to avoid:**
1. 按 EdGraphPin.cpp L1844 开始读取 OwningNode
2. OwningNode 是 FPackageIndex（int32），指向本节点自身

**Warning signs:** LinkedTo 引用解析失败、BitField 值异常（超出 0-255 范围）

### Pitfall 2: LinkedTo 格式错误

**What goes wrong:** 当前仅读取 PinId GUID，缺失 OwningNode 引用。

**Why it happens:** 假设 LinkedTo 存储的是 PinId GUID 列表，但实际上是 SerializePin 引用格式。

**How to avoid:**
1. LinkedTo 使用 SerializePinArray 格式
2. 每个元素：`bNullPtr + OwningNode + PinGuid`
3. OwningNode 是 FPackageIndex，需要解析为节点名称

**Warning signs:** 连接映射构建失败（Phase 19 无法找到目标节点）

### Pitfall 3: BitField 类型错误

**What goes wrong:** 当前读取 u8，实际上应读取 uint32。

**Why it happens:** 假设 flags 是单字节 bitfield，但实际上是 uint32（包含 8 persistent bits + transient bits）。

**How to avoid:**
1. 读取 uint32 BitField
2. 按位提取显示属性（bit 0-7）
3. transient bits（bit 8-10）仅在 transacting 时有效

**Warning signs:** flags 值超出 0-255、后续字段读取失败

### Pitfall 4: 版本检查缺失

**What goes wrong:** 跳过版本检查，导致字段格式错误。

**Why it happens:** 假设所有资产使用最新格式，但实际上旧版本资产使用不同格式。

**How to avoid:**
1. 检查 CustomVersion 阈值
2. 根据版本决定字段格式（FName vs FString）
3. 条件读取版本依赖字段（SourceIndex、bIsConst 等）

**Warning signs:** FName 解析失败、字段缺失或多余

```python
    archive: FArchive,

    1. OwningNode (FPackageIndex)
    2. PinId (FGuid)
    3. PinName (FName/FString) - version dependent
    4. [PinFriendlyName] (FText) - EditorOnly
    5. [SourceIndex] (int32) - version dependent
    6. PinToolTip (FString)
    7. Direction (uint8)
    8. PinType (FEdGraphPinType)
    9. DefaultValue (FString)
    10. AutogeneratedDefaultValue (FString)
    11. DefaultObject (FPackageIndex)
    12. DefaultTextValue (FText)
    13. LinkedTo (SerializePinArray)
    14. SubPins (SerializePinArray)
    15. ParentPin (SerializePin)
    16. ReferencePassThroughConnection (SerializePin)
    17. [PersistentGuid] (FGuid) - EditorOnly
    18. [BitField] (uint32) - EditorOnly
    """

    framework_version = summary.custom_version.get(FFrameworkObjectVersion.GUID, 0)

    # 1. OwningNode (FPackageIndex) [L1844]
    owning_node_index = archive.read_i32()
    # owning_node_index 指向本节点自身，可用于验证

    # 2. PinId (FGuid 16 bytes) [L1845]
    pin_id_bytes = archive.read_bytes(16)
    pin_id = pin_id_bytes.hex()

    # 3. PinName (version dependent) [L1847-1856]
    if framework_version >= FFrameworkObjectVersion.PinsStoreFName:

    pin_friendly_name = None

    # 5. SourceIndex (int32) - version dependent [L1865-1868]
    source_index = None
    if mainstream_version >= FUE5MainStreamObjectVersion.EdGraphPinSourceIndex:
        source_index = archive.read_i32()

    # 6. PinToolTip (FString) [L1870]
    pin_tooltip = archive.read_fstring()

    # 7. Direction (uint8) [L1871]
    direction = archive.read_u8()  # 0=EGPD_Input, 1=EGPD_Output

    # 8. PinType (FEdGraphPinType) [L1872]
    pin_type = read_ed_graph_pin_type(archive, name_map, summary)

    # 9-10. DefaultValue strings [L1873-1874]
    default_value = archive.read_fstring()
    autogenerated_default_value = archive.read_fstring()

    default_object_index = archive.read_i32()
    default_object = resolve_fpackage_index(default_object_index, export_map, name_map)

    default_text_value = read_ftext(archive)

    # 13. LinkedTo (SerializePinArray) [L1886]
    linked_to = read_pin_array(archive, name_map, export_map)

    # 14. SubPins (SerializePinArray) [L1889]
    sub_pins = read_pin_array(archive, name_map, export_map)

    parent_pin = read_pin_reference(archive, name_map, export_map)

    # 不在需求范围，但需要读取用于位置同步
    ref_pass_through = read_pin_reference(archive, name_map, export_map)

    # 17-18. EditorOnly fields [L1894-1948]
    persistent_guid = None
    hidden = False
    not_connectable = False
    advanced_view = False
    orphaned_pin = False

    if not summary.is_cooked:
        # 17. PersistentGuid (FGuid) [L1897]
        persistent_guid_bytes = archive.read_bytes(16)
        persistent_guid = persistent_guid_bytes.hex()

        # 18. BitField (uint32) [L1902-1942]
        bitfield = archive.read_u32()
        hidden = bool(bitfield & (1 << 0))
        not_connectable = bool(bitfield & (1 << 1))
        advanced_view = bool(bitfield & (1 << 4))
        orphaned_pin = bool(bitfield & (1 << 5))

    return UEdGraphPin(
        pin_id=pin_id,
        pin_name=pin_name,
        pin_tooltip=pin_tooltip,
        direction=direction,
        pin_type=pin_type,
        default_value=default_value,
        autogenerated_default_value=autogenerated_default_value,
        default_object=default_object,
        default_text_value=default_text_value,
        linked_to_raw=linked_to,
        sub_pins=sub_pins,
        parent_pin=parent_pin,
        source_index=source_index,
        persistent_guid=persistent_guid,
        hidden=hidden,
        not_connectable=not_connectable,
        advanced_view=advanced_view,
        orphaned_pin=orphaned_pin
    )
```

```python
# Source: EdGraphPin.cpp L2132-2296
def read_pin_reference(archive: FArchive, name_map: List[str], export_map: List[ObjectExport]) -> Optional[dict]:
    """
    读取单个 Pin 引用（用于 LinkedTo/SubPins/ParentPin）。

    格式：
    1. bNullPtr (bool)
    2. OwningNode (FPackageIndex)
    3. PinGuid (FGuid)
    """
    b_null_ptr = archive.read_bool()
    if b_null_ptr:
        return None

    owning_node_index = archive.read_i32()
    pin_guid_bytes = archive.read_bytes(16)
    pin_guid = pin_guid_bytes.hex()

    # 解析 OwningNode 为节点名称
    owning_node_name = resolve_fpackage_index(owning_node_index, export_map, name_map)

    return {
        "node": owning_node_name,
        "pin_guid": pin_guid
    }

def read_pin_array(archive: FArchive, name_map: List[str], export_map: List[ObjectExport]) -> List[dict]:
    """
    读取 Pin 引用数组（LinkedTo/SubPins）。

    格式：
    1. ArrayNum (int32)
    2. For each: PinReference
    """
    array_num = archive.read_i32()
    if array_num < 0 or array_num > MAX_LINKEDTO_PER_PIN:
        raise ParseError(f"Invalid pin array count: {array_num}")

    pins = []
    for _ in range(array_num):
        pin_ref = read_pin_reference(archive, name_map, export_map)
        if pin_ref:
            pins.append(pin_ref)

    return pins
```
