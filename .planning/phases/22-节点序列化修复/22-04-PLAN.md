将第 2385 行的 import 类型字段选择从 class_name 改为 object_name。

**当前代码 (错误):**
```python
if class_index.is_import:
    import_idx = class_index.to_import_index()
    if 0 <= import_idx < len(import_map):
        return import_map[import_idx].class_name  # ← 错误：返回类型名而非对象名
```

**修复为:**
```python
if class_index.is_import:
    import_idx = class_index.to_import_index()
    if 0 <= import_idx < len(import_map):
        return import_map[import_idx].object_name  # ← 正确：返回对象名
```

**原因:**
- class_name 字段存储的是导入对象的类型名（如 "Class", "Package"）
- object_name 字段存储的是对象名称（如 "K2Node_InputAction", "EdGraph"）
- 节点的类型判断需要 object_name，而非 class_name

**示例:**
```
ImportMap entry:
  class_name: "Class"        # 类型名（无用）
  object_name: "K2Node_InputAction"  # 对象名（有用）

resolve_class_name 应返回 "K2Node_InputAction"，而非 "Class"
```
