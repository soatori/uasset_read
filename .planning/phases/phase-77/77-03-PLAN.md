Create `src/uasset_read/pak/crypto.py`:

**decrypt_aes_ecb(data: bytes, key: bytes) -> bytes:**
- Validate key length: must be 16 bytes (128-bit). Raise `ValueError("AES key must be 16 bytes (128-bit)")` if not.
- Compute aligned_size = `(len(data) + 15) & ~15`
- If len(data) < aligned_size: pad data with zero bytes to aligned_size
- Lazy import: `from cryptography.hazmat.primitives.ciphers import Cipher, algorithms`
  - Wrap in try/except ImportError: `raise ImportError("AES decryption requires 'cryptography' package. Install with: pip install uasset_read[pak]")`
- Create cipher: `Cipher(algorithms.AES(key), None)` — ECB mode (no mode parameter = ECB in cryptography library)
- Decrypt: `decryptor.update(padded_data) + decryptor.finalize()`
- Return result trimmed to original len(data) (strip padding)

**validate_index_hash(decrypted_index_blob: bytes, expected_hash: bytes) -> bool:**
- Compute `hashlib.sha1(decrypted_index_blob).digest()` (20 bytes)
- Return `computed_hash == expected_hash`

**decrypt_index_blob(index_data: bytes, key: bytes, expected_hash: bytes) -> bytes:**
- Convenience wrapper: decrypt_aes_ecb(index_data, key), then validate_index_hash on result
- If hash validation fails: raise `ParseError("Index hash mismatch — decrypted index blob is corrupted or wrong AES key")`
- Return decrypted blob on success

Add `__all__ = ["decrypt_aes_ecb", "validate_index_hash", "decrypt_index_blob"]`.

Update `src/uasset_read/pak/__init__.py` to export these functions.
