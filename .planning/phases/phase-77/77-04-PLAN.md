Create `src/uasset_read/pak/index.py` with index parsing functions. This module handles the index blob that lives at FPakInfo.index_offset with size FPakInfo.index_size.

**read_fstring(stream) -> str:** Re-use from structures.py (already implemented in Plan 01).

**parse_primary_index(stream: BinaryIO, pak_info: FPakInfo, aes_key: bytes | None = None) -> tuple[str, list[FPakEntry], dict]:**
Main entry point for index parsing. Steps:

1. Seek to pak_info.index_offset, read pak_info.index_size bytes as index_blob
2. If pak_info.encrypted_index:
   - If aes_key is None: raise `UAssetError("Encrypted index requires AES key")`
   - Decrypt: index_blob = decrypt_index_blob(index_blob, aes_key, pak_info.index_hash)
3. Else: validate hash with validate_index_hash(index_blob, pak_info.index_hash) — if mismatch, raise ParseError
4. Create BytesIO(index_blob) as index_stream
5. Read mount_point = read_fstring(index_stream)
6. Read num_entries = struct.unpack('<i', index_stream.read(4))[0]
7. Branch by version:
   - **Version < 10 (legacy):** For i in range(num_entries): path = read_fstring(index_stream), entry = FPakEntry.deserialize_legacy(index_stream, pak_info.version). Append (path, entry) to list. Return (mount_point, entries_dict, {})
   - **Version >= 10 (PathHashIndex):**
     - Read PathHashSeed = struct.unpack('<Q', index_stream.read(8))[0]
     - Read bHasPathHashIndex = bool(index_stream.read(1))
     - If bHasPathHashIndex: read PathHashIndexOffset, PathHashIndexSize (int64 each), then parse path hash index from those offsets in the original file stream (not index_blob). The path hash index is a TMap<uint64 hash, FPakEntryLocation>. For each entry: hash_value (uint64), then location (file_offset int64, size int64).
     - Read bHasDirectoryIndex = bool(index_stream.read(1))
     - If bHasDirectoryIndex: similar to path hash index — read offsets, parse directory index
     - Read EncodedPakEntries: first read num_encoded_entries (uint32), then for each: decode_bitfield from index_stream using pak_info. Store decoded entries in a dict keyed by their path hash.
     - Read NonEncodedEntries: first read num_non_encoded (uint32), then for each: path = read_fstring, entry = decode_bitfield. These have explicit paths.
     - Return (mount_point, all_entries_dict, {"path_hash_index": ..., "directory_index": ...})

**parse_path_hash_index(stream: BinaryIO, offset: int, size: int, pak_info: FPakInfo) -> dict[int, tuple[int, int]]:**
- Seek to offset in file stream, read size bytes
- Parse TMap: num_entries (uint32), then for each: key=uint64 (path hash), value=FPakEntryLocation (file_offset=int64, size=int64)
- Return dict mapping hash -> (file_offset, size)

**parse_directory_index(stream: BinaryIO, offset: int, size: int, pak_info: FPakInfo) -> dict[str, dict[str, tuple[int, int]]:**
- Similar to path hash index but with FString keys
- Return nested dict: directory -> {filename -> (file_offset, size)}

```python
class PakFileReader:
    """
    Main reader for .pak files.

    Usage:
        reader = PakFileReader("game.pak")
        info = reader.info  # FPakInfo
        entries = reader.entries  # dict[path, FPakEntry]
        files = reader.list_files()  # list[str]
        data = reader.extract("path/to/file.txt")  # bytes
    """

    def __init__(self, path: str, aes_key: bytes | None = None, tolerant: bool = False):
        self._path = path
        self._aes_key = aes_key
        self._tolerant = tolerant
        self._file: BinaryIO | None = None
        self._file_size: int = 0
        self._info: FPakInfo | None = None
        self._entries: dict[str, FPakEntry] = {}
        self._mount_point: str = ""
        self._directory_index: dict = {}

    def open(self) -> None:
        """Open the .pak file and parse FPakInfo + Primary Index."""
        # 1. Open file, get file_size
        # 2. Read FPakInfo: FPakInfo.deserialize(stream, file_size)
        # 3. Read index blob: seek to info.index_offset, read info.index_size bytes
        # 4. If encrypted: decrypt_index_blob(index_blob, aes_key, info.index_hash)
        # 5. Validate hash
        # 6. Parse index: parse_primary_index(stream, info, aes_key)
        # 7. Store mount_point, entries, directory_index

    def close(self) -> None:
        """Close the file handle."""

    def __enter__(self) -> "PakFileReader":
        self.open()
        return self

    def __exit__(self, *args) -> None:
        self.close()

    @property
    def info(self) -> FPakInfo | None:
        """Return parsed FPakInfo (None if not opened)."""

    @property
    def entries(self) -> dict[str, FPakEntry]:
        """Return path -> FPakEntry mapping."""

    @property
    def mount_point(self) -> str:
        """Return the mount point from the primary index."""

    def list_files(self) -> list[str]:
        """Return list of all file paths in the pak (excluding deleted entries)."""
        return [p for p, e in self._entries.items() if not e.is_deleted]

    def get_entry(self, path: str) -> FPakEntry | None:
        """Get FPakEntry for a specific path. Returns None if not found."""

    def extract(self, path: str) -> bytes | None:
        """
        Extract a file entry from the pak.
        Returns raw bytes (decompressed if entry was compressed).
        Returns None if path not found.
        """
        # 1. Get entry from self._entries
        # 2. If entry.is_deleted: raise UAssetError("Entry is deleted")
        # 3. Seek to entry.offset + entry.serialized_size
        # 4. If not entry.is_compressed: read entry.uncompressed_size bytes
        # 5. If compressed: decompress_entry(stream, entry, self._aes_key)
        # 6. Return bytes
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .pak file → PakFileReader.open() | Untrusted binary input; all offsets validated against file_size |
| Index blob → parse_primary_index | Index may be malformed; SHA1 hash validation required |
| Entry extraction → decompress_entry | Compressed blocks validated before decompression |
| AES key → decrypt_index_blob | User-provided; no storage or logging |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-77-13 | Tampering | parse_primary_index hash validation | mitigate | SHA1 validation before parsing entries; reject on mismatch |
| T-77-14 | Elevation of Privilege | PakFileReader entry offset validation | mitigate | Validate entry.offset + entry.size <= file_size before any seek/read |
| T-77-15 | Denial of Service | extract() on large entries | mitigate | Log entry size before extraction; tolerant mode can skip entries > threshold |
| T-77-16 | Information Disclosure | PakFileReader._aes_key | mitigate | Key stored as instance attribute only; never serialized or logged |
| T-77-17 | Spoofing | Mount point parsing | mitigate | Validate mount_point contains only printable characters after read_fstring; reject if contains null bytes in middle |
| T-77-SC | Tampering | pip installs (all pak deps) | mitigate | Already gated by Plans 02/03 checkpoints |
</threat_model>
