  <action>
Create `src/uasset_read/pak/decompress.py`:

**decompress_block(data: bytes, uncompressed_size: int, method: str) -> bytes:**
- Dispatch based on method string name (from FPakInfo.compression_methods table or "None")
- "None" or "": return data[:uncompressed_size]
- "Zlib": `zlib.decompress(data, wbits=-15)` — raw deflate, no header (matches UE)
- "LZ4": lazy import `lz4.block`; `lz4.block.decompress(data, uncompressed_size=uncompressed_size)`
- "Zstd": lazy import `zstandard`; `zstandard.decompress(data, max_output_size=uncompressed_size)`
- "Oodle": raise `NotImplementedError("Oodle decompression requires oo2core library — not available as open-source Python package. See https://github.com/Kaldaien/Oodle for proprietary options.")`
- Any other: raise `ValueError(f"Unknown compression method: {method}")`
- Each import wrapped in try/except ImportError with helpful message: `raise ImportError(f"LZ4 decompression requires 'lz4' package. Install with: pip install uasset_read[pak]")`

**decompress_entry(stream: BinaryIO, entry: FPakEntry, encryption_key: bytes | None = None) -> bytes:**
- If not entry.is_compressed: seek to entry.offset + entry.serialized_size (or entry.StructSize per legacy), read entry.uncompressed_size bytes, return
- If compressed: iterate over entry.compression_blocks
  - For each block: seek to block.compressed_start
  - block_size = block.compressed_end - block.compressed_start
  - alignment = 16 if entry.is_encrypted else 1
  - aligned_size = (block_size + alignment - 1) & ~(alignment - 1)
  - Read aligned_size bytes from stream
  - If encrypted and encryption_key provided: defer to Plan 04 integration (crypto module from Plan 03). TODO: from uasset_read.pak.crypto import decrypt_aes_ecb
  - Decompress block using decompress_block with method from entry
  - Append to result buffer
- Return concatenated bytes
- Log warning for Oodle blocks: skip decompression, log method name and entry path if available

Add `__all__ = ["decompress_block", "decompress_entry"]` to the module.

Update `src/uasset_read/pak/__init__.py` to export decompress_block and decompress_entry.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Compressed block data → decompressor | Untrusted input; decompression bombs possible |
| Block size fields → alignment calculation | Tampered sizes could cause out-of-bounds reads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-77-07 | Denial of Service | decompress_block (Zlib) | mitigate | Use wbits=-15 (raw deflate, no header) to prevent zlib header allocation attacks; limit output to uncompressed_size |
| T-77-08 | Denial of Service | decompress_block (LZ4/Zstd) | mitigate | Pass uncompressed_size/max_output_size to prevent decompression bombs |
| T-77-09 | Tampering | Block offset calculation | mitigate | Validate block.compressed_start and block.compressed_end against file_size before seeking |
| T-77-SC | Tampering | pip installs (lz4, zstandard) | mitigate | Gated behind checkpoint:human-verify per Package Legitimacy Audit in RESEARCH.md |
</threat_model>
