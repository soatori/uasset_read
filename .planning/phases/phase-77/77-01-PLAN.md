**FPakCompressedBlock** (simplest, define first):

```python
@dataclass
class FPakCompressedBlock:

    compressed_end: int    # int64 — exclusive end offset
```

**FPakEntry** (core data structure):
```python
@dataclass
class FPakEntry:
    offset: int                    # int64 — file offset where entry data starts
    uncompressed_size: int         # int64 — size of uncompressed data
    size: int                      # int64 — compressed size (== uncompressed_size if not compressed)
    compression_method_index: int  # uint32 — index into FPakInfo.compression_methods
    is_encrypted: bool             # from bitfield or flag
    is_compressed: bool            # derived from compression_method_index > 0
    compression_block_count: int   # uint16/uint32 depending on version
    compression_block_size: int    # uint32 — size of each compression block (uncompressed)
    compression_blocks: list[FPakCompressedBlock] = field(default_factory=list)
    hash: bytes = b""              # 20 bytes — SHA1 of uncompressed data
    flags: int = 0                 # raw flags (Flag_Encrypted, Flag_Deleted)
    is_deleted: bool = False       # derived from flags
    # Version >= 10 bitfield fields:
    serialized_size: int = 0       # size this entry occupied in the encoded index
```

Deserialization methods for FPakEntry:
- `deserialize_legacy(stream, version)` — reads full struct: Offset(int64), UncompressedSize(int64), Size(int64), CompressionMethodIndex(uint32), CompressionBlockCount(uint16 if v<8 else uint32), CompressionBlockSize(uint32), CompressionBlocks[array], Hash[20 bytes]. Per UE `FPakEntry::Serialize`.
- `decode_bitfield(data: bytes, offset: int, pak_info: FPakInfo) -> tuple[FPakEntry, int]` — decodes bitfield-encoded entry (v10+). Returns (entry, bytes_consumed). Bitfield layout from RESEARCH.md Pattern 2: Bit 31=offset fits 32-bit, Bit 30=uncompressed size fits 32-bit, Bit 29=size fits 32-bit, Bits 23-28=compression method index (6 bits), Bit 22=encrypted, Bits 6-21=block count (16 bits), Bits 0-5=block size index (6 bits, 0x3F=read from stream). After bitfield: read actual uint64 values for fields that don't fit in 32-bit, then compression block offsets.

**FPakInfo** (trailer structure):
```python
@dataclass
class FPakInfo:
    magic: int = PAK_FILE_MAGIC
    version: int = 0
    index_offset: int = 0        # int64 — offset of primary index in file
    index_size: int = 0          # int64 — size of index blob
    index_hash: bytes = b""      # 20 bytes — SHA1 of index blob
    encryption_key_guid: bytes = b""  # 16 bytes, version >= 7
    encrypted_index: bool = False     # version >= 7
    compression_methods: list[str] = field(default_factory=list)  # up to 5 names, version >= 8
    index_is_frozen: bool = False      # version 9 only
```

Deserialization: `deserialize(stream, file_size: int) -> FPakInfo`
- Algorithm from RESEARCH.md Pattern 1: iterate versions from latest (12) to earliest (1), compute `pos = file_size - serialized_size(version)`, seek to pos, read raw bytes, check magic. If magic matches, deserialize remaining fields in UE order and return. If no version matches, raise `ParseError("Unknown .pak format")`.
- Deserialization order for matched version: new fields first (EncryptionKeyGuid[16] + bEncryptedIndex[1] for v>=7), then core fields (Magic[4] + Version[4] + IndexOffset[8] + IndexSize[8] + IndexHash[20]), then FrozenIndex[1] for v9 only, then CompressionMethods[32*5] for v>=8.

**FPakDirectoryEntry** (directory tree node):
```python
@dataclass
class FPakDirectoryEntry:
    path: str                    # directory path
    filename: str                # file name within directory
    entry: FPakEntry             # the actual entry data
```

**read_fstring(stream) -> str** helper function:
- Read int32 length. If length == 0: return empty string.
- If length > 0: read `length` ANSI bytes + 1 null terminator byte. Decode as ANSI.
- If length < 0: read `abs(length) * 2` UTF-16LE bytes + 2 null terminator bytes. Decode as UTF-16LE.
- Raise `ParseError` if length > MAX_FSTRING_LENGTH (10MB).
- Note: version 12 may use FUtf8String — handle as UTF-8 if version >= 12 (read length as uint32, read length bytes of UTF-8 + 1 null terminator).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .pak file → PakFileReader | Untrusted binary input; all offsets and sizes must be bounds-checked |
| Index blob → FPakInfo | Index may be tampered; SHA1 hash validation required after decryption |
| Compressed blocks → decompressor | Block size must be validated against decompression bounds |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-77-01 | Tampering | FPakInfo.deserialize | mitigate | SHA1(index_blob) == IndexHash validation after parsing; reject if hash mismatch |
| T-77-02 | Spoofing | PAK_FILE_MAGIC check | mitigate | Verify magic == 0x5A6F12E1 exactly; reject files without valid magic |
| T-77-03 | Elevation of Privilege | FPakEntry offset/size fields | mitigate | Bounds-check all offsets against file_size before seeking; raise ParseError if offset+size > file_size |
| T-77-04 | Denial of Service | Compression block decompression | mitigate | Limit decompressed size to entry.uncompressed_size; use wbits=-15 for raw deflate (no header allocation attacks) |
| T-77-05 | Information Disclosure | FString parsing | mitigate | Enforce MAX_FSTRING_LENGTH (10MB) cap; reject oversized strings |
| T-77-06 | Tampering | Encrypted index | mitigate | If bEncryptedIndex=True but no AES key provided, raise UAssetError rather than attempting to parse garbage |
| T-77-SC | Tampering | pip installs (cryptography, lz4, zstandard) | mitigate | Gated behind checkpoint:human-verify per Package Legitimacy Audit in RESEARCH.md |
</threat_model>
