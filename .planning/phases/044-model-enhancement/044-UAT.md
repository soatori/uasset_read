### Issue #1: resolve_package_index_to_reference Import Error

**Source:** `src/uasset_read/parsers/property_parser.py:218`

**Root Cause:**  
The function `resolve_package_index_to_reference` is imported from `uasset_read.serializers.object_resources` but does not exist in that module. This is a **Phase 43 pre-existing bug** unrelated to Phase 44.

**Analysis:**
- Phase 43 added `PackageLinker.resolve_package_index()` method in `src/uasset_read/link/linker.py:123`
- Phase 43 also added `resolve_package_index_to_reference()` call in `property_parser.py:218-220`
- The actual implementation of `resolve_package_index_to_reference()` is missing
- Alternative: Use `PackageLinker.resolve_package_index()` when linker is available
- Fallback: Use `import_map` / `export_map` / `name_map` directly when linker is not available

**Fix Strategy:**  
Add the missing function to `src/uasset_read/serializers/object_resources.py`:
```python
def resolve_package_index_to_reference(
    pkg_idx: PackageIndex,
    import_map: List[ObjectImport],
    export_map: List[ObjectExport],
    name_map: List[str]
) -> Optional[Dict[str, Any]]:
    """Resolve PackageIndex to reference dict using raw maps (no linker)."""
    if pkg_idx.is_null:
        return None
    if pkg_idx.is_import:
        idx = pkg_idx.to_import_index()
        if 0 <= idx < len(import_map):
            imp = import_map[idx]
            return {
                "source": "import_map",
                "import_index": idx,
                "object_name": imp.object_name,
                "class_name": imp.class_name,
                "outer_name": imp.package_name or imp.class_package,
            }
    if pkg_idx.is_export:
        idx = pkg_idx.to_export_index()
        if 0 <= idx < len(export_map):
            exp = export_map[idx]
            return {
                "source": "export_map",
                "export_index": idx,
                "object_name": exp.object_name,
                "class_name": get_asset_class_with_linker(exp, None, import_map, export_map, name_map),
            }
    return None
```

**Impact:**  
This bug blocks **Test 8 (Smoke Test)** in Phase 44, preventing full linker-based parsing of real assets.  
The bug is in Phase 43, but causes Phase 44's UAT to be incomplete.
