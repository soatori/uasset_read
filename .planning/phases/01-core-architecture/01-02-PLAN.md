    6. **新增 FString 读取方法（per checker 修复要求）**：
       ```python
       def read_fstring(self) -> str:
           """读取 UE FString。
           
           UE FString 序列化格式：
           - int32 Length：字符串长度（负数表示 UTF-16 编码）
           - char[] Data：字符串数据（UTF-8 或 UTF-16）
           - char NullTerminator：末尾的 null 字符（不包含在返回值中）
           
           Source: Runtime/Core/Public/UObject/NameTypes.h
           Source: Runtime/Core/Private/UObject/UnrealString.cpp
           """
           length = self.read_int32()
           if length == 0:
               return ""
           
           # 负数表示 UTF-16 编码
           is_utf16 = length < 0
           char_count = abs(length)
           
           if is_utf16:
               # UTF-16 编码：每个字符 2 字节
               data = self._file.read(char_count * 2)
               self._position += char_count * 2
               # UE 使用 UTF-16LE
               return data.decode('utf-16-le').rstrip('\x00')
           else:
               # UTF-8 编码
               data = self._file.read(char_count)
               self._position += char_count
               # 去掉末尾的 null terminator
               return data.rstrip(b'\x00').decode('utf-8')
       ```
