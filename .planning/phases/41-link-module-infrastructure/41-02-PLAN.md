**文件头：**
```python
"""PackageLinker — two-phase loading coordinator.

Mirrors UE's FLinkerLoad pattern: link() creates UObjectInstance shells,
preload(index) lazily deserializes properties on demand.
"""
```

**Imports:**
- `from __future__ import annotations`
- `from typing import TYPE_CHECKING, List, Optional`
- TYPE_CHECKING 块：FArchive, PackageFileSummary, ObjectImport, ObjectExport, PackageIndex（避免循环导入）
- `from uasset_read.link.object_instance import UObjectInstance`（运行时导入）

**构造函数 `__init__`:**
参数：archive: FArchive, summary: PackageFileSummary, name_map: List[str], import_map: List[ObjectImport], export_map: List[ObjectExport]
内部字段：
- `self._archive = archive`
- `self._summary = summary`
- `self._name_map = name_map`
- `self._import_map = import_map`
- `self._export_map = export_map`
- `self._import_objects: List[UObjectInstance] = []`
- `self._export_objects: List[UObjectInstance] = []`
- `self._root_objects: List[UObjectInstance] = []`
- `self._preload_cache: dict[int, bool] = {}`

**link() 方法:**
1. 遍历 import_map，为每个条目创建 UObjectInstance：
   - package_index = -(idx + 1)（负数编码）
   - object_name = name_map[imp.object_name] if isinstance(imp.object_name, int) else imp.object_name
   - object_class = name_map[imp.class_name] if isinstance(imp.class_name, int) else imp.class_name
   - class_package = name_map[imp.class_package] if isinstance(imp.class_package, int) else imp.class_package
   - outer_index = imp.outer_index
   - is_import = True
   - linker = self
   - _raw_import = imp
2. 遍历 export_map，为每个条目创建 UObjectInstance：
   - package_index = idx + 1（正数编码）
   - object_name = name_map[exp.object_name] if isinstance(exp.object_name, int) else exp.object_name
   - 解析 class_index: 使用 resolve_class_name(exp.class_index, import_map, export_map) 获取 object_class
   - class_package = None（export 的 class_package 通常不需要）
   - outer_index = exp.outer_index
   - is_import = False
   - serial_offset = exp.serial_offset
   - serial_size = exp.serial_size
   - linker = self
   - _raw_export = exp
3. 调用 self.build_outer_tree()
4. 收集 root_objects（outer_index.is_null 或 outer_index 为 None 的实例）

**build_outer_tree() 方法:**
遍历所有 _import_objects + _export_objects：
- 如果 instance.outer_index 为 None 或 is_null，跳过（outer 保持 None）
- 否则调用 self.resolve_package_index(instance.outer_index)
- 将结果赋给 instance.outer

**resolve_package_index(pkg_idx: PackageIndex) -> Optional[UObjectInstance]:**
- 如果 pkg_idx.is_null，返回 None
- 如果 pkg_idx.is_export：idx = pkg_idx.to_export_index()，如果 0 <= idx < len(_export_objects)，返回 _export_objects[idx]，否则返回 None
- 如果 pkg_idx.is_import：idx = pkg_idx.to_import_index()，如果 0 <= idx < len(_import_objects)，返回 _import_objects[idx]，否则返回 None

**get_children(obj: UObjectInstance) -> List[UObjectInstance]:**
- 返回 [inst for inst in all_objects if inst.outer is obj]

**preload(index: int) -> None:**
- 如果 index 在 _preload_cache 中，直接返回
- 如果 index < 0 或 index >= len(_export_objects)，返回（守卫越界）
- instance = _export_objects[index]
- 如果 instance._preloaded，更新 _preload_cache[index] = True 并返回
- 如果 instance.serial_size == 0，设置 _preloaded = True, _preload_cache[index] = True，返回
- archive.seek(instance.serial_offset)
- 延迟导入 parse_properties_from_export（避免模块加载时循环导入）：
  `from uasset_read.parsers.property_parser import parse_properties_from_export`
- 获取对应的 ObjectExport: exp = self._export_map[index]
- 调用 parse_properties_from_export(exp, self._archive, self._summary, self._name_map, self._export_map, self._import_map)
- 将结果赋给 instance.serialized_properties
- 设置 instance._preloaded = True
- 设置 _preload_cache[index] = True

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FArchive → PackageLinker | 共享 archive 实例，seek 操作改变全局位置状态 |
| parse_properties_from_export → linker | 延迟导入在 preload 中执行，失败可能泄露部分状态 |
| resolve_package_index → _export_objects/_import_objects | 越界 PackageIndex 可能导致 IndexError |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-03 | Tampering | resolve_package_index | mitigate | 显式 bounds check: 0 <= idx < len(_export_objects/_import_objects)，越界返回 None |
| T-41-04 | Tampering | preload() archive seek | mitigate | 每次 preload 前 archive.seek(instance.serial_offset)，不依赖当前位置；serial_offset 已在 read_export_map 中验证为非负 |
| T-41-05 | Denial of Service | preload() re-entrancy | mitigate | _preloaded 标志 + _preload_cache 双重守卫，防止重复解析 |
| T-41-06 | Information Exposure | LinkerParseResult.errors | accept | 仅包含技术性错误信息，无用户敏感数据；低价值目标 |

</threat_model>
