# Plan 11-01: 集成ExportMap属性解析

**Objective:** 在parse_uasset主流程中调用parse_properties_from_export()填充export.properties字段

## Context

研究发现`parse_properties_from_export()`函数已完整实现（Phase 2），但未在`parse_uasset()`主流程中调用，导致`ObjectExport.properties`字段始终为空。

**Goal:** 对SerialSize>0的ExportMap条目解析属性，使用户可从ParseResult.export_map读取组件属性值。

## Truths

- parse_properties_from_export()已实现且测试通过（test_property_parsing.py验证）
- 仅对SerialSize>0的条目解析以避免性能浪费
- 属性解析失败不应中断整体解析流程（捕获异常并记录）

<action>
在parse_uasset()函数的ExportMap读取后（约line 3920附近），新增属性解析循环：

1. 定位到read_export_map()调用后的位置（result.export_map已填充）
2. 新增for循环遍历export_map：
   ```python
   # Phase 11: 解析ExportMap属性
   for export in result.export_map:
       if export.serial_size > 0:
           try:
               export.properties = parse_properties_from_export(
                   export, archive, result.summary, result.name_map, result.export_map
               )
           except UAssetError as e:
               result.errors.append(f"Property parse error in {export.object_name}: {e}")
               export.properties = []  # 保持空列表而非None
   ```
3. 确保异常处理不影响后续Blueprint/Graph解析
</action>
