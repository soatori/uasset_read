# 64 — 集成与验证

**Goal**: 将 Kismet 字节码反编译能力集成到现有 pipeline，用真实蓝图函数验证端到端翻译质量。

**Depends on**: Phase 61, Phase 62, Phase 63

**Requirements**: INTEGRATE-01, INTEGRATE-02, INTEGRATE-03

**Success Criteria** (what must be TRUE):
1. Kismet 反编译器与现有 Phase 58 `CppFunctionBodyExtractor` 无缝集成：从 JSON function_graphs → 字节码读取 → 表达式树 → C++ 伪代码，端到端可运行
2. 至少 3 个真实蓝图函数（Jump/Aim/Move）的字节码被完整反编译为可读 C++ 代码
3. 生成的 C++ 代码与参考实现（`reference/蓝图节点文本参考.md`）逻辑一致
