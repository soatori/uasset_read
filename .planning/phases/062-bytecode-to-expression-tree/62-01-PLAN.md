# 62 — 字节码 → 表达式树

**Goal**: 从 FFunction 的 ScriptBytecode 字节流构建完整的 KismetExpression AST（抽象语法树），对标 CUE4Parse 的 FKismetArchive + BlueprintDecompilerUtils 组合。

**Depends on**: Phase 61

**Requirements**: BYTECODE-01, BYTECODE-02, BYTECODE-03

**Success Criteria** (what must be TRUE):
1. ScriptBytecodeReader 可从原始字节码字节流中读取完整的表达式树，覆盖变量、常量、函数调用、赋值、控制流
2. 表达式树保留字节码中的位置信息（每个节点标注 source_offset），支持调试和错误定位
3. 支持 UE4/UE5 版本差异处理（如 UE4.25+ 的 FFieldPath vs 旧版 FPackageIndex）
