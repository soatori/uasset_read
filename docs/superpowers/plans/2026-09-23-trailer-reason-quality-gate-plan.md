# Trailer Reason Context + Quality Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend trailing-reason classification to carry object context (name/Outer/role/payload kind), reclassify 20 of the 28 `unexpected` corpus trailers (the 8 AnimBlueprint entries belong to the sibling plan) into honest reasons (`editor_only` / `known_unimplemented`) without writing new native readers, and add a report-level quality gate over all manifest samples so trailing-warning counts, bytes, and reason mix cannot regress silently.

**Architecture:** One shared context-carrying classifier (`classify_trailing_reason(TrailingContext | str)`) in `models/diagnostics.py` replaces the class-name-only entry point; the single emit site in `legacy_reader.py` builds the context from the `ObjectRecord` plus resolved Outer name and passes `size=` so diagnostics carry unresolved bytes structurally. True reader gaps become explicit `known_unimplemented` entries (opaque + diagnostic + byte count preserved, no decoders). A new top-level `aggregate` section in `tests/samples/quality_baseline.json` — generated by `tools/gen_quality_baseline.py` and asserted by one new test over **all 66 manifest samples** — is the report-level gate; CLI `--batch` stays a pure report writer (decision recorded below).

**Tech Stack:** Python 3.10+, stdlib only (`dataclasses`, `pytest`), existing `quality_baseline.json` machinery (`_assert_quality_baseline`, `tools/gen_quality_baseline.py`). No new dependencies.

**Spec:** `docs/designs/2026-08-26-package-first-uasset-parser-refactor.md` (diagnostics/status layering: structured diagnostics, opaque region + diagnostic for unknown data, layered status, bounded reads)

## Global Constraints

- Python 3.10+ on Windows/Linux/macOS; no fixed drive letters or user directories in code.
- Read-only parser: no binary writing; unknown data preserved as opaque region + structured diagnostic, never silently skipped.
- Bounded reads: validate ranges/counts before consuming; classifier and gate must not allocate unbounded structures.
- Standard library only; zero new runtime dependencies.
- Diagnostics over logs: library code returns structured `Diagnostic`, never configures process-global logging.
- Default output bounded: no raw blobs, no unlimited arrays in any report the plan adds.
- Tests: no `skip`/`xfail`, no `MagicMock` for UE binary structures, no wall-clock thresholds; bounded bytes for reader units, real fixtures for support claims; deterministic count/byte limits only.
- Peer corroboration named only (`Corroborated (not proof): <Peer> <symbol>`); never a support claim; tracked facts belong in committed docs, not `temp/`.
- Commit format `<type>: <summary> (#issue)` (issue optional); English for code/comments/errors.
- No root-level or `scripts/` verification programs; reusable behavior lives in package APIs, `python -m uasset_read`, or tests/tools already present.
- No universal silent fallback that swallows unknowns; no warning-budget inflation to hide bytes — baseline ceilings must not be raised in the same change that increases counts, except via the documented regeneration flow with a reviewable diff.

```python
def classify_trailing_reason(context: TrailingContext | str) -> DiagnosticReason:
    """Map export trailing-bytes context to a closed reason value.

    Accepts a bare class name (str) as shorthand for TrailingContext.
    Bulk-data classes are checked first so names such as ``FontFace`` are
    never swallowed by a broader prefix rule. Identity rules keyed on
    object_name/outer_name/roles slot in after the class-prefix tables,
    immediately before the fallback return.
    """
    if isinstance(context, str):
        context = TrailingContext(class_name=context)
    cn = context.class_name
    if cn in _BULK_CLASSES or any(cn.startswith(p) for p in _BULK_PREFIXES):
        return "bulk_expected"
    if any(cn.startswith(p) for p in _EDITOR_ONLY_PREFIXES):
        return "editor_only"
    if cn in _KNOWN_UNIMPLEMENTED_CLASSES or any(cn.startswith(p) for p in _KNOWN_UNIMPLEMENTED_PREFIXES):
        return "known_unimplemented"
    # Identity-rule slot: object_name / outer_name / roles evaluated here
    # (sibling AnimBlueprint plan). Empty by design in this plan.
    return "unexpected"
```

def _resolve_outer_name(
    obj: ObjectRecord,
    objects: list[ObjectRecord],
    import_map: list[ObjectImport],
) -> str | None:
    """Resolve an object's Outer to its display name; None when absent or out of range."""
    ref = obj.outer_ref
    if ref is None:
        return None
    if ref.table == "export":
        if 0 <= ref.index < len(objects):
            return objects[ref.index].name
        return None
    if 0 <= ref.index < len(import_map):
        return import_map[ref.index].object_name
    return None

```python
def aggregate_trailing_report(docs):
    """Aggregate EXPORT_TRAILING_BYTES_UNCONSUMED across (name, doc) pairs.

    Deterministic ceilings keyed by reason and (reason, class): counts and
    unresolved bytes. Non-trailing diagnostics and missing sizes are ignored
    (size gating is enforced by test_trailing_diagnostics_carry_structured_size).
    """
    totals = {"count": 0, "bytes": 0}
    by_reason = {}
    by_reason_class = {}
    for _name, doc in docs:
        class_by_id = {o.id: (o.class_name or "?") for o in doc.objects}
        for d in doc.diagnostics:
            if d.code != "EXPORT_TRAILING_BYTES_UNCONSUMED":
                continue
            reason = d.reason or "unexpected"
            cls = class_by_id.get(d.object_id, "?")
            size = d.size or 0
            totals["count"] += 1
            totals["bytes"] += size
            r = by_reason.setdefault(reason, {"max_count": 0, "max_bytes": 0})
            r["max_count"] += 1
            r["max_bytes"] += size
            key = f"{reason}/{cls}"
            rc = by_reason_class.setdefault(key, {"max_count": 0, "max_bytes": 0})
            rc["max_count"] += 1
            rc["max_bytes"] += size
    return {
        "scope": "manifest",
        "sample_count": len(docs),
        "max_total_warnings": totals["count"],
        "max_total_bytes": totals["bytes"],
        "by_reason": dict(sorted(by_reason.items())),
        "by_reason_class": dict(sorted(by_reason_class.items())),
    }
```
