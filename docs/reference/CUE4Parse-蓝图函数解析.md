## 1. 解析架构总览

CUE4Parse 对蓝图函数的解析分为三个独立层次，各层职责清晰、可独立使用：

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 3: 反编译 (BlueprintDecompilerUtils)                  │
│  Kismet 表达式树 → C++ 风格伪代码                              │
├─────────────────────────────────────────────────────────────┤
│  Layer 2: 字节码解析 (FKismetArchive)                        │
│  原始字节 → KismetExpression 表达式树                         │
├─────────────────────────────────────────────────────────────┤
│  Layer 1: 图结构提取 (UEdGraphNode / UEdGraphPin)            │
│  Export 序列化 → 节点 + Pin 连接关系                          │
└─────────────────────────────────────────────────────────────┘
        ↑                   ↑                    ↑
   UObject 反序列化     UStruct.Deserialize   BlueprintNodeExtractor
```

### 1.1 三层关系

| 层次 | 入口 | 输出 | 独立可用 |
|------|------|------|----------|
| **Layer 1** — 图结构 | `UEdGraphNode.Deserialize()` | 节点坐标、Pin 连接、函数引用 | 是 — BPExtractor |
| **Layer 2** — 字节码 | `UStruct.Deserialize()` → `FKismetArchive.ReadExpression()` | `KismetExpression[]` 表达式树 | 是 — 任意 UStruct/UFunction |
| **Layer 3** — 反编译 | `BlueprintDecompilerUtils.GetLineExpression()` | C++ 伪代码字符串 | 依赖 Layer 2 输出 |

### 2.2 UEdGraphNode 反序列化

`UEdGraphNode` 继承自 `UObject`，在标准属性反序列化之后额外读取 Pin 数组：

```csharp
// UEdGraphNode.cs:9-18
public class UEdGraphNode : UObject
{
    public UEdGraphPinReference?[] Pins = [];

    public override void Deserialize(FAssetArchive Ar, long validPos)
    {
        base.Deserialize(Ar, validPos);  // UObject 标准属性反序列化
        if (!Ar.IsFilterEditorOnly && FBlueprintsObjectVersion.Get(Ar) >= FBlueprintsObjectVersion.Type.EdGraphPinOptimized)
        {
            UEdGraphPin.SerializeAsOwningNode(Ar, ref Pins);  // 版本感知的 Pin 序列化
        }
    }
}
```

**关键点**：
- `IsFilterEditorOnly` — Cooked 资产中编辑器数据被剥离，此字段为 true 时不读取 Pin
- `FBlueprintsObjectVersion` — UE 版本分支：早期版本 Pin 以不同方式嵌入

### 2.4 Pin 序列化机制

Pin 的序列化采用**引用解析模式**，根据上下文决定是完整读取还是只读引用：

```csharp
// UEdGraphPin.cs:112-133
public static bool SerializePin(FAssetArchive Ar, ref UEdGraphPinReference? PinRef,
    int ArrayIdx, UEdGraphPinReference? RequestingPin,
    EPinResolveType ResolveType, ref UEdGraphPinReference?[] OldPins)
{
    var bNullPtr = Ar.ReadBoolean();  // 空指针标记
    if (bNullPtr) { PinRef = null; return true; }

    var pinRef = new UEdGraphPinReference(Ar);  // 基础引用（Owner + PinId）

    if (ResolveType == EPinResolveType.OwningNode)
        PinRef = new UEdGraphPin(Ar);   // 完整读取（所有者节点调用）
    else
        PinRef = pinRef;                 // 轻量引用（LinkedTo/SubPins 等）

    return true;
}
```

**解析类型分发**：

| `EPinResolveType` | 含义 | 序列化深度 |
|---|---|---|
| `OwningNode` | 正在读取拥有此 Pin 的节点 | 完整 `UEdGraphPin` |
| `LinkedTo` | 连接目标 | 轻量 `UEdGraphPinReference` |
| `SubPins` | Split 子 Pin | 轻量 `UEdGraphPinReference` |
| `ParentPin` | 父 Pin | 轻量 `UEdGraphPinReference` |
| `ReferencePassThroughConnection` | 引用传递 | 轻量 `UEdGraphPinReference` |

### 2.5 Pin 完整字段读取顺序


```csharp
    foreach (var export in exports)
```

```csharp
private static string? GetFunctionReference(IPropertyHolder holder)
{
    // 查找 FunctionReference 属性
    foreach (var prop in holder.Properties)
    {
        if (prop.Name.Text == "FunctionReference") { tag = prop; break; }
    }

    if (tag?.Tag is not StructProperty sp) return null;

    // 从 MemberReference 结构中提取 MemberName
    var structType = sp.Value?.StructType;
    if (structType is FStructFallback fallback)
    {
        if (fallback.TryGet<FName>("MemberName", out var memberName))
            return memberName.Text;  // 返回函数名
    }
    return null;
}
```

### 3.2 UStruct 字节码读取流程

`UStruct` 是所有可包含字节码的类型的基类（`UFunction`、`UScriptStruct` 等）：

```csharp
// UStruct.cs:14-66
public class UStruct : UField
{
    public FPackageIndex SuperStruct;           // 父结构体
    public FPackageIndex[] Children;            // 子对象列表
    public FField[] ChildProperties;            // 属性列表（FField 体系）
    public KismetExpression[] ScriptBytecode;   // ← 字节码存储

    public override void Deserialize(FAssetArchive Ar, long validPos)
    {
        base.Deserialize(Ar, validPos);

        SuperStruct = new FPackageIndex(Ar);    // 父结构体引用
        Children = Ar.ReadArray(() => new FPackageIndex(Ar));  // 子对象

        if (FCoreObjectVersion.Get(Ar) >= FCoreObjectVersion.Type.FProperties)
            DeserializeProperties(Ar);          // FField 属性反序列化

        // ===== 字节码读取 =====
        var bytecodeBufferSize = Ar.Read<int>();     // 缓冲区大小
        var serializedScriptSize = Ar.Read<int>();    // 序列化脚本大小

        if (Ar.Owner!.Provider?.ReadScriptData == true && serializedScriptSize > 0)
        {
            // 核心：创建 FKismetArchive 包装原始字节
            using var kismetAr = new FKismetArchive(
                Name,
                Ar.ReadBytes(serializedScriptSize),  // 读取原始字节码
                Ar.Owner,
                Ar.Versions
            );

            var tempCode = new List<KismetExpression>();
            try
            {
                // 循环读取所有表达式直到 EOF
                while (kismetAr.Position < kismetAr.Length)
                    tempCode.Add(kismetAr.ReadExpression());
            }
            catch (Exception e)
            {
                Log.Warning(e, $"Failed to serialize script bytecode in {Name}");
            }
            finally
            {
                ScriptBytecode = [.. tempCode];
            }
        }
        else
        {
            Ar.Position += serializedScriptSize;  // 跳过字节码
        }
    }
}
```

**关键决策点**：
- `ReadScriptData` — 全局开关，控制是否解析字节码（性能优化）
- `serializedScriptSize > 0` — 空函数没有字节码
- 异常捕获 — 字节码解析失败不中断整个包加载

### 3.3 UFunction 特化

`UFunction` 继承 `UStruct`，额外读取函数特有的元数据：

```csharp
// UFunction.cs:8-32
public class UFunction : UStruct
{
    public EFunctionFlags FunctionFlags;           // 函数标志位
    public FPackageIndex? EventGraphFunction;      // EventGraph 快速调用目标
    public int EventGraphCallOffset;               // 快速调用偏移

    public override void Deserialize(FAssetArchive Ar, long validPos)
    {
        base.Deserialize(Ar, validPos);  // ← UStruct.Deserialize 包含字节码读取

        FunctionFlags = Ar.Read<EFunctionFlags>();

        // 网络复制参数
        if ((FunctionFlags & EFunctionFlags.FUNC_Net) != 0)
            Ar.Read<short>();  // RepOffset（未使用）

        // EventGraph 快速调用（UE4.18+）
        if (Ar.Ver >= EUnrealEngineObjectUE4Version.SERIALIZE_BLUEPRINT_EVENTGRAPH_FASTCALLS_IN_UFUNCTION)
        {
            EventGraphFunction = new FPackageIndex(Ar);  // 目标 UFunction
            EventGraphCallOffset = Ar.Read<int>();        // 调用偏移
        }
    }
}
```

**ReadExpression() — 核心分发**：

```csharp
// FKismetArchive.cs:32-151
public KismetExpression ReadExpression()
{
    var index = Index;  // 记录当前表达式索引
    var token = (EExprToken)Read<byte>();  // 读取 1 字节 Token

    KismetExpression expression = token switch
    {
        // ===== 变量引用 =====
        EExprToken.EX_LocalVariable       => new EX_LocalVariable(this),
        EExprToken.EX_InstanceVariable    => new EX_InstanceVariable(this),
        EExprToken.EX_DefaultVariable     => new EX_DefaultVariable(this),

        // ===== 控制流 =====
        EExprToken.EX_Return              => new EX_Return(this),
        EExprToken.EX_Jump                => new EX_Jump(this),
        EExprToken.EX_JumpIfNot           => new EX_JumpIfNot(this),
        EExprToken.EX_PushExecutionFlow   => new EX_PushExecutionFlow(this),
        EExprToken.EX_PopExecutionFlow    => new EX_PopExecutionFlow(),
        EExprToken.EX_PopExecutionFlowIfNot => new EX_PopExecutionFlowIfNot(this),
        EExprToken.EX_SwitchValue         => new EX_SwitchValue(this),

        // ===== 函数调用 =====
        EExprToken.EX_FinalFunction       => new EX_FinalFunction(this),
        EExprToken.EX_CallMath            => new EX_CallMath(this),
        EExprToken.EX_VirtualFunction     => new EX_VirtualFunction(this),
        EExprToken.EX_LocalFinalFunction  => new EX_LocalFinalFunction(this),
        EExprToken.EX_LocalVirtualFunction => new EX_LocalVirtualFunction(this),

        // ===== 上下文访问 =====
        EExprToken.EX_Context             => new EX_Context(this),
        EExprToken.EX_Context_FailSilent  => new EX_Context_FailSilent(this),
        EExprToken.EX_ClassContext        => new EX_ClassContext(this),

        // ===== 赋值 =====
        EExprToken.EX_Let                 => new EX_Let(this),
        EExprToken.EX_LetBool             => new EX_LetBool(this),
        EExprToken.EX_LetValueOnPersistentFrame => new EX_LetValueOnPersistentFrame(this),

        // ===== 常量 =====
        EExprToken.EX_IntConst            => new EX_IntConst(this),
        EExprToken.EX_FloatConst          => new EX_FloatConst(this),
        EExprToken.EX_StringConst         => new EX_StringConst(this),
        EExprToken.EX_ObjectConst         => new EX_ObjectConst(this),
        EExprToken.EX_StructConst         => new EX_StructConst(this),
        EExprToken.EX_True                => new EX_True(),
        EExprToken.EX_False               => new EX_False(),
        EExprToken.EX_Self                => new EX_Self(),

        // ===== 类型转换 =====
        EExprToken.EX_Cast                => new EX_Cast(this),
        EExprToken.EX_DynamicCast         => new EX_DynamicCast(this),
        EExprToken.EX_MetaCast            => new EX_MetaCast(this),

        // ===== 委托 =====
        EExprToken.EX_BindDelegate        => new EX_BindDelegate(this),
        EExprToken.EX_AddMulticastDelegate => new EX_AddMulticastDelegate(this),
        EExprToken.EX_CallMulticastDelegate => new EX_CallMulticastDelegate(this),

        // ===== 集合 =====
        EExprToken.EX_SetArray            => new EX_SetArray(this),
        EExprToken.EX_ArrayConst          => new EX_ArrayConst(this),
        EExprToken.EX_MapConst            => new EX_MapConst(this),
        EExprToken.EX_SetConst            => new EX_SetConst(this),

        // ===== 游戏特定 =====
        EExprToken.EX_6E when Versions.Game == EGame.GAME_WutheringWaves => new EX_WuWaInstr1(this),
        EExprToken.EX_FD when Versions.Game == EGame.GAME_2XKO => new EX_FixedPointConst(this),
        EExprToken.EX_F9 when Versions.Game == EGame.GAME_Borderlands4 => new EX_DamageSourceContainer(this),

        _ => throw new ParserException($"Unknown EExprToken {token}")
    };

    expression.StatementIndex = index;  // 记录表达式在字节码中的位置
    return expression;
}
```

### 3.5 关键表达式类型详解

#### EX_FinalFunction — 函数调用

蓝图中最常见的表达式，表示对已知函数的直接调用：

```csharp
// KismetExpression.cs:488-524
public class EX_FinalFunction : KismetExpression
{
    public override EExprToken Token => EExprToken.EX_FinalFunction;
    public FPackageIndex StackNode;          // 函数引用（通过 FPackageIndex 解析到 UFunction）
    public KismetExpression[] Parameters;    // 参数列表

    public EX_FinalFunction(FKismetArchive Ar)
    {
        StackNode = new FPackageIndex(Ar);   // 读取函数引用
        Parameters = Ar.ReadExpressionArray(EExprToken.EX_EndFunctionParms);  // 读取参数直到终止 Token
    }
}
```

**StackNode 解析路径**：
```
FPackageIndex → ResolvedObject (lazy) → UFunction
  → UFunction.Name        → 函数名（如 "ReceiveBeginPlay"）
  → UFunction.Outer       → 所属类（如 "BP_MyActor"）
  → UFunction.FullName    → 完整路径（如 "/Script/Engine.Actor.ReceiveBeginPlay"）
```

#### EX_SwitchValue — switch 表达式

```csharp
// KismetExpression.cs:1274-1303
public class EX_SwitchValue : KismetExpression
{
    public uint EndGotoOffset;                    // 结束跳转偏移
    public KismetExpression IndexTerm;            // switch 索引表达式
    public KismetExpression DefaultTerm;          // 默认分支
    public FKismetSwitchCase[] Cases;             // case 列表

    public EX_SwitchValue(FKismetArchive Ar)
    {
        ushort numCases = Ar.Read<ushort>();       // case 数量
        EndGotoOffset = Ar.Read<uint>();           // 结束偏移
        IndexTerm = Ar.ReadExpression();           // 索引表达式
        Cases = Ar.ReadArray(numCases, () => new FKismetSwitchCase(Ar));  // case 数组
        DefaultTerm = Ar.ReadExpression();         // 默认分支
    }
}

public struct FKismetSwitchCase
{
    public KismetExpression CaseIndexValueTerm;   // 匹配值
    public uint NextOffset;                        // 下一个 case 偏移
    public KismetExpression CaseTerm;              // case 体表达式
```

### 4.2 GetLineExpression() — 核心反编译

递归遍历 `KismetExpression` 树，生成 C++ 风格的伪代码字符串：

```csharp
// BlueprintDecompilerUtils.cs:1162-1781
public static string GetLineExpression(KismetExpression expression)
{
    switch (expression)
    {
        // ===== 变量引用 =====
        case EX_VariableBase variableBase:
            return variableBase.Variable.ToString();  // 变量名

        // ===== 赋值 =====
        case EX_LetValueOnPersistentFrame persistent:
            var assignment = GetLineExpression(persistent.AssignmentExpression);
            var dest = persistent.DestinationProperty.ToString();
            return $"{dest} = {assignment}";

        // ===== 函数调用 =====
        case EX_FinalFunction final:
            // 1. 递归解析所有参数
            var parametersList = new List<string>();
            foreach (var parameter in final.Parameters)
            {
                var prm = GetLineExpression(parameter);
                if (!string.IsNullOrWhiteSpace(prm))
                    parametersList.Add(prm);
            }
            var parameters = string.Join(", ", parametersList);

            // 2. 从 StackNode 提取函数名和类名
            var stackNode = final.StackNode.ToString();
            var functionName = stackNode.SubstringAfter(':').Trim('\'');
            var className = stackNode.SubstringAfter('.').SubstringBefore(':');

            // 3. 分发到专用清理器
            if (expression is EX_CallMath)
                return MathFunctionCleaner(className, functionName, parametersList, parameters);
            if (expression is EX_LocalFinalFunction)
                return $"{GetPrefix(className)}{className}::{functionName}({parameters})";

            return FinalFunctionCleaner(className, functionName, parametersList, parameters);

        // ===== 上下文访问 =====
        case EX_Context context:
            var function = GetLineExpression(context?.ContextExpression).SubstringAfter("::");
            var obj = GetLineExpression(context?.ObjectExpression);

            // 库函数直接调用，对象方法用 ->
            if (obj.Contains("KismetArrayLibrary") || obj.Contains("BlueprintMapLibrary") || ...)
                return function;
            else
                return $"{obj}->{function}";

        // ===== 控制流 =====
        case EX_JumpIfNot jumpIfNot:
            var condition = GetLineExpression(jumpIfNot.BooleanExpression);
            return $"if (!{condition})\n    goto Label_{jumpIfNot.CodeOffset}";

        case EX_PopExecutionFlow:
            return _executionFlowStack.Count == 0 ? "return" : $"goto Label_{_executionFlowStack.Pop()}";

        case EX_Return returnExpr:
            if (returnExpr.ReturnExpression.Token == EExprToken.EX_Nothing)
                return "return";
            return $"return {GetLineExpression(returnExpr.ReturnExpression)}";

        // ===== 常量 =====
        case EX_IntConst intConst: return intConst.Value.ToString();
        case EX_FloatConst floatConst: return floatConst.Value.ToString(CultureInfo.CurrentCulture);
        case EX_StringConst stringConst: return $"\"{stringConst.Value}\"";
        case EX_True: return "true";
        case EX_False: return "false";
        case EX_Self: return "this";

        // ===== 类型转换 =====
        case EX_Cast cast:
            var target = GetLineExpression(cast.Target);
            var conversionType = cast.ConversionType switch
            {
                ECastToken.CST_ObjectToBool => "bool",
                ECastToken.CST_DoubleToFloat => "float",
                ECastToken.CST_FloatToDouble => "double",
                _ => "Interface"
            };
            return $"Cast<{conversionType}>({target})";

        // ===== 结构体 =====
        case EX_StructConst structConst:
            var props = structConst.Properties.Select(p => GetLineExpression(p)).ToList();
            return $"F{structConst.Struct.Name}({string.Join(", ", props)})";

        // ===== switch =====
        case EX_SwitchValue switchValue:
            // 2 个 case 时简化为三元表达式
            if (switchValue.Cases.Length == 2)
            {
                var indexTerm = GetLineExpression(switchValue.IndexTerm);
                var case0 = GetLineExpression(switchValue.Cases[0].CaseTerm);
                var case1 = GetLineExpression(switchValue.Cases[1].CaseTerm);
                return $"{indexTerm} ? {case1} : {case0}";
            }
            // 多 case 生成 switch 语句
            ...

        // ===== 70+ 其他表达式类型 =====
        ...
    }
}
```

### 4.3 MathFunctionCleaner — 数学运算简化

将 UE 的 `KismetMathLibrary` 函数调用简化为 C++ 运算符表达式：

```csharp
// BlueprintDecompilerUtils.cs:102-207
private static string MathFunctionCleaner(string className, string functionName,
    List<string> parametersList, string parameters)
{
    if (className.StartsWith("SolarisMathLibrary_") || className == "KismetMathLibrary")
    {
        // 比较运算
        if (functionName.StartsWith("EqualEqual_")) return $"{parametersList[0]} == {parametersList[1]}";
        if (functionName.StartsWith("NotEqual_"))   return $"({parametersList[0]} !== {parametersList[1]})";
        if (functionName.StartsWith("Less_"))       return $"({parametersList[0]} < {parametersList[1]})";
        if (functionName.StartsWith("Greater_"))    return $"({parametersList[0]} > {parametersList[1]})";

        // 算术运算
        if (functionName.StartsWith("Add_"))        return $"{parametersList[0]} + {parametersList[1]}";
        if (functionName.StartsWith("Subtract_"))   return $"{parametersList[0]} - {parametersList[1]}";
        if (functionName.StartsWith("Multiply_"))   return $"({parametersList[0]} * {parametersList[1]})";
        if (functionName.StartsWith("Percent_"))    return $"({parametersList[0]} % {parametersList[1]})";

        // 逻辑运算
        if (functionName.StartsWith("BooleanAND"))  return $"{parametersList[0]} && {parametersList[1]}";
        if (functionName.StartsWith("BooleanOR"))   return $"({parametersList[0]} || {parametersList[1]})";
        if (functionName.StartsWith("Not_PreBool")) return $"!{parametersList[0]}";

        // 构造器简化
        if (functionName.StartsWith("MakeVector"))   return $"FVector({parametersList[0]}, {parametersList[1]}, {parametersList[2]})";
        if (functionName.StartsWith("MakeRotator"))  return $"FRotator({parametersList[0]}, {parametersList[1]}, {parametersList[2]})";
        if (functionName.StartsWith("MakeTransform")) return $"FTransform({parametersList[0]}, {parametersList[1]}, {parametersList[2]})";

        // 类型转换
        if (functionName.StartsWith("Conv_IntToBool")) return $"({parametersList[0]} != 0)";
        if (functionName.EndsWith("ToFloat"))          return $"((float){parametersList[0]})";
        if (functionName.EndsWith("ToInt"))            return $"((int32){parametersList[0]})";
        ...
    }
}
```

### 4.6 控制流栈管理

反编译器使用一个栈来追踪 `EX_PushExecutionFlow` / `EX_PopExecutionFlow` 配对：

```csharp
// BlueprintDecompilerUtils.cs:26
private static readonly Stack<int> _executionFlowStack = new();

// EX_PushExecutionFlow 压入目标地址
case EX_PushExecutionFlow pushExecutionFlow:
    _executionFlowStack.Push((int)pushExecutionFlow.PushingAddress);
    return "";  // 不产生输出

// EX_PopExecutionFlow 弹出并跳转
case EX_PopExecutionFlow:
    if (_executionFlowStack.Count == 0)
        return "return";  // 栈空 = 函数结束
    var target = _executionFlowStack.Pop();
    return $"goto Label_{target}";

// EX_PopExecutionFlowIfNot 条件弹出
case EX_PopExecutionFlowIfNot pop:
    var cond = GetLineExpression(pop.BooleanExpression);
    if (_executionFlowStack.Count == 0)
        return $"if (!{cond})\n    return";
    var tgt = _executionFlowStack.Pop();
    return $"if (!{cond})\n    goto Label_{tgt}";
```

## 5. 与 uasset_read 的对比

### 5.1 模块映射

| CUE4Parse 模块 | uasset_read 对应 | 差异 |
|---|---|---|
| `FKismetArchive` | `kismet/archive.py` — `KismetArchive` | C# 泛型读取 vs Python struct |

| `UStruct.ScriptBytecode` | `kismet/bpgc_bytecode.py` | 都在 UStruct/UFunction 层读取字节码 |

### 5.2 设计差异

| 方面 | CUE4Parse | uasset_read |
|------|-----------|-------------|
| **字节码读取** | `FKismetArchive` 统一上下文，FName 通过 `Owner.NameMap` 解析 | `KismetArchive` 独立模块，NameMap 通过参数传入 |
| **表达式分发** | 单一 `ReadExpression()` switch-case（70+ 分支） | 类似模式但分散在多个文件 |
| **反编译输出** | `GetLineExpression()` 单一递归函数（600+ 行） | `translator.py` + `body_builder.py` 分离翻译和构建 |
| **数学简化** | `MathFunctionCleaner()` 硬编码映射表 | 类似模式但更分散 |
| **控制流** | 栈管理 + `goto Label_X` 输出 | 结构化流程图构建 |
| **Pin 处理** | `UEdGraphPin` 完整序列化（16 个字段） | `UEdGraphPin` 模型（简化字段集） |
| **类型推导** | `GetPropertyTagVariable()` 统一入口 | 分散在多个解析器中 |

### 5.3 可借鉴的模式

1. **`FKismetArchive` 的统一上下文模式** — FName 通过 `Owner.NameMap` 解析，避免每种表达式自行处理引用
2. **`EX_Context_FailSilent` 的静默失败处理** — 通过继承 `EX_Context` 零代码重复
3. **`MathFunctionCleaner` 的映射表模式** — 集中管理所有数学函数到运算符的映射
4. **`FKismetPropertyPointer` 的版本分支** — 通过 `Ar.Game` 判断新旧格式，一个类处理两种序列化
5. **`UEdGraphPin` 的引用解析模式** — 根据 `EPinResolveType` 决定读取深度，避免重复数据
