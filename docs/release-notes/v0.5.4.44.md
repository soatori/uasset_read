# v0.5.4.44 Release Notes

## Breaking Changes

- **移除 `--text` 格式和 TextRenderer** — 旧的文本渲染器已完全移除，当前仅支持 JSON 和 Markdown 格式
  - 运行 `python run.py --list-formats` 查看可用格式
  - 迁移：使用 `--markdown` 替代 `--text`

## Report Quality Improvements

### CLI Output
- 批量模式新增 partial 状态统计
- 按原因（opaque、partial_metadata 等）分类显示
- 改进错误消息可读性

### JSON Renderer
- 新增 `warnings` 顶层字段（有警告时出现）
- 新增 `statistics` 字段，包含导出计数和 opaque 类分布
- `opaque_classes` 按类型统计

### Markdown Renderer
- 诊断信息按严重度分组并显示图标（❌ ⚠️ ℹ️）
- 新增 opaque 类统计到 overview

### Logging
- 改进警告聚合计数
- 结构化摘要生成

## Bug Fixes

- **#422: LevelSequence 解析修复** — LevelSequence 改为走 tagged properties 路线，移除错误的 archive-reading handler
- **#423: 批量错误日志详情** — batch 失败时记录完整 traceback 到日志文件
- **#424: 伪 EExprToken 过滤** — serial_scan_recovery 增加启发式过滤，减少伪 token 生成
- **CI 修复** — resource-safety job 指向现存测试文件，修复 collection error
- 修复批量模式未追踪 partial 文件的问题
- 修复 JSON 输出中缺失 warnings 的问题

## Improvements

- **#421: 批量摘要耗时统计** — batch_summary 新增 elapsed_seconds 字段
- **测试清理** — 移除已删除 API（parse_level_sequence、TextRenderer）的残留测试
