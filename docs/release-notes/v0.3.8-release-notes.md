## 标记说明

此版本标记为 **稳定发布**，但包含以下已知限制：

### ⚠️ 已知限制

1. **函数引用解析不完整** — 部分复杂蓝图（Lyra 等）的 `K2Node_CallFunction` 节点 `function_reference` 为 `None`，无法获取具体函数名
2. **变量名称解析** — 部分 Blueprint 变量名称显示为 `Unknown`
3. **仅支持 unbaked 资产** — cooked 资产的图数据已被剥离，无法解析（预期行为）
4. **Kismet 未知 Token** — `EExprToken 0xFF` 在容错模式下跳过

### ✅ 可以发布

- 所有单元测试通过（218 passed）
- 所有集成测试通过（40 passed, 2 xfail）
- 多资产手动验证通过（6/8 成功，1 xfail, 1 cooked）
- 版本号已统一为 `0.3.8`
- 文档已同步更新
