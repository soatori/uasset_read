# v0.5.1 迁移说明

**Version:** 0.5.1  
**Date:** 2026-07-03

## Breaking Changes

### output_version 字段移除

v0.5.1 移除了 JSON 输出中的 `output_version` 字段，替换为可选的 `$schema` 引用。

**之前:**
```json
{
  "output_version": "0.5.0",
  "status": { ... },
  "summary": { ... },
  "exports": [ ... ]
}
```

**之后:**
```json
{
  "$schema": "package.schema.json",
  "status": { ... },
  "summary": { ... },
  "exports": [ ... ]
}
```

**影响:**
- 依赖 `output_version` 字段进行版本检查的消费者将无法正常工作
- `$schema` 字段默认不启用，需要通过 `include_schema=True` 参数开启

**迁移方案:**

1. **版本检查方式变更**

   ```python
   # 旧代码
   if data.get("output_version") != "0.5.0":
       raise VersionMismatchError()

   # 新代码：使用 summary.ue_version 或 schema 字段
   if options.include_schema and data.get("$schema") != "package.schema.json":
       raise SchemaMismatchError()

   # 或直接检查 ue_version
   if data["summary"]["ue_version"] < MIN_UE_VERSION:
       raise UnsupportedUEVersionError()
   ```

2. **启用 $schema 输出**

   ```python
   # CLI
   python run.py file.uasset --include-schema

   # API
   from uasset_read.core import parse_single
   result = parse_single("file.uasset", include_schema=True)
   ```

**受影响的 API:**
- `parse_single()` 返回的 JSON 输出
- `parse_batch()` 返回的 JSON 输出
- 所有使用 `JSONRenderer` 的渲染入口

**测试验证:**
- `test_json_schema.py` — 验证 `output_version` 已移除、`$schema` 可选
- `test_json_completeness.py` — 验证 JSON 完整输出不包含 `output_version`
- `test_renderer_quality.py` — 验证输出质量检查
