uasset_read 开发文档

v0.3.8 | Unreal Engine .uasset 解析器

项目介绍

uasset_read 是虚幻引擎 .uasset 文件的 Python 解析器，使 AI 代理无需 UE 编辑器即可读取蓝图内容。专注于未烘焙/编辑器保存的资产（包含完整蓝图数据），采用零运行时依赖设计。

  • 支持 40+ 种属性类型解析、蓝图变量/变换/组件提取、Kismet 字节码反编译
  • 输出格式：JSON / Text / Markdown / Mermaid / C++ 骨架 / N2C 中间格式
  • 可选 PAK/IoStore 容器读取支持

快速开始

安装后即可通过 CLI 或 Python API 使用：

pip install uasset-read
uasset-read path/to/file.uasset          # JSON 输出（默认）
uasset-read path/to/file.uasset --summary  # 仅摘要

Python 入口：parse_uasset() 和 parse_package()

架构设计

解析器镜像 UE 内部的 FArchive 序列化管线：

.uasset 文件 → FArchive 读取器 → Deserializer → GraphParser / BlueprintParser → Formatters → 输出

开发规范

  • 仅支持未烘焙/编辑器保存的资产（Cooked 资产图数据已剥离）
  • 只读设计：仅解析，不支持修改或写入
  • 零运行时依赖：不向 dependencies 添加第三方包
  • 必须参考 UE 源码：格式理解追溯到 UE C++ 源码
  • 临时文件一律放在 temp/ 目录
