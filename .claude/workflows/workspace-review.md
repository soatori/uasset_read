## Review Process
For each workspace:
1. Check git status and changes
2. Review code changes for correctness
3. Verify test coverage
4. Check if issue requirements are met
5. Provide completion status

## Output Format
Structured report with:
- Workspace name
- Issue number
- Changes summary
- Code quality assessment
- Test coverage status
- Completion percentage
- Recommendations
