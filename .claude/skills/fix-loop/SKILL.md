# Fix Loop（修复循环）

## 适用场景

- "整理错误报告并修复"
- "研究问题并修复"
- "下一轮修复"
- 需要迭代修复多个相关问题时

## 输入

- 错误报告/失败测试列表
- 可选：修复优先级或范围限制

## 流程

1. **整理错误报告**
   - 解析错误日志/测试结果
   - 提取失败项并分类
   - 生成结构化错误列表

2. **研究解决方案**
   - 对每个错误，查询 UE 源码或 CUE4Parse 参考实现
   - 确认正确的修复方向
   - 记录源码依据

3. **创建修复计划**
   - 按优先级排序错误
   - 为每个错误定义修复步骤
   - 预估影响范围

4. **执行修复**
   - 按计划逐项修复
   - 每项修复后立即运行相关测试
   - 记录修复结果

5. **验证与汇总**
   - 运行完整测试套件
   - 生成修复报告（成功/失败/跳过）
   - 提交代码（格式：`fix: <描述>`）

6. **循环判断**
   - 若还有未修复项，返回步骤 2
   - 若全部完成，输出最终报告

## 输出

- 修复报告：包含每个错误的状态、修复方法、验证结果
- 提交记录：每项修复一个提交
- 剩余问题列表（如有）

## 边界

- 不修改无关代码
- 不降低测试强度
- 遇到需要架构调整的问题时暂停并询问
- 单次循环最多处理 10 个错误，超过则分批

## 项目特定约束

- 必须参考 UE 源码（`E:\Develop\lib\UnrealEngine`）
- 临时文件放 `temp/`
- 遵循 `.claude/rules/constraints.md`
